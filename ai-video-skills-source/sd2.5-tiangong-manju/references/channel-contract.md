# 渠道契约

## 静态出图：Midjourney（默认渠道，用户 2026-08-24 拍板）

静态场景/角色/道具出图**默认走 Midjourney**。提交流程由用户自行探索，主控负责产出 MJ 三要素交付物，方法论固化在 [references/midjourney-workflow.md](midjourney-workflow.md)：

1. **提示词**：按 `design-xianxia-celestial-shots/references/midjourney-celestial-palace-rules.md` 编译——前 1–2 句必须写画幅、镜头、核心空间事件和主体尺度；MJ 组装顺序为 `[画幅与镜头] + [一个核心空间事件] + [主体/人物尺度] + [前景遮挡或地面] + [中景建筑/奇观] + [远景云海/天体/城市] + [光线方向] + [色彩预算] + [材质证据] + [风格质量] + [硬性排除] + [MJ参数]`。
2. **参数**：集中在结尾：`--ar`、`--raw`、`--stylize`、`--chaos`、`--hd`、`--seed`、`--sref`。场景按风格档取值：写实天宫 `--chaos 5-15 --raw --stylize 180-350 --hd`；极简圣境 `--chaos 4-6 --raw --stylize 180-220`；洪荒/神兽/高能奇观 `--chaos 15-40 --stylize 300-500 --hd`。
3. **参考图**：垫图（`--sref` 或图生图）优先使用用户自己已验收的天宫图；不垫第三方版权图。

负面控制用原生 `--no`，不写长行政式负面清单。

失败规则不变：视觉不通过 → 记录最早失败变量，禁止自动重试或静默换渠道。

## 静态出图：OpenLux gpt-image-2-c（兜底/备用渠道）

当用户明确要 OpenLux，或无 MJ 渠道、需要本地直接出图（如角色 3D 国漫母板这类结构化定妆图）时使用。用户已授予长期授权，后续不再逐次询问。使用 `openlux-imagegen` Skill 的封装脚本直接调用。

固定顺序（不可跳、不可倒）：
1. 提示词与资产范围审计（本 Skill S3 段已完成的资产才可提交）
2. 调用 `openlux-imagegen` 脚本生成（`POST https://api.openlux.ai/v1/images/generations`，模型 `gpt-image-2-c`）
3. 文件可读 + 精确尺寸验收（角色 1024x1536 竖版；场景 1024x1536 竖版；道具 1024x1024 方形）
4. 视觉验收（对照 style-bible 验收门）
5. 写入唯一 `asset_manifest`

### 调用方式

```bash
python scripts/generate_image.py \
  --prompt "提示词" \
  --size 1024x1536 \
  --quality high \
  --out output.png
```

图生图（参考图改图）：
```bash
python scripts/generate_image.py \
  --prompt "修改描述" \
  --ref reference.png \
  --size 1024x1536 \
  --out output.png
```

### 尺寸对照

| 用途 | 请求 size | 实际返回 | 说明 |
|---|---|---|---|
| 角色定妆（竖版） | `1024x1536` | 1024x1536 | 3:4 竖版，天宫漫剧角色标准（默认） |
| 角色定妆（竖版 4K） | `2304x4096` | **2160x3840** | 9:16 真 4K 竖版，实测可用 |
| 场景母图（竖版） | `1024x1536` | 1024x1536 | 3:4 竖版（轻量） |
| 场景母图（竖版 4K） | `2304x4096` | **2160x3840** | 9:16 真 4K 竖版，高清首选 |
| 场景母图（横版 4K） | `4096x2304` | **3840x2160** | 16:9 真 4K 横版，横屏素材 |
| 道具档案 | `1024x1024` | 1024x1024 | 方形 |
| 高分辨率角色 | `2048x2048` | 2048x2048 | 2K 方形（需要时） |

> 用户要求：竖屏、横屏均出 4K。竖屏 4K 用 `2304x4096`（实测返回 2160x3840），横屏 4K 用 `4096x2304`（返回 3840x2160）。渠道 4K 像素上限约 9M，超过会降档。角色定妆默认仍用 `1024x1536`（够用且利于 Dola 参考图一致性）；如需极致清晰度可换 4K 竖版。

### 注意事项

- 一次只能出一张（`n=1`），多张需分次调用
- 生成耗时 30-75 秒，超时设 ≥300s
- 不支持 URL 返回，必须接收 base64 落盘
- 图生图通过 `image` 参数传参考图（data URI 格式）

### 失败规则

超时、失败或视觉不通过 → 记录最早失败变量，**禁止自动重试、禁止静默切换渠道**。重做需新的当次授权。

## 视频：Seedance 2.5 图生视频（用户自行在 Dola 渠道调用）

### 提交方式

本 Skill **不直接提交视频生成任务**。S5 产出两样东西交给用户：
1. **提示词文件夹**：每集每段一个 `.md` 文件，用户自行上传到 Dola 渠道
2. **资产图文件夹**：已验收的角色/场景/道具/首帧图，用户自行上传到 Dola 渠道作为参考图

### 单集结构：6 段 × 30s = 3 分钟

每集拆为 6 个独立 30 秒片段，各自独立提交：

```text
第N集/
├── prompts/           ← 提示词文件夹
│   ├── seg01_30s.md   ← 第1段（0-30s）
│   ├── seg02_30s.md   ← 第2段（30-60s）
│   ├── seg03_30s.md   ← 第3段（60-90s）
│   ├── seg04_30s.md   ← 第4段（90-120s）
│   ├── seg05_30s.md   ← 第5段（120-150s）
│   └── seg06_30s.md   ← 第6段（150-180s）
└── assets/            ← 资产图文件夹
    ├── characters/     ← 角色定妆图
    ├── scenes/         ← 场景母图
    ├── props/          ← 道具图
    └── keyframes/      ← 首帧/承接帧（每段一张）
```

### 每段提示词规则

- 每段独立 30 秒，正文不写秒数/时间戳/帧号
- 每段写清 `@图片` 参考职责（角色图、场景图、首帧图）
- 段间连续性通过首帧/末帧承接：上一段末帧 = 下一段首帧参考
- 纯净素材声明："纯净视频，全程无字幕、无背景音乐"
- 台词与声音写在对应动作段内，不另设独立声音大段

### 参考职责分离

- `@图片1`（角色定妆图）：仅参考脸型、发型、服装身份与材质等级；不参考背景
- `@图片2`（场景母图）：仅参考空间布局、地标、光线方向、色彩；不参考人物
- `@图片3`（首帧/上一段末帧）：仅参考当前构图、主体位置、动作起始状态

## 候选验收与 accepted_clip

- 用户在 Dola 渠道生成后回传视频文件
- 候选片段逐项验收：角色身份一致（对照定妆图）、天宫场景锚点稳定（主殿轮廓/主光/云层）、动作因果可读、无换脸/滑步/穿模/建筑崩坏、段间承接连贯
- 通过 → 登记 `accepted_clip`；不通过 → 标记最早失败变量，只重做该最早片段
- 返工原因与候选保留，不删除证据
