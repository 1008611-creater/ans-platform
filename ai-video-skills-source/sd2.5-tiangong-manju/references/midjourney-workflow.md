# Midjourney 出图三要素方法论

> ⚠️ **已废弃（2026-08-24）**：本文件基于旧版 MJ 假设，V8.2 语法已变。新权威见 `mj-tiangong-imagegen` Skill（V8.2 自然语言模版 + 参数表 + 参考图关联度手册）。本文件仅作历史参考。

用户 2026-08-24 拍板：天宫漫剧静态出图默认走 Midjourney。本文件固化"提示词 → 参数 → 参考图"三要素的编译与交付规则。提交流程（如何在 MJ 客户端/网页/中转渠道实际出图）由用户自行探索；主控的职责是把三要素编译成**可直接复制提交的成品**，不做提交。

## 三要素总览

| 要素 | 作用 | 主控产出物 |
|---|---|---|
| 1. 提示词 | 决定画面内容、构图、尺度、光影、材质 | 一段可直接复制的完整 MJ prompt（英文或中英混合），前 1–2 句写画幅+镜头+核心空间事件+主体尺度 |
| 2. 参数 | 决定画幅、风格化程度、随机度、底模 | 集中在 prompt 末尾的参数串：`--ar --raw --stylize --chaos --hd --seed --sref` |
| 3. 参考图 | 锁定风格/构图/质感，降低随机性 | 垫图清单（`--sref` URL 或图生图底图）+ 每张图"参考什么/不参考什么" |

三要素的优先级：先把提示词的骨架写对（一个核心空间事件 + 极小人物尺度 + 大面积有内容空气 + 东方建筑语法），再配参数控制风格化强度，最后用参考图收敛风格。骨架不对时，调参数和垫图都救不回来。

## 要素一：提示词

### 组装顺序（不可打乱）

```text
[画幅与镜头] + [一个核心空间事件] + [主体/人物尺度] +
[前景遮挡或地面] + [中景建筑/奇观] + [远景云海/天体/城市] +
[光线方向] + [色彩预算] + [材质证据] + [风格质量] +
[硬性排除] + [MJ参数]
```

### 开头句公式

横版（电影感建立镜头）：
```text
16:9 cinematic Chinese xianxia film still, low eye-level 24mm wide lens, [one dominant spatial event], [tiny adult immortal figures under X% of frame] used only for scale, ...
```

竖版（天宫大门/阶梯俯冲/人物背影眺望）：
```text
9:16 vertical cinematic Chinese xianxia establishing shot, ultra-wide low-angle view, [dominant vertical event], [one tiny rear-facing adult immortal under X% of frame], ...
```

### MJ 提示词硬规则

- **前 1–2 句必须写画幅、镜头、核心空间事件和主体尺度**，不要先堆抽象风格词。
- **一个画面只保留一个主空间事件/主奇观**。巨月、圆门、瀑布、神兽、能量柱不同时出现。
- 不适合长行政式分层；可以写长，但要像电影美术设定一样连续描述，少用"参数锁定、五层空间"这类内部术语。
- "华丽"来自尺度和材质（透视、遮挡、反射、云层体积、建筑比例），不是堆词。
- 负面内容写一条 `--no` 或一句 avoid，不写长清单。

### 从参考模块提炼的稳定写法

A 极简圆门 / B 天宫柱廊 / C 水上天河 / D 宗门桥 / E 落霞青鸾 / F 洪荒能量瀑布 / G 天梯 / H 月宫对照 / I 神兽托城 / J 沙海蓬莱。每个模块的"核心事件 + 构图 + 色彩 + 关键词"见 `design-xianxia-celestial-shots/references/midjourney-celestial-palace-rules.md` 第 4 节，不重复粘贴。

## 要素二：参数

参数集中在 prompt 末尾，不夹在句中。

| 参数 | 作用 | 天宫场景取值 |
|---|---|---|
| `--ar` | 画幅 | `16:9` 电影横幅（水庭/长廊/云海/神兽）；`9:16` 竖版压迫（大门/阶梯/人物背影）；`21:9`/`2:1` 超宽建立镜头（桥/横向飞瀑） |
| `--raw` | 减少 MJ 自身美化，更贴摄影写实 | 写实天宫必加 |
| `--stylize` | 风格化强度 | 写实天宫 180–350；极简圣境 180–220；洪荒/神兽/高能奇观 300–500 |
| `--chaos` | 随机度 | 写实 5–15；极简 4–6；洪荒/神兽 15–40 |
| `--hd` | 高分辨率 | 场景/巨构建议加 |
| `--seed` | 稳定复现 | 需要系列一致性时锁定 |
| `--sref` | 风格参考图 | 见要素三 |

三档预设（照抄即用）：
- **写实天宫**：`--chaos 5-15 --raw --stylize 180-350 --hd`
- **极简圣境**：`--chaos 4-6 --raw --stylize 180-220`
- **洪荒/神兽/高能奇观**：`--chaos 15-40 --stylize 300-500 --hd`

调参口诀：
- 画面太乱 → 降 `--chaos`，主事件缩成一个，补 `minimal elements, no clutter`。
- 建筑西化 → 正向加 `strictly oriental Chinese xianxia palace architecture, layered flying eaves and dougong brackets`，`--no` 加 `European palace western dome cathedral fantasy castle`。
- 复现某张满意的图 → 保留该图的 `--seed`，其余不动。

## 要素三：参考图

参考图用于收敛风格，降低随机性。两条硬边界：

1. **只用用户自己已验收的天宫图**（本项目 `outputs/` 内通过验收门的产物）或用户明确提供的合法参考；**不垫第三方版权图**、不复刻受保护作品的具体画面。
2. 每张参考图必须声明"参考什么 / 不参考什么"，职责唯一。

用法：
- `--sref <图片URL>`：只参考风格/质感/色调，不锁构图。适合跨系列统一视觉。
- 图生图（首图 + prompt）：参考构图和主体位置，再叠加新的空间事件。适合在同一场景内换机位/换光线。

参考图职责分离（与 I2V 参考职责一致）：
- 风格参考图：只参考色彩、光线、材质等级、整体氛围；不参考人物、构图、剧情。
- 场景参考图：只参考空间布局、地标、主光方向；不参考人物。
- 角色参考图：只参考身份、脸型、发型、服装；不参考背景。

## 交付格式（用户要图时按此输出）

按 `design-xianxia-celestial-shots/SKILL.md` 的 Midjourney 输出要求，只输出四段：

1. `MJ升级思路`：3–5 条，指出主事件、尺度、画幅、负面控制怎么定。
2. `Midjourney完整提示词`：一个可直接复制的 prompt，参数集中在最后。
3. `可选负面词`：一行 `--no`，优先排除西式建筑、文字水印、人物过大、塑料水、雾糊。
4. `如果还糊`：给一个具体改法（降 chaos / 缩人物 / 删次要奇观 / 换画幅）。

用户说"只要提示词"时，只输出第 2 段 + 第 3 段。

## 与视觉 DNA 的关系

MJ 提示词仍须遵守 `chinese-celestial-palace` 的视觉 DNA 与质量门（可信中国木构、云海物理、尺度证据、单一主光、克制配色、大留白）。MJ 负责把这些规则用"紧凑电影设定式"语言写出来，而不是推翻它们。质检标准不变：总分 ≥85，无建筑结构/云物理/尺度/主光/随机文字/多奇观硬失败。
