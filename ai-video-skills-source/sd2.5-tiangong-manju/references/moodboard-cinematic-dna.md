# 情绪板参考图：电影感视觉 DNA 与编译模板 v1

> 来源：`E:/漫剧/资产图/情绪板参考图/` 8 张样图（1648x2944，9:16 竖幅）。
> 用途：把"做出这种图"的方法固化为可复用的编译规则。与 `sd2.5-tiangong-manju` 的中性 3D 国漫路线并存，作为**电影感叙事路线**的权威视觉源。

## 一、8 图共同视觉 DNA（逐项实测提取）

### 1. 第一人称主观视角（8/8）
- 7 张画面内含"第一人称的手"：持茶杯、伸出的手、执笔写纸、拉绳、递物；
- 第 8 张以前景人物背影+案头代行主观位。
- 观众永远"站在场景里"，不是旁观上帝视角。

### 2. 垂直坠落式高位空间（8/8）
- 机位都在悬崖/高楼/飞舟的边缘：脚下是云海，头顶或远处是殿宇；
- 画面张力来自"上-下"垂直差，而非水平纵深。

### 3. 云海成海（8/8）
- 云不是雾、不是贴图，是**翻滚的海浪**：有浪头、有体积、有被光打亮的云顶、有暗部云谷；
- 多处云间垂落瀑布（云瀑），云海里有"航道"。

### 4. 空中木船（4/8，世界观符号）
- 带桅杆帆索的木船在云海中航行/停泊，是这个世界"交通方式"的锚点。

### 5. 生活痕迹前置（8/8）
- 前景必有可触摸的旧物：信纸、书卷、茶盏、香炉、烛火、铜器、灯笼、绳索；
- "有人在这里生活"的叙事感，而非空景。

### 6. 暖冷双光源对撞（8/8）
- 暖：灯笼/烛火/香火星，2700K 橙，只照亮前景人物与器物；
- 冷：月光/黎明蓝天/星空，青蓝，铺满远景云海与建筑剪影；
- 两色在画面中部交界，形成电影感色分离。

### 7. 暗调高对比电影渲染（8/8）
- 整体偏暗、湿润、有空气感；暗部不死黑、亮部柔滚降；
- 有景深（前景手/帘微虚）、轻微暗角、胶片颗粒感；
- **拒绝**：高亮度白底、塑料 CG、游戏 UI、过曝、HDR 过锐。

### 8. 深色风化中式木构（8/8）
- 建筑是**深色旧木**、黛瓦、铜绿、局部金箔高光，不是白玉纯净渲染；
- 木纹理、榫卯、雕花窗、垂帘、风铃等细节密度高。

### 9. 人物"在场感"而非"完美感"（6/8 有人物）
- 人物小、背影、侧脸、动作中（读信、递灯、拉绳、凭栏），不摆拍；
- 服饰是真实织物褶皱与垂坠，不是时装展示。

### 10. 前景遮挡分层（8/8）
- 纱帘/帷幔/屋檐/栏杆/手部从画面边缘切入，形成 3-5 层深度阶梯：
  前景遮挡 → 近景人物/器物 → 中景云海/船 → 远景殿宇 → 天空。

## 二、与现有天宫风格圣经的差异

| 维度 | 天宫 style-bible（中性 3D 国漫） | 本情绪板（电影感叙事） |
|---|---|---|
| 视角 | 客观展示视角 | 第一人称主观 |
| 亮度 | 高明度云白/珍珠灰 | 暗调、湿润、高对比 |
| 建筑 | 白玉/浅石色纯净 | 深色旧木/铜绿/金箔 |
| 人物 | 角色定妆主体 | 在场叙事小人物/主观手 |
| 云 | 托举/留白 | 海浪式云海+云瀑+航道 |
| 光 | 单一主光 | 暖冷双光源对撞 |
| 用途 | 资产档案/定妆 | 叙事概念图/分镜/海报 |

两条路线不互相替代：资产定妆仍走中性母板；**分镜、情绪、海报、开场镜头走本路线**。

## 三、编译模板（自然语言，直接喂 OpenLux gpt-image-2-c）

```text
9比16竖幅，一幅真人电影质感的中式玄幻叙事概念图：观众以第一人称视角站在{location}，{foreground_action}。

前景：{occluder}从画面{occluder_side}切入并轻微失焦，{prop_1}与{prop_2}置于近前，被{warm_source}的暖橙色光照亮，器物有旧痕与使用感。

垂直空间：机位{camera_pose}；脚下是{cloud_sea}，{cloud_detail}；中景{mid_anchor}；上方或远处{far_anchor}的深色中式木构剪影，檐角垂{hanging}。

光线：两个光源对撞——{warm_source}给前景人物与器物暖橙2700K光，{cool_source}给远景云海与建筑青蓝冷调；暖冷在画面中部交界；暗部保留细节，亮部柔滚降。

材质：深色风化旧木、黛瓦、铜绿与局部金箔高光、湿润石面、半透纱帘；人物衣料有真实褶皱垂坠，动作自然不摆拍。

渲染：暗调高对比电影摄影质感，浅景深，轻微暗角与胶片颗粒，空气透视；不要塑料CG、游戏UI、过曝、霓虹、文字、水印、logo、卡通Q版、现代物品。
```

槽位默认值：
- location：悬崖高阁的回廊 / 飞舟船头 / 临云书斋的窗边
- foreground_action：一手持茶盏凭栏 / 执笔在信纸上停顿 / 向对面递出一盏灯
- occluder：纱帘、屋檐、栏杆、自己的手
- cloud_sea：翻滚如海浪的云海，云顶被冷光打亮、云谷沉入暗部
- mid_anchor：一艘带桅杆的空中木船（可选）
- far_anchor：层叠殿宇 / 主殿 / 天际桥廊
- warm_source：灯笼 / 烛火 / 香火星
- cool_source：满月 / 黎明蓝天 / 星空

## 四、v1 质感差距诊断（2026-08-24）

v1 两张产物与参考图对比，差距根因是**密度不足**，具体：

| 维度 | 参考图 | v1 产物 | 差距 |
|---|---|---|---|
| 散落暖光点 | 3-7 个灯笼/烛火散布 | 1 个 | 暖光点太少，无"万家灯火"感 |
| 人物数量 | 多个小人物散布 | 1 个 | 无叙事群落感 |
| 阴影色相 | teal 青 | 中性灰 | 缺电影调色 |
| 光晕 | halation 溢出+镜头眩光 | 无 | 光线太干净 |
| 前景道具 | 书+笔+茶+香+铜器 密集 | 2 件 | 无"有人在此生活"密度 |
| 胶片质感 | 颗粒+暗角+湿润反光 | 无 | 太干净像 CG |
| 云海暗部 | 云谷深暗、有云瀑 | 浅淡 | 云没有体积感 |

## 五、v2 密度补丁（已验证）

### 补丁内容

1. **密度清单**：prompt 显式列举前景道具 6+ 件（信纸+香炉+毛笔+旧书+茶壶+铜钥匙）、中景 2 艘船+散落绳索木箱、远景 5 扇窗有灯光其中 1 扇有人影、檐角有风铃+布幔+鸟
2. **胶片 stock 语言**：`Kodak Vision3 5219 胶片stock质感，ISO800颗粒`
3. **调色语言**：`teal-orange调色，暗部偏teal青`
4. **光效语言**：`halation光晕溢出与镜头眩光`
5. **湿润质感**：`湿润石面、湿润反光`
6. **旧痕细节**：`茶渍、书卷边缘卷损、铜锈`
7. **降曝指令**：`暗调高对比`，排除项加`白亮底`

### v2 产物文件大小对比（信息密度代理指标）

| 版本 | 路线 | 文件大小 | vs v1 |
|---|---|---|---|
| v1 图生图 | 云船提灯 | ~7MB | 基线 |
| v1 纯文本 | 临云回廊 | ~9.9MB | +42% |
| **v2 图生图** | 临云回廊 | **12.5MB** | **+79%** |
| **v2 纯文本** | 临云回廊 | **10.1MB** | **+44%** |

### v2 验收

v2 图生图（12.5MB）信息密度最大，质感最接近参考图。v2 纯文本（10.1MB）也超过 v1 最佳，说明**密度清单 + 胶片 stock 语言**是可复制的 prompt 技术而非依赖参考图。

## 六、复现路线（v2 已验证）

- **路线 A（图生图，首选）**：OpenLux `--ref` 喂一张本文件夹样图 + v2 密度 prompt，质感还原度最高。
- **路线 B（纯文本）**：v2 密度 prompt 直出，不依赖参考图也能达到接近的密度与质感。
- **验收门**：暖冷对撞、云海成海、前景生活器物 6+件、暗调电影感、teal阴影、halation光晕六项全过。

## 七、v2 编译模板（密度补丁版）

```text
9比16竖幅，一幅真人电影质感的中式玄幻叙事概念图：观众以第一人称视角站在{location}，{foreground_action}。

前景：{occluder}从画面{occluder_side}切入并轻微失焦；{prop_list_6plus}；{warm_source}的暖橙光照亮前景器物与手部，器物有旧痕与使用感、{wear_detail_1}、{wear_detail_2}。

中景：{cloud_sea_detail}；云海里{mid_anchor_1}，{mid_detail_1}；{mid_anchor_2}，{mid_detail_2}。

远景与上方：{far_anchor}，{far_detail_with_3plus_light_points}；{cool_source}，{moon_detail}。

光线：两个光源对撞——{warm_source}给前景暖橙2700K光，有halation光晕溢出与镜头眩光；{cool_source}给远景青蓝冷调；暖冷在画面中部交界；暗部偏teal青、保留细节，亮部柔滚降。

材质：深色风化旧木、黛瓦、铜绿与局部金箔高光、湿润石面、半透纱帘、{wear_detail_3}、榫卯雕花、{wear_detail_4}；人物衣袖真实织物褶皱垂坠。

渲染：暗调高对比电影摄影质感，Kodak Vision3 5219胶片stock质感，ISO800颗粒，浅景深，轻微暗角与胶片颗粒，teal-orange调色，空气透视，湿润反光；不要塑料CG、游戏UI、过曝、霓虹、文字、水印、logo、卡通Q版、现代物品、白亮底。
```

密度清单槽位（必填 6+ 件）：
- prop_list_6plus：信纸、香炉、毛笔、旧书、茶壶、铜钥匙、绳索、木箱（选 6+）
- wear_detail：茶渍、书卷边缘卷损、铜锈、旧木纹理、使用痕（选 2+）
- far_detail_with_3plus_light_points：三五扇窗内透出暖橙灯笼光点、其中一扇窗半开露出人影
- mid_detail：甲板上散落绳索与木箱、两艘船之间有系缆
