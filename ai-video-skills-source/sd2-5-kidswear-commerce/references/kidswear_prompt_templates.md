# sd2.5童装带货skill｜口播与镜头模板

## 使用顺序

1. 读取商品图和用户确认的商品事实。
2. 选择一个主风格：场景沉浸型、换装变装型、知识科普型。
3. 在完整提示词内部单独设置【连续妈妈口播】字段，集中放置一条完整口播；动作与镜头段只写画面执行，不逐句插入口播；不得把口播移到提示词外。
4. 按“整体识别 -> 核心结构 -> 活动证明 -> 场景结果”安排证据。
5. 可直接投喂的提示词只保留必要的画面/声音约束；后期录音、字幕、BGM、音效、剪辑和投放说明放到提示词外的交付备注。


## 场景沉浸型口播模板

```text
[具体生活场景]的时候，很多妈妈都会遇到[具体穿衣麻烦]。我会更愿意选这种[品类]，因为[可见结构]，看起来[白话结果]；再看[细节一]和[细节二]，孩子[具体活动]时能看到[衣服变化或活动结果]。平时[真实场合一]、[真实场合二]都能穿，想看颜色和尺码，可以进橱窗对照一下。
```

镜头顺序：生活任务中景 -> 商品整体中景 -> 一个结构近景 -> 一个活动中景 -> 场景结果广中景。

## 换装变装型口播模板

```text
孩子原来穿[基础搭配]，看着没问题，就是[具体视觉问题]。不用重新搭一整套，换上这件[商品]，先看[整体变化]，再看[局部变化]；孩子[一个活动]时，[衣服结构]也能看清。上学、出门或周末活动都能直接套用，喜欢这种省事的搭配，进橱窗看一下。
```

镜头顺序：换装前完整搭配 -> 商品遮挡/匹配转场 -> 换装后完整搭配 -> 一个细节近景 -> 一个自然活动中景。

## 知识科普型口播模板

```text
看[品类]别只看颜色，先看[结构一]。它做成[可见结构]，简单说就是[白话解释]，所以视觉上会[可见结果]；再看[结构二]，它让[衣服比例/领型/边缘/层次]更清楚。这里说的是从图片能看到的设计，不把它夸成功能，想自己对照细节和尺码，进橱窗看商品图。
```

镜头顺序：结构一特写 -> 手部触摸或动作验证 -> 回到整体比例 -> 结构二近景 -> 与结构相关的活动中景。

## 动作段模板

```text
[景别]，主体从[起点状态]开始，因为[触发原因]执行[一个主动作]；动作结果是[商品结构被看见]，衣料/纹理/下摆/袖口产生[二次物理反应]，主体出现[微小自然反应]。镜头[保持/跟随/短推/短移]，因为要[揭示结构/跟随手部/澄清空间/承接转场]；画面中心保持[主体或商品结构]，光线来自[窗/门/户外/室内实用光]，在衣服表面形成[可见光影结果]。声音只保留连续妈妈口播和与动作直接相关的自然声音；在完整提示词中单独设置【连续妈妈口播】字段，集中放置完整口播，不把口播句写在动作段末尾。不要在动作段或提示词正文中写后期录音、字幕、BGM添加、音效合成、剪辑或投放说明。
```

## 交付前四问

- 观众现在首先看见的，是商品、孩子的动作，还是无关道具？
- 这一镜解决了哪个家长购买疑问？
- 口播中的这句话，画面是否正在展示对应证据？
- 如果删掉这一镜，商品理解或购买理由是否会损失？如果不会，删掉。
