# 小说对白设计三差异法

## 适用场景
- 设计有张力、有趣味的小说对白
- 让不同身份角色说话方式有明显区分
- 通过对白制造喜剧感和戏剧冲突

## 核心规则
- **身份差**：市井人说市井话，官场人说官场话，江湖人说江湖话，不同身份说话方式不同
- **信息差**：对白趣味来自"一个人知道，一个人不知道"（撒谎被看穿、想装体面被识破）
- **性格差**：一个嘴硬直接，一个冷面拆台，形成天然喜剧感
- **三差叠加**：最好的对白同时包含身份差+信息差+性格差
- **幽默原则**：幽默来自人物错位，而非现代段子或强行搞笑

## 可调用内容

### 身份差对照表
| 身份类型 | 语言特征 | 典型话题 |
|---------|---------|---------|
| 市井人 | 生活化、直接、讲实惠 | 银子、吃食、生计、面子 |
| 江湖人 | 黑话、规矩、试探、套话 | 走镖、买路钱、江湖人情 |
| 官场人 | 试探、规劝、原则、权衡 | 律法、名节、朝局、门第 |

### 信息差对白公式
```
A隐瞒/伪装 → B看穿但不说破 → 读者知道双方底牌 → 张力产生
```

### 性格差对白公式
```
A嘴硬逞强 → B精准拆台 → A更狼狈但保持尊严 → 喜剧感+人物魅力
```

### 对白检查清单
- [ ] 不同身份角色说话方式是否有明显区分？
- [ ] 对白中是否有信息差制造张力？
- [ ] 性格差异是否通过对白自然体现？
- [ ] 幽默是否来自人物错位而非段子？
- [ ] 对白是否同时推进了人物/关系/矛盾？

## 输出示例
> 林凤君嘴硬、直接、反应快。陈秉正冷面、锋利、会拆台。两人对白经常形成：一个嘴硬，一个拆台。这类对白有天然喜剧感。很多对白的趣味来自"一个人知道，一个人不知道"——女主撒谎，男主看穿；女主想装体面，别人其实心里明白。

## 避免事项
- 不要所有角色说话方式一样
- 不要强行插现代段子破坏氛围
- 不要为了搞笑牺牲人物尊严
- 对白不要只聊天不推进剧情
- 古风对白不要堆砌假古文
