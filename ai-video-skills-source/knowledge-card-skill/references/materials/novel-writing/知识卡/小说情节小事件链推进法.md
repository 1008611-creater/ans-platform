# 小说情节小事件链推进法

## 适用场景
- 设计连续有阅读动力的小说情节
- 避免"每章等爆点"的节奏问题
- 用小事件持续推动人物关系和故事发展

## 核心规则
- **核心原则**：一件小事接一件小事，每件事都推动人物关系
- **事件功能**：一个有效小事件最好同时完成三件事——展示人物、推进关系、暴露矛盾
- **开篇公式**：危机场景 → 人物应对 → 性格露出 → 背景补充（先给事件，不急着介绍人物）
- **事件分类**：江湖事件（展示能力）、官场事件（展示规则）、生活事件（展示不适配）、感情事件（推动关系）、家庭事件（展示压力）
- **节奏控制**：不一定每章都要大爆点，但每章最好都有一个具体事件

## 可调用内容

### 开篇公式
```
危机场景 → 人物应对 → 性格露出 → 背景补充
```
好处：读者马上进入场景、人物能力自然展示、世界规则顺势展开、背景信息不生硬

### 事件功能分类表
| 事件类型 | 作用 | 示例 |
|---------|------|------|
| 江湖事件 | 展示女主能力和市井经验 | 夜船遇水匪、父女护镖周旋 |
| 官场事件 | 展示男主原则和权力环境 | 官船查私盐、衙门误会 |
| 京城生活事件 | 展示女主与高门规则的不适配 | 鸟市买锦鸡、茶楼遇贼 |
| 感情事件 | 推动旧情破裂和新关系建立 | 灯会约会、何怀远解围 |
| 家庭事件 | 展示父女情感和现实压力 | 父女卖艺撑场面 |

### 情节推进公式
```
小危机开场 → 人物靠本事解决 → 暴露身份差异 → 引出更大规则 → 男女主产生误判 → 下一事件继续碰撞
```

### 事件检查清单
- [ ] 每个事件是否至少完成"展示人物/推进关系/暴露矛盾"中的两项？
- [ ] 事件之间是否有因果或递进关系？
- [ ] 是否避免了纯过渡章节（无具体事件）？
- [ ] 开篇是否先给事件而非先介绍人物？

## 输出示例
> 前期事件链：夜船遇水匪 → 父女护镖周旋 → 官船查私盐 → 女主假扮孕妇 → 男主识破女主 → 进京买锦鸡 → 围观抄家 → 茶楼遇小偷 → 女主被误会带走 → 何怀远出面解围 → 灯会约会 → 父女卖艺撑场面。这些事件单独看不算巨大，但组合起来很有效。

## 避免事项
- 不要每章都等"大爆点"，小事件也有价值
- 不要写纯过渡章节（无具体事件推进）
- 不要开篇先介绍人物背景再给事件
- 事件不要只推进剧情不展示人物
- 事件之间不要没有关联
