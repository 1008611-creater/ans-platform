# 小说场景烟火气细节法

## 适用场景
- 营造有生活质感的市井场景
- 避免"喊口号式"的场景描写
- 用具体细节让读者产生代入感

## 核心规则
- **核心公式**：烟火气 = 具体物件 + 具体价格 + 具体动作 + 具体尴尬
- **细节原则**：好的市井感不是喊口号，而是靠小细节堆出来的
- **场景功能**：每个场景都要同时承担"好看+推进人物+暴露矛盾"的功能
- **正剧底色**：轻喜剧场景中要埋入现实压力（私盐/官船/抄家/婚约/阶层差距）
- **格局支撑**：小事件负责好看，大关系负责推进，大环境负责加压

## 可调用内容

### 烟火气细节清单
| 类别 | 具体示例 |
|------|---------|
| 具体物件 | 茶点、首饰、衣服、帕子、鸟笼、锦鸡 |
| 具体价格 | 鸟市里锦鸡多少钱、镖银少了一半 |
| 具体动作 | 鞋子被泥糊住、灯会里卖艺讨赏、茶楼先结账 |
| 具体尴尬 | 想装体面却露怯、想撒谎被拆穿、想逃跑被堵住 |
| 感官细节 | 卤牛肉的香味、泥水溅到裙摆、茶楼人声嘈杂 |

### 场景写法公式
```
具体物件 + 具体价格 + 具体动作 + 具体尴尬 = 有烟火气的场景
```

### 场景检查清单
- [ ] 场景中是否有具体物件（而非抽象描述）？
- [ ] 是否有具体价格/数量（而非"很多""很贵"）？
- [ ] 是否有具体动作（而非"她做了某事"）？
- [ ] 是否有具体尴尬/冲突（而非一帆风顺）？
- [ ] 场景是否同时承担了推进人物/关系的功能？

## 输出示例
> 这本书的场景写得好，是因为它很具体。它不只写"京城繁华"，而是写：茶楼要先结账、鸟市里锦鸡多少钱、卤牛肉的香味、镖银少了一半、鞋子被泥糊住、灯会里卖艺讨赏。这些都是具体生活细节。好的市井感不是喊口号，而是靠这些小细节堆出来的。

## 避免事项
- 不要只写"繁华""热闹"等抽象词
- 不要堆砌辞藻而缺少具体细节
- 场景不要只描写不推进剧情
- 市井感不要写成土味/粗俗
- 不要忘记在轻松场景中埋入现实压力
