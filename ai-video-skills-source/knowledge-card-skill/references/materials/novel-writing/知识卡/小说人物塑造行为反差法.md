# 小说人物塑造行为反差法

## 适用场景
- 设计有厚度、不扁平的小说人物
- 通过行为反差建立角色辨识度
- 避免"作者介绍式"人设，改用"遇事反应式"立人

## 核心规则
- **核心原则**：人物靠"遇事反应"立住，不靠作者介绍
- **反差设计**：给人物的核心特质设计一个反差面（如：莽撞但真诚、清贵但后期改观）
- **职业绑定**：角色身份不能只是标签，要影响行动方式、说话方式和判断方式
- **不完美原则**：人物魅力来自真实和不完美，而非完美无缺
- **成长弧光**：人物必须有变化过程，前期特质在后期被重新审视

## 可调用内容

### 女主塑造模板（野生型）
```
核心特质：胆子大 + 反应快 + 会随机应变 + 能吃苦 + 有江湖经验
反差面：嘴硬但心软 / 莽撞但真诚 / 容易露怯也容易逞强
魅力点：被现实摔打过，但依然有旺盛生命力
避免：只写粗鲁，忽略野生、真诚、有生命力
```

### 男主塑造模板（原则型）
```
核心特质：清贵 + 冷硬 + 锋利 + 讲原则 + 不好糊弄
反差面：前期审视拆穿 → 后期重新评价
魅力点：有强烈的士人原则和判断标准，后期改变更有分量
避免：只写毒舌，忽略原则、判断力和士人骨气
```

### 配角塑造模板（现实型）
```
核心特质：老江湖 + 讲人情 + 懂规矩 + 会忍让
功能：承载江湖经验、现实压力、情感底盘
生存逻辑：人面、情面、场面，能动嘴就不动手
```

### 人物检查清单
- [ ] 人物是否靠行为而非介绍立住？
- [ ] 是否有核心特质+反差面的组合？
- [ ] 职业身份是否影响了说话和行动方式？
- [ ] 人物是否有不完美但真实的魅力点？
- [ ] 人物是否有成长/变化弧光？

## 输出示例
> 林凤君不是标准的精致型大女主，也不是完美无缺的女侠。她的强不是"算无遗策"，而是：被现实摔打过，但依然有旺盛生命力。她会假扮孕妇，会和水匪周旋，也会在京城规则里尴尬、露怯、受伤。她的魅力不是完美，而是真实、有劲儿、抗摔打。

## 避免事项
- 不要靠作者旁白介绍人物性格
- 不要写完美无缺的角色
- 不要把人物身份当标签而不影响行为
- 女主不要只写"粗鲁"而忽略生命力
- 男主不要只写"毒舌"而忽略原则厚度
- 配角不要写成纯工具人
