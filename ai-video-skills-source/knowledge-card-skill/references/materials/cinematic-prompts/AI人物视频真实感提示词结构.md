# AI人物视频真实感提示词结构

## 适用场景

适合生成单人物或多人物 AI 视频提示词，让角色不僵硬、不像摆拍，而像正在经历一个真实瞬间。

## 输入字段

- 人物身份
- 具体场景
- 当前状态
- 行为动机
- 触发事件
- 连续动作
- 动作链
- 身体联动
- 细微生命反应
- 情绪变化
- 镜头语言
- 视觉风格

## Prompt 正文

```text
请生成一段 AI 人物视频提示词。

人物身份：【人物身份】
具体场景：【具体场景】
当前状态：【当前状态】
行为动机：【人物为什么这样动】
触发事件：【声音 / 消息 / 他人动作 / 环境变化 / 情绪变化】
连续动作：【先做什么，随后怎么变化，最后停在哪里】
动作链：【起始状态 / 触发原因 / 预备动作 / 主动作 / 结束定格】
身体联动：【头部、肩膀、上身、手臂、手指、衣袖、发丝如何自然配合】
细微生命反应：【自然眨眼、轻微呼吸、眼神停顿、手指细小动作、发丝或衣袖轻微起伏】
情绪变化：【从什么情绪变成什么情绪】
镜头语言：【推进 / 跟拍 / 浅景深 / 低机位 / 手持 / 静态】
视觉风格：【电影感 / 古风 / 写实 / 商业广告 / 赛博朋克】

输出要求：
不要只写人物外貌，不要只写单一动作。必须写清楚人物在哪里、正在做什么、为什么这样动、动作如何自然持续，以及动作后的细微反应。人物整体动作克制自然，不夸张表演。
```

## 单人物输出示例

```text
一位古风女子站在安静的书房里，手里握着一把团扇，像是在等待门外的人进来。她原本低头看着桌上的书卷，听到门外传来轻微脚步声后，才慢慢抬眼看向前方。手中的团扇原本轻轻摇动，随后动作慢慢停住，表情从平静变成一丝克制的期待。发饰轻轻晃动，衣袖有细微起伏，镜头缓慢推进，古风电影感，画面安静自然。
```

## 多人物输出示例

```text
华丽的古风房间里，女子穿着红色华服，站在男子面前。男子低声说了一句话后，身体微微靠近她。女子没有立刻回答，只是抬眼看着他，眼神短暂停顿，嘴唇轻轻抿住，像是在压住情绪。男子停在她面前，没有继续逼近。镜头缓慢推进，浅景深，画面安静紧张，古风电影感。
```

## 避免事项

- 不要只写"女子抬头""人物回头""男生喝咖啡"。
- 不要让人物没有原因地看向镜头。
- 不要让人物完全静止或只有机械动作。
- 不要让多人物同时表演。
