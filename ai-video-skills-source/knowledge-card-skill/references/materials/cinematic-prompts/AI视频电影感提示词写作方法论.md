# AI视频电影感提示词写作方法论

## 适用场景
适用于所有需要写出"电影感"的AI视频提示词，包括动作戏、叙事片段、人物特写、环境镜头等。核心解决"只写关键词导致画面像静态拼贴"的问题，提供从理论框架到实战模板的完整写作体系。

## 核心规则（五要素框架）

> 不要只写画面结果，要同时写清楚**谁在动、怎么动、镜头怎么跟、情绪怎么变、环境怎么参与**。

| 要素 | 写什么 | 示例 |
|------|--------|------|
| **主体** | 谁在做 | 两名西装男子 |
| **动作** | 做什么、怎么动 | 近身搏斗，被撞向玻璃窗后反击 |
| **镜头** | 机位/景别/运动/焦段 | 中近景侧后方手持跟拍，随碰撞轻微晃动 |
| **情绪** | 角色状态/节奏/氛围/收尾 | 紧张→压抑→喘息停顿 |
| **环境** | 背景是否参与叙事，光影和空间如何配合主体 | 窗外冷蓝轮廓光+室内暖光切出面部 |

## 可调用内容

### 一、电影感动作镜头写法

**优化逻辑链：**
```
普通动作 → 明确场景 → 明确人物关系 → 明确镜头位置 → 明确动作变化 → 明确光影情绪
```

**错误→正确对比：**

❌ 错误：
```
两个人打斗。
```

✅ 正确：
```
室内夜景，两名西装男子在高层酒店房间内近身搏斗。
镜头采用手持跟拍，从主角侧后方贴近移动。
主角被撞向玻璃窗，身体短暂停顿后反击。
窗外城市冷蓝灯光形成轮廓光，室内暖色台灯制造局部高光。
整体节奏紧张、真实、有压迫感。
```

### 二、跟随主体拍摄提示词模板

**用途：** 让AI视频画面更像真实拍摄，而不是静态摆拍。

```
镜头始终跟随主体移动，保持主体在[画面中心偏左]位置。
相机以[中近景]距离贴近人物，随着人物动作[轻微晃动]。
人物移动时，背景产生轻微位移与透视变化，增强真实跟拍感。
```

**可替换参数表：**

| 参数维度 | 可选值 |
|---------|--------|
| 主体位置 | 画面中心 / 中心偏左 / 中心偏右 / 前景主体 |
| 跟拍距离 | 近景 / 中近景 / 中景 / 远景 |
| 运动方式 | 手持跟拍 / 低机位跟拍 / 侧后方跟拍 / 环绕跟拍 / 缓慢推进 |
| 运动质感 | 轻微晃动 / 稳定推进 / 紧张晃动 / 呼吸感移动 |

### 三、情绪收尾镜头模板

**用途：** 动作结束后保留情绪，使视频不生硬停止。

```
动作结束后，不要立刻切断画面。
角色短暂停顿，呼吸急促，低头整理衣服或扶墙站稳。
镜头缓慢靠近人物面部，保留[疲惫/疼痛/压抑/警觉]的情绪。
```

**常用情绪词库：**
`疲惫` `疼痛` `压抑` `警觉` `克制` `紧张` `沉默` `失神` `喘息` `迟疑`

### 四、环境参与叙事写法

**核心原则：** 环境不要只是背景，要参与画面的气氛、空间关系和叙事压迫感。

**普通→高级对比：**

❌ 普通：`房间里，两个人打斗。`

✅ 高级：
```
高层酒店房间夜景，窗外冷蓝城市灯光照进室内。
人物靠近玻璃窗搏斗，窗面反射出破碎的身体轮廓。
室内暖色台灯在墙面形成局部高光，暗部保留细节。
空间狭窄压迫，人物动作受到家具和墙面的限制。
```

**可复用环境变量：**
`窗外城市光` `室内台灯` `玻璃反射` `狭窄走廊` `雨夜街道` `霓虹反射` `烟雾` `尘埃` `逆光` `轮廓光`

### 五、错误vs正确写法拆解公式

```
错误写法：只写事件
正确写法：事件 + 场景 + 主体关系 + 镜头运动 + 光影 + 情绪收尾
```

**完整示例：**

❌ 两个人在房间里打斗。

✅ 室内夜景，两名西装男子在高层酒店房间内近身搏斗。镜头贴近主角侧后方手持跟拍，随着身体碰撞轻微晃动。窗外冷蓝城市光形成轮廓，室内暖光切出面部表情。动作结束后主角低头喘息，扶墙站稳，情绪压抑。

### 六、9要素通用公式

```
场景时间 + 主体身份 + 动作事件 + 镜头位置 + 镜头运动 +
光影关系 + 环境细节 + 情绪收尾 + 画面质感限制
```

**填空模板：**
```
[场景时间]，[主体身份]正在[动作事件]。
镜头采用[镜头位置/景别]，以[镜头运动]跟随主体。
[主要光源]形成主体轮廓，[辅助光源]补充面部或身体细节。
环境中加入[环境细节]，增强空间真实感和叙事氛围。
动作结束后，角色[情绪收尾动作]，整体情绪为[情绪关键词]。
画面风格为[写实电影质感/高反差/胶片感/冷暖对比]。
```

**完整示例：**
```
夜晚高层酒店房间内，一名受伤男子正被对手逼退到玻璃窗前。
镜头采用中近景侧后方手持跟拍，随着人物后退缓慢推进。
窗外冷蓝城市灯光形成轮廓光，室内暖色台灯照亮人物侧脸。
玻璃反射、凌乱家具和低照度暗部增强空间压迫感。
动作结束后，主角扶墙喘息，短暂停顿后抬头看向画面外。
整体情绪紧张、压抑、真实，写实电影质感，高反差但暗部保留细节。
```

## 避免事项

- **不要只写风格词，要写镜头关系** — "电影感、高级、夜景"无法指导AI生成连贯动作
- **不要只写动作结果，要写动作过程** — "打斗"不如"被撞向玻璃窗后反击"
- **不要只写背景，要写环境如何影响主体** — 环境要参与叙事压迫感和空间限制
- **不要只写高级感，要写具体的光影、材质、色彩和构图**
- **不要让动作结束得太突然，要加入情绪收尾** — 否则视频生硬切断
- **不要堆砌关键词** — 关键词堆砌导致画面像静态拼贴，动作没有连续性
