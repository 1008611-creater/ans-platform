# AI视频角色资产锁定规则

## 适用场景
适用于AI视频创作中需要角色跨镜头保持一致性的场景，通过三视图+角色特征锁定建立稳定的"角色ID"，告别"抽卡式"随机生成。

## 核心规则
- 不要只提供一张静态图作为参考，单图只是"风格与结构的弱约束"
- 必须生成三视图（正面、侧面、背面），让AI理解角色立体拓扑结构
- 启用平台"角色特征锁定"功能，将三视图拆解上传（主视图+侧视图+后视图）
- 人物和场景必须分离，避免场景光影渗入人物像素特征
- 角色资产包一旦建立，可在项目中复用，不随环境波动

## 可调用内容

### 原理：为什么单图参考会失败？
当只提供一张静态图时，AI在潜空间中将其视为"一团可能性的云"。一旦视频开始生成，像素流动，AI会试图在每一帧重新解释人物。光影、角度或动作稍有变化，AI就会"遗忘"原图特征，导致人物在第三秒变成另一个人。

### 步骤1：生成正交三视图
**核心**：不要"人物+场景+动作"一锅炖，先建立高精度多角度角色资产包。

**提示词模板**：
```
character reference sheet (角色设定图), model sheet (模组图), three-view turnaround (三视图环绕), full body shot (全身镜头), front view, side view, back view (正面, 侧面, 背面), standing side-by-side in T-pose / A-pose (并排站立, T姿势/A姿势)
```

**操作流程**：
1. 先生成一张角色美宣图确立风格
2. 使用上述提示词生成三视图
3. 目的：建立"神经锚点"，让AI理解角色立体结构

### 步骤2：启用角色特征锁定
**核心**：将三视图拆解上传，获得可复用的"角色ID"。

**操作**：
1. 不要直接上传一张图
2. 将三视图拆解：主视图、侧视图、后视图分别上传
3. 使用平台的"主体/角色锁定"功能创建角色ID
4. 此后无论角色去咖啡馆还是海边，数据特征已被锁死

### 三视图生成提示词（详细版）
```
生成[角色名]的三视图，白底图，
左侧展示精细半身特写肖像，面部特征、骨骼结构、神态表情、发型及头部配饰必须与参考图严格一致，呈现自然皮肤纹理、毛孔和发丝细节。
右侧展示完全相同的全身照片，呈标准A-pose站姿，以精确三视图排列：正视图、侧视图、背面图。超模身体比例、完整服装设计、布料层次、鞋子及整体穿搭风格必须严格遵循，所有服装配饰呈现真实物理材质质感。
```

## 输出示例
```
完整角色资产锁定流程：
1. 提示词：character reference sheet, three-view turnaround, full body shot, front view, side view, back view, A-pose
2. 生成三视图（正面/侧面/背面）
3. 拆解上传至平台角色锁定功能
4. 获得可复用角色ID
5. 后续生成直接调用角色ID，不随场景变化
```

## 避免事项
- 不要"人物+场景+动作"一锅炖，这是导致一致性崩塌的元凶
- 不要只生成一张美图，必须有三视图
- 不要直接上传单图作为参考，单图是弱约束
- 不要跳过角色特征锁定功能，三视图必须拆解上传
- 场景光影变化会渗入人物像素，人物必须从环境中剥离
- 不要认为"差不多就行"，角色资产包必须多角度完整
