# Kuaishou Copy Patterns

## Title Patterns

- 直接收益: `3步把___做好`
- 痛点反问: `你是不是也___?`
- 结果前置: `这样做以后___`
- 避坑提醒: `___别再这样做了`
- 场景共鸣: `___的人一定要看`
- 对比悬念: `同样是___, 差别在这里`

## Cover Text

- Keep each line short.
- Put the strongest noun or result on the first line.
- Avoid full sentences on the cover.

## Caption

Use this order:

1. Expand the hook.
2. Add one useful detail.
3. Ask for one action.

## Tag Hygiene

- Use 3-6 relevant tags.
- Include broad category + specific niche + audience/use case.
- Do not add unrelated trending tags.
