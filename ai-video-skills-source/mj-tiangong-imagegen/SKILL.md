# MJ 天宫生图（Midjourney V8.2 权威）

## 定位

天宫漫剧项目的**静态出图提示词权威**。用户已拍板（2026-08-24）默认用 Midjourney 8.2 做图。本 Skill 是 MJ 侧的唯一事实源：提示词模版、参数、参考图与关联度，全部按 **V8.2 现行语法**重建，不沿用 image2（gpt-image-2-c）或旧版 MJ（V6/V7 关键词式）的写法。

与冠军链的关系：
- 上游：`sd2.5-tiangong-manju`（天宫冠军）的 S3 资产段调用本 Skill 编译提示词；视觉约束继承 `chinese-celestial-palace`（结构/云物理/尺度/主光/配色）与 `design-xianxia-celestial-shots`（构图原型与镜头）。
- 下游：产出「提示词 + 参数 + 参考图清单」三件套交给用户提交（提交流程由用户探索）；产物经冠军链验收门后才写入 `asset_manifest`。
- 边界：本 Skill 不调用任何生成渠道、不产生费用、不重写剧本或分镜事实。

## V8.2 与旧写法的根本差异（编译前必读）

| 维度 | 旧写法（V6/V7/image2 式） | V8.2 权威写法 |
|---|---|---|
| 提示词结构 | 逗号分隔关键词堆砌 | **自然语言描述句**（40–80 词），像给摄影师写简报：写清空间关系、光线方向、遮挡与纵深 |
| 画质词 | 堆 4k / ultra-detailed / masterpiece | **全部删除**——V8 无意义，删掉反而更好 |
| 否定表达 | 正文写 no people / no text | **正文禁写否定句**（会混淆模型），排除一律走 `--no` 标志 |
| 风格锚点 | 一条提示词叠多种风格 | **每图只留一个风格锚点**（如"电影级写实数字绘景"） |
| 角色一致性 | `--cref --cw` | `--cref/--cw` 在 V8 系**已废除**；用 `--oref`（Omni Reference）锁人物/物件 |
| 质量参数 | `--q 2` | `--q/--quality` **已移除**；分辨率用 `--hd`（原生 2048）/ `--sd`（1024） |
| 参数版本 | 不写或 `--v 6/7` | 明确 `--v 8.2` |

## 工作流程

0. **有多张参考图时先调用 `tiangong-moodboard`**，按 `人物/远景巨构/中近景日常/素材道具` 四类整理并生成情绪板摘要；情绪板负责参考职责，随后再用本 Skill 的四类 DNA 做硬约束校验。
1. 读取任务来源（冠军链的资产需求：`asset_id`、类型、职责、参考图）。
2. **判断当前任务属于四类中的哪一类**：
   - 南天门/天庭全景/巨构场景 → **A 类：远景巨构 DNA**（建筑形制、云海、天瀑、尺度、视角）
   - 角色定妆/天兵出场 → **B 类：人物 DNA**（体态、面部、发型、服饰、动作、情绪、五大原则）
   - 角色发现天宫/情绪反应/日常 → **C 类：中近景日常 DNA**（POV/OTS/遮挡/窗光/门光）
   - 道具/法器展示 → **D 类：素材道具 DNA**（材质系统、道具形制、使用状态）
3. 读对应类别的 DNA 后，再选 `references/celestial-megastructure-prompts.md` 中的对应模版和快速路由。远景巨构有场景母图 4 变体 / 角色 3 变体 / 道具 4 变体 / 戏剧镜头 4 变体；人物/中近景有 6A/6C/6D/6E 模版；素材道具类目前使用道具模版。
3a. **考证门（强制）**：提示词中凡涉及历史/名著/神话的服饰、官服、冠帽、官职品级、道具形制、神态行为逻辑、民俗礼仪等细节，**必须先过 `references/fact-check-protocol.md`**：按"原著 > 经典改编共识 > 官制典章 > 老大指令"顺序查证，结论落盘进提交卡「查证依据」段，作废元素加 `--no` 防回潮。不凭印象写名著细节（2026-08-25 弼马温案例：老大查"帽子衣服该啥样"后，乌纱帽+大红官袍+丑萌神态全部有依据）。
4. 普通场景按 `references/prompt-templates.md` 选模版（场景/角色/道具 × 画幅），填入事实；**五层结构**：主体 → 空间与机位 → 风格锚点 → 光线与色彩 → 材质与氛围，全部自然语言成句。MXAI 国内版先过 `references/mxai-safe-language.md` 做安全词替换。
5. 按 `references/v82-parameters.md` 配参数档（画幅、raw、stylize、chaos、hd）。
6. 按 `references/reference-image-playbook.md` 决定是否垫参考图、用哪个旋钮、关联度取多少。天宫巨构已有 `references/celestial-megastructure-dna.md` 第 16 节"风格参考图集"作为优选 sref 池。
7. **提示词质量审计**：成稿后逐条核对对应类别的 DNA 覆盖度：
   - 远景巨构 → A 类：质感元素、建筑形制、云海物理、单一主光、10 项验收门
   - 人物 → B 类：体态轮廓、面部发型、服饰材质、动作情绪、五大原则、人物禁止项
   - 中近景 → C 类：POV/OTS 规则、前景遮挡、窗光/门光、中近景禁止项
   - 素材道具 → D 类：材质系统、道具形制、使用状态、道具禁止项
  提交卡正文中必须包含"本卡参考的 DNA 与情绪板来源"表格，逐项标注每条描述来自 DNA 第几节或情绪板第几类，形成可追溯的审计链；涉及历史/名著/官制/民俗细节的描述还需标注查证来源（原著出处/改编定式/官制结论），未查证项不得入稿。
6. 交付三件套：完整可复制提示词 + 参数串 + 参考图清单（含每张"参考什么/不参考什么"）；用户实际渠道为 MXAI 国内版时，按 `references/mxai-ui-guide.md` 输出 **中文执行版 + English reference version** 的双语 MXAI 提交卡（提示词文本 + 参考图/--iw + 尺寸按钮 + 滑杆值 + 验收操作）。
6a. **提交卡写好后，必须将中文提示词（含参数串）直接贴在对话回复中**，字体加粗或用代码块包裹，让用户可以直接复制使用。不可只写文件名让用户自己去翻文件。提示词和参数是用户实际操作的入口，必须放在对话里。
7. 用户回传成品图 → 按对应类别的 DNA 验收门逐项验收（远景巨构 A14 节 10 项验收门 / 人物 B1-B9 逐项核 / 中近景 C7 禁止项 / 素材道具 D5 禁止项）；满意图的**图片URL/任务ID** 回记到资产清单供系列复现（MXAI 代理未开放 `--seed`，复现靠同提示词+同垫图+同旋钮值，不回记 seed）。

## 西游之重铸天庭 · 权威风格定案（2026-08-26 老大确认，本项目内优先于旧档）

项目《西游之重铸天庭》全片唯一风格 = **极简的形 + 敦煌的色 + 文化的魂**（比例约 7:2:1）：

1. **形极简**：大尺度、干净几何、留白、装饰做减法；
2. **色敦煌**：石青/石绿/朱砂/赭黄/泥金矿物色**克制点睛**，单镜≤3 处点缀，金只描边不做满金；
3. **魂传统**：脊兽/斗拱/飞天/藻井/垂幡等文化元素**纪念碑化融入**，有但不密堆；建筑必写中式屋顶语法（弧形屋面轮廓+起翘檐角带脊兽，可简化不可缺）。

项目权威版四锚提示词在 `output/西游之重铸天庭/12_S7_四类风格锚_v3_敦煌天宫3D仿真人.md` §2.8（唯一生效），本项目提示词按该文件执行，与本节冲突时以该文件为准。

**元素恰当原则（老大指令，本项目内覆盖"天瀑默认必写"的旧写法）**：天瀑/瀑布/巨月等戏剧化元素**不是默认必写项**——只有镜头确实需要（水雾光源、垂直动势、纵深层次）时才写，不需要时只写缥缈云海。每个元素进提示词前自问"缺了它这个镜头不行吗"，答不上来就不加。云语法基线 = ethereal dissolving（溶解雾边 + 飘丝随风缓移），禁结实菜花云。

**项目参数**：统一 `--v 8.2 --ar 2:3 --stylize 400 --chaos 12`（抖音发布改 9:16）；**全链禁 `--raw`**（2026-08-26 实证：raw 把 CG 仿真人拉向真人摄影，是"太真人"主因）；风格锚注入 `--sref <验收图> --sw 150`，参考图只锚风格不锚身份（身份用老大交付资产图）。

**用户沟通约定**：老大不看英文——提示词交付必须"英文粘贴版 + 中文意思说明"成对给出；出图为付费动作，须老大当次授权后本人提交。

## 硬边界

- 一个画面一个主奇观（visual-dna 奇观预算），不堆巨月+圆门+神兽。
- 排除项只写 `--no`，正文不出现否定句。
- 参考图只用用户自己已验收的图或用户明确提供的合法素材；不垫第三方版权图。
- 不虚构资产事实；剧本/分镜没写的不编。
- 人物远景只做尺度锚（占画高 3–5%）；角色身份图除外。
