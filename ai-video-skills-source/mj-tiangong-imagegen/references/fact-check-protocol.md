# 考证协议（历史/神话/名著/民俗细节提示词编写前强制执行）

> 2026-08-25 建立。起因：弼马温孙悟空提示词先写"凶相+宽檐圆帽+靛蓝袍"，老大指出眼神应丑萌、帽衣无依据；查证后发现原著零服饰描写、经典改编一致=乌纱帽+大红官袍。教训：**名著/历史/官制细节不能凭印象写，必须先查证**。

## 触发条件（命中任一即强制查证，不可跳过）

1. **历史/名著人物的服饰、官服、冠帽、发型**（如弼马温官服、乌纱帽形制、唐代官服）；
2. **官职、品级、机构名称与权限**（如"弼马温是几品官"）；
3. **道具形制**（如马鞭、官印、香炉、灯笼的具体形态）；
4. **神态/行为逻辑**（如"弼马温时期悟空是凶还是得意"——查原著情节）；
5. **民俗/宗教/礼仪细节**（如祭祀、朝拜、婚礼的具体动作与器物）；
6. 任何用户**明确质疑**过的形象细节（用户说"查一下"即为指令）。

## 查证顺序（按权威性排序）

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | **原著原文** | 四大名著、史书原文。原文怎么说就是怎么回事；原文没写=原著无依据，需标注 |
| 2 | **经典改编共识** | 京剧/戏曲定式、86版西游记等权威影视、权威出版物（人民日报等）。多个来源一致=强共识 |
| 3 | **官制/典章** | 官职品级、机构设置（如"未入流""御马监"） |
| 4 | **老大指令** | 老大确认的方向/神态/元素=最高裁决，与考证冲突时以老大为准，但要说明考证结论供其知情决策 |

## 输出要求（查证结果必须落盘，形成审计链）

1. **提交卡**：新增「查证依据」段——写明原著出处、改编来源、官制结论；
2. **DNA/情绪板**：把考证结论写进对应角色/道具条目，标注"查证结论，非凭印象"；
3. **项目记忆**：关键查证结论登记当日记忆（防止下次重新踩坑）；
4. **排除项防回潮**：被作废的形象元素（如靛蓝袍+砖红披巾）必须加进 `--no`，防止模型跑回旧造型。

## 中国专有名词的平台编译规则（v4.1 实测教训 · 2026-08-25）

查证得到的正确名词**不等于 MJ 能听懂**。MJ v8.2 对中文语境专有词理解差，实测"乌纱帽"渲染成西式礼帽/高帽。规则：

1. **查证定名词，提示词写描述**：提交卡/ DNA 记录权威名词（乌纱帽），但提示词正文用**形状描述式**："中国传统黑色官帽，圆顶无帽檐黑纱质地，帽后两侧一对小巧帽翅微微上翘"；
2. **同类风险词**：官帽、幞头、进贤冠、冕旒、氅衣、补服等服饰冠帽类专有词，一律描述式（颜色+形状+材质+结构特征）；
3. **排除项防西化**：帽类加 `--no western top hat, bowler hat, fedora, cowboy hat, brimmed hat`；
4. 出图后核对：帽/冠/服饰是否跑成西式形制，跑偏即补描述+排除项，不回滚查证结论。

## 冲突裁决规则

- 老大指令 > 考证结论 > 参考图元素 > 我的印象；
- 参考图里的元素（如认可图的帽子/袍子）**不等于授权**，与考证冲突时先查证、再问老大；
- 原著没写的，按经典改编共识办，并在提交卡注明"原著无描写，按 XX 改编定式"；
- 完全查不到依据的细节，**标注"未查证/待老大裁决"，不凭印象编**。
