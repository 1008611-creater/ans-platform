# MXAI 国内版界面对接指南（2026-08-24 截图校准 / 22:10 用户确认 v8.2）

用户的实际出图渠道是 **MXAI 国内中文版**（www.mxai.cn，MJ 图生入口），不是官方 Discord/API。本文件把 `v82-parameters.md` 的权威参数翻译成 MXAI 界面操作。所有交付物从"三件套"升级为 **MXAI 提交卡**（见第 3 节），且默认提供中文执行版与 English reference version 两套提示词。

## 0. 版本前提（2026-08-24 22:10 已确认）

用户确认 MXAI 当前实际跑 **v8.2**。**收敛为 V8.2 单轨**：提示词一律用 `prompt-templates.md` 的 V8.2 自然语言五层结构；V6 关键词式写法仅作历史参考，不再用于新编译。

**v8.2 下的英文解析器风险（实测 bug）**：
- MXAI v8.2 解析器会把提示词正文中带连字符的合成词、全大写缩写误判为"未知参数"，导致整次生成失败（积分自动退回）。
- 实测触发案例：`close-up, game UI, plastic CGI` 被解析为 `~up.game / ui.plastic / cgi`，报"无法识别的参数"。
- **英文版编译必须避开**：`close-up`→`closeup`、`game UI`→`game interface`、`plastic CGI`→`plastic 3D render`；同理避免 `UHD / HDR / VFX / SFX` 等全大写缩写。
- 中文执行版不受此 bug 影响（无连字符合成词与全大写缩写），国内版优先用中文版兜底。

## 1. 界面事实清单（截图逐项）

- 入口：左侧「MJ 图生」。
- 参考图：点击/拖拽上传或图片 URL（PNG/JPG ≤10M）；配套「--iw 图片相似度」下拉。
- 文本参考（界面提示原文）：文本内可写 `~oref` 参考、`~sref` 风格一致性、`~cref` 角色一致性（**波浪号写法**）。
- 生成尺寸 --ar 按钮（截图可见集）：1:1 / 1:2 / 3:4 / 3:2。
- 高级参数：风格化等级 Stylize 滑杆（截图值 380）；多样化等级 Chaos 滑杆（截图值 7）。
- 结果操作：编辑 U1-U4（放大）、变化 V1-V4、C1-C4、视野 M1-M4。
- 成本：每次 6 积分（截图账户余 4300）。

## 2. 权威参数 → MXAI 操作映射

| 权威参数 | MXAI 操作 | 天宫默认 |
|---|---|---|
| `--v 8.2` / `6.2` | 版本选择器（待确认） | 跟用户实际可用版本 |
| `--ar 9:16`（竖版默认） | 尺寸按钮 **1:2** | 漫剧角色/场景母图 |
| `--ar 16:9` | 尺寸按钮 **3:2** | 横幅概念图 |
| `--ar 1:1` | 尺寸按钮 **1:1** | 道具档案 |
| `--stylize` | Stylize 滑杆 | 定妆 250 / 场景 380-500（截图 380 可用） |
| `--chaos` | Chaos 滑杆 | 定妆 3-5 / 场景 7-15（截图 7 可用） |
| `--iw` | 「--iw 图片相似度」下拉 | 见第 4 节 |
| `--sref <URL>` | 提示词文本写 `~sref <URL>` | 系列风格一致 |
| `--oref <URL>` | 提示词文本写 `~oref <URL>` | 角色/道具身份锁 |
| `--cref`（仅 v6） | 文本写 `~cref <URL>` | 仅当渠道确认 v6 时 |
| `--no` | 文本末尾照写 `--no ...` | 两版通用 |
| `--hd` | 界面未见；用 **U 按钮放大** 替代 | 先标准跑，验收后 U |
| `--seed` | 界面无直接入口，待确认；回记靠 ID | 满意图记任务 ID |

## 3. 交付格式：MXAI 提交卡（五段）

```markdown
### MXAI 提交卡 — 资产 <ID>：<名称>
1. **中文执行版提示词**：<国内版优先粘贴，经过安全词汇编译>
2. **English reference version**：<对应英文语义，用于核对与跨渠道迁移>
3. **参考图**：上传？哪张？--iw 下拉选 = 相似度 X%（不上传则写"无"）
4. **尺寸按钮**：1:2 / 3:2 / 1:1
5. **滑杆**：Stylize=___，Chaos=___
6. **验收操作**：四宫格先选构图 → U 放大看细节 → 构图对细节差用 V 变体 → 满意回传图+任务ID
```

## 4. --iw 相似度速查（关联度）

| 下拉档 | 相似度 | 用途 |
|---|---|---|
| 0.25 / 0.5 | 30% / 40% | 只借色调，构图自由 |
| 1 / 1.25 | 50% / 60% | **默认**：继承氛围，构图可调 |
| 1.75 | 70-80% | 同场景换机位 |
| 2 | 90% | 贴死原图做微调 |

规则：上传参考图走 --iw 时，**文本里不再同时写 ~sref**（职责二选一）；角色身份锁走文本 `~oref`，可与上传图 --iw 并存但要在卡里注明各自职责。
