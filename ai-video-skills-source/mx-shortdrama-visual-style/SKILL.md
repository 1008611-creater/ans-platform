# 转绘视觉风格路由

- 默认不启用视觉风格；基础转绘路由不自动注入风格词。
- 用户明确要求风格或任务标记需要风格时，先运行本 Skill，再进入资产、首帧、故事板或生视频节点。
- 当前第一轮生产已确认启用“现代目标地区写实短剧”试运行基调；后续新任务仍需主动询问是否启用，用户未选择时不注入。
- 风格配置必须输出为可直接拼接到提示词的短规则，只改变视觉表现，不改变原片事实、人物关系、动作、台词、道具状态、镜头时序或本土化规则。

当前试运行基调：现代目标地区写实短剧。可注入配置：真实人物；目标地区社会文化语境；自然电影光线；真实材质和空间；克制但有戏剧张力；不添加原片当前镜头没有的人物；不使用插画、动漫、游戏渲染或过度美颜效果。

反馈顺序：先看人物真实、身份稳定和目标地区身份自然度；若人物真实但整体画面不统一，先修改本 Skill 的 `prompt_injection`，不先改角色卡或首帧模板。第一轮效果良好时记录为 `v1`，用同一集另一生产组、同一目标地区和同一视觉基调验证，重点比较人物身份稳定、服装连续和目标地区气质自然；验证通过后才考虑固定或升级，不立即设为默认。验证不通过时保留 `v1`，修改为 `v1.1` 再验证，不靠每个提示词临时补词绕过本 Skill。

输出：

```text
style_id:
style_name:
prompt_injection:
preserve:
avoid:
user_decision:
```

先读取 `target_region`、`target_language_locale` 和已确认事实，再主动询问是否启用；启用后把 `prompt_injection` 放在主体事实和动作要求之后，作为独立“视觉风格”段落写入需要风格的生图或生视频提示词。第一批资产和第一段视频完成后立即收集用户的保留、删除、增强、减弱意见，并直接更新试运行基调；确认稳定前不升级为正式风格库，也不设为默认。
