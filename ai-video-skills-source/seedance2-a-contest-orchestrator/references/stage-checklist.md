# Stage Checklist

Use this checklist for award-oriented all-AI contest work:

1. Rule lock
   - lane, duration, aspect ratio, originality, and tool constraints.
2. Method lock
   - identify one proven reference workflow and define what is being borrowed.
3. World lock
   - genre, taste signal, core design language, emotional range.
4. Character lock
   - identity sheets and consistency strategy.
5. Frame lock
   - first frames for the hardest shots.
6. Shot language test
   - 3 to 5 experimental but story-relevant shots.
7. Full shot queue
   - build only after the tests validate the pipeline.
8. Assembly
   - select, trim, reorder, fill gaps.
9. Submission polish
   - credits, poster, synopsis, platform packaging if needed.
