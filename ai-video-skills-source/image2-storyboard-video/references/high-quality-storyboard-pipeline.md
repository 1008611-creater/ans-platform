# 高质量故事板四阶段流程

用于高质量故事板任务。默认适用：

- 用户要高质量故事板
- 用户要减少 AI 感
- 用户要长时间口播、多段转场、复杂一致性
- 用户已经明确“不要直接从脚本跳故事板”

## 默认顺序

1. 人物图
2. 关键信息图
3. 首帧图
4. 故事板

除非用户明确要求快速版、跳过前置资产或只要草案，否则按这个顺序工作。

## 阶段 1：人物图

目的：先锁后续会反复出现的人。

优先级：

- 先锁固定主角、固定主讲人、固定口播人
- 再锁需要跨镜头一致的关键人物
- 路人、背景群众不先做

至少锁定：

- 脸部结构
- 发型轮廓
- 服装搭配
- 手势或行为习惯
- 远景 / 中景 / 近景识别点

通过门：

- 看起来像真实人，不像 AI 偶像、不像主播、不像海报模特
- 后续可以直接进入首帧，不需要重做人设

没通过时：

- 继续打磨人物图
- 不进入信息图替代，不进入首帧，不进入故事板

## 阶段 2：关键信息图

目的：先锁“这一段到底要说明什么”，避免故事板一开始就散。

信息图不是：

- 正式故事板
- 最终视频帧
- PPT
- 扁平 infographic
- 科技大屏海报

信息图是：

- 纪实视觉关系板
- 导演前期信息锚点图
- 论点和证据之间的视觉关系草模

建议数量：

- 每个项目先做 3-5 张
- 一张图只承担一条核心逻辑

通过门：

- 一眼能看出这张图在说明什么
- 能直接反哺首帧和故事板
- 不是只是“漂亮的拼贴图”

## 阶段 3：首帧图

目的：给每个未来的视频段落先锁 true first frame。

首帧不是：

- 海报
- 故事板
- 静态成片
- 角色设定页

首帧必须锁：

- 画幅
- 构图
- 主体位置
- 空间关系
- 光线方向
- 动作起点
- 镜头运动余量

对口播项目：

- 先锁主讲人口播位首帧
- 再锁 B-roll 场景首帧

通过门：

- 看起来就是视频开始的第一帧
- 后续动作和运镜有空间继续发生

## 阶段 4：故事板

只有前 3 阶段通过，才进入正式故事板。

故事板必须继承：

- 已通过的人物图身份锚点
- 已通过的关键信息图逻辑
- 已通过的首帧图起始构图和场景锚点

不要让故事板替代前 3 阶段职责。

## 口播型项目专用规则

适用：单人长时间口播 + 多片段转场 / 插片。

顺序：

1. 先锁固定主讲人人物图
2. 再做每个论点的关键信息图
3. 再做主讲人口播位和关键 B-roll 的首帧图
4. 最后做正式故事板

故事板里的分工：

- 主讲人镜头是主线
- B-roll 只负责解释、证明和转场
- 不让 B-roll 另起一条叙事线抢走主线

## 失败回退

如果故事板看起来散、假、AI 感重，优先这样回退：

- 主体不稳：回退人物图
- 信息混乱：回退关键信息图
- 起始画面不对：回退首帧图
- 板面结构缺失：回退故事板提示词本身
