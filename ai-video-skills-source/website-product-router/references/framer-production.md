# Framer Production

Use Framer when the user needs a polished public site quickly, values visual editing, and does not require deep app logic.

## Required Artifacts

- Framer project/page URL or exported handoff notes.
- Page inventory and primary conversion.
- Form destination or booking/contact target.
- SEO title, description, canonical, and OG image plan.
- Desktop and mobile screenshots.

## Verification

- Open published or preview URL.
- Check desktop and mobile first viewport.
- Check navigation, forms/CTA targets, and external links.
- Check SEO/social fields are present when launch is requested.
- Record analytics plan or verified tracking status.

## Do Not Use Framer When

- Auth, database, API workflows, complex state, or source-code ownership are required.
- The user needs repo-native components, tests, or custom deployment pipeline.
