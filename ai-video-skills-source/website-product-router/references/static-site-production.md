# Static Site Production

Use static site route for simple public sites with low interactivity and low operational burden.

## Good Fits

- Portfolio, brochure, docs, event page, campaign page.
- Plain HTML/CSS/JS, Astro, Vite static export, 11ty, GitHub Pages, Cloudflare Pages, Vercel static.

## Required Checks

- Assets use stable relative paths or configured base path.
- Mobile layout and text wrapping verified.
- SEO title/description and social image plan.
- Forms either use a verified external endpoint or are marked not done.
- No broken internal links.

## Verification

- Open locally or serve with a lightweight static server when needed.
- Capture desktop/mobile screenshots.
- Check console errors and missing assets.
