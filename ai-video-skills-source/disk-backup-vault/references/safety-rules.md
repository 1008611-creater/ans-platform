# 安全规则（备份优先于清理）

本 Skill 的最高优先级是**不造成数据损失**。任何清理意图都必须让位于备份完整性。

## 1. 只读原则

- 所有写操作发生在备份根（目标盘），源盘只读。
- 禁止对源盘执行 `rm` / `del` / `move`（移动本质是先拷后删，也不允许）。
- 复制失败（权限、文件锁定）只跳过，不重试到破坏源。

## 2. 备份优先于清理（关键时序）

正确顺序：
```
备份 → 校验可读 → 用户确认冗余 → 单目录删除确认 → 删除
```

错误顺序（禁止）：
```
清理腾空间 → 想起来要备份 → 已删
```

一旦用户表达过“先备份”，即使后续提到清理，也必须先完成备份全流程。

## 3. 删除的逐项目确认

即使用户说“备份完可以删”，也要：
- 逐项列出已备份且暂不用的目录
- 每个目录单独确认，不批量删除
- 删除前再次确认备份库该目录存在且可读

## 4. 运行中的系统保护

以下默认不碰，除非用户明确、单独授权：
- WSL 发行版（`wsl -l -v` 显示 Running 的不动）
- 页面文件、休眠文件
- 正在运行程序的数据目录
- 杀毒/安全软件数据

## 5. 失败与中断处理

- 复制中断：重新跑同一 `robocopy`（自带增量，已拷的不重复），不从头清源。
- 空间不足：停止并报告，不擅自删除源盘内容凑空间。
- 锁定文件：记录跳过列表，整体任务不失败。

## 6. 备份库自身安全

- 备份根不放回源盘同一物理磁盘（否则磁盘坏=全没）。
- 备份根不在系统盘（C:）内。
- 重要备份库额外上传网盘或移动硬盘做异地冗余。
