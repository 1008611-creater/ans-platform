# ANS (AI Never Stops) 前端、文案与 UI/UX 最低交付基线

本 Skill 将 `oil-ui`、`oil-frontend`、`ui-ux-guide`、`oil-tone` 四套开源实战规范与 ANS 真实产品红线融合成不可退让的**最低交付水准**。

---

## 核心五条铁律（The 5 Non-Negotiable Laws）

### 1. 零虚构状态伪装铁律（Real User State vs. Honest Onboarding Guide）
- **严禁伪造实时动态**：严禁在任何页面渲染假实时中奖播报、假在线人数、假社区评价分、假 SHA-256 哈希或预填在用户个人名下的假任务/假订单。
- **预设内容诚实归位**：所有为了帮助同学快速看懂效果而准备的预设内容，必须诚实归位为高质量、零 AI 味的 **「📖 新手引导 / 参考范例 / 模板」**（默认按需展开或与个人真实记录严格分栏隔离），而用户的余额、项目、任务、订单必须 100% 反映真实状态。

### 2. 解释性小字分层与「悬停才显示」铁律（L0–L3 Help Text Layering）
对齐 `ui-ux-guide` **UX Hard Rule #9**：
- **L0（不写）**：按钮、图标、布局已经能自解释的操作，**严禁再写解释性小字**（禁止出现 `（点击展开）`、`（拖拽旋转 360°）`、`在左侧输入…右侧实时预览` 等说明书式废话）。
- **L1（单行常驻）**：仅限扣费、不可逆删除、未登录限制等关键边界，用 `≤ 1 行` 极简短句说明。
- **L2（鼠标移上去才显示 / Hover-to-Reveal）**：补充说明、次要参数（如模型面数、段位规则、交付物细项、任务提示、奖励数值明细）默认隐藏，**仅在鼠标移上去（`group-hover` / `title` / `?` 悬浮气泡）时显示**。
- **L3（抽屉/折叠详情）**：长篇规则、概率明细、Sample 样本全文一律收进 `<details>` 或按需弹窗。

### 3. 图文不重复、同页不复读铁律（Image-First & Zero Redundancy）
对齐 `oil-ui`（`references/media.md` & `references/visual-language.md`）与 `oil-frontend`（`references/collection-and-detail-contract.md`）：
- **能用图表示就用图，图里有就不加文案**：卡片已有 16:9 视觉封面或 3D 实时舞台时，只保留标题、核心指标与唯一主按钮；次要描述一律隐藏或悬停展示。
- **同页不复读**：同一条规则（如积分汇率 `10 积分 = ¥1 元`、用户昵称与余额、同一组项目推荐）在同一页面只准在主位置出现一次，严禁在页头、横幅、卡片、页脚重复堆砌。
- **单卡单主动作**：同一张卡片严禁同时放两个跳转同一目标的按钮/链接。

### 4. 零 AI 腔、零自嗨黑话、统一纯净命名铁律（`oil-tone` Clean Copy）
- **禁用词黑名单**：严禁出现 `赋能`、`矩阵`、`闭环`、`底座`、`心智`、`四段式`、`主理人`、`赛博圣殿`、`算力金库`、`欧皇`、`天选锦鲤`、`暴击`、`正态分布` 等 AI 味或博彩/中二词汇。
- **统一纯净命名**：
  - 官方品牌全称唯一锁定为 **`ANS (AI Never Stops)`**。
  - 站内智能体统一称为 **`Agent`**（严禁在任何用户可见界面出现内部代号 `Pi Agent`、`Pi-Agent`、`Pi-Codex`、`Pi 工具`）。
  - 工作台与代码/网页生成模式统一称为 **`工作模式`**（对话窗与工作台顶部模式切换保持 1:1 语义对齐：`🤖 Agent 对话` ⇄ `🛠️ 工作模式`）。

### 5. 两轮「无上下文 + 对抗式 Subagent」强制审查门禁
每次完成页面或交互重构后，必须通过两轮独立审查方可上线：
1. **Round 1（全量对抗式挑刺）**：启动零上下文 Subagent 扫描虚构数据残留、AI 味词汇、重复文案与交互死角。
2. **Round 2（回归与契约复核）**：核对单元测试断言、锁定文件哈希、移动端/桌面端布局呼吸感与全路由 `HTTP 200`。
