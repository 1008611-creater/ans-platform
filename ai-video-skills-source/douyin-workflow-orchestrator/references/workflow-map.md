# Douyin Workflow Map

## Phase Outputs

| Phase | Skill | Input | Output |
| --- | --- | --- | --- |
| Select | douyin-video-selection | raw videos, links, notes, product goal | ranked shortlist and chosen angle |
| Produce | douyin-video-production | chosen angle, footage, constraints | edit brief, shot list, subtitle plan, export checklist |
| Package | douyin-caption-cover | final/near-final video, audience, offer | titles, caption, hashtags, cover plan |
| Publish | douyin-publish-operator | video path, package, account state | prepared upload page and final confirmation request |

## Session Brief Rules

Keep the brief compact and update it after each phase. Mark unknowns as `待确认` rather than inventing them.

Use these status words:

- `待用户提供`: blocked on user material or decision.
- `可执行`: enough context exists to proceed.
- `已完成`: phase output is ready.
- `需复核`: contains platform-sensitive, compliance-sensitive, or account-impacting action.

## Final Review Checklist

- Video file path and upload success are confirmed.
- Caption, title, tags, and cover match the same promise.
- No claim is stronger than what the video can support.
- Account-impacting actions are held for user confirmation.
- The final response states what is ready and what remains for the user.
