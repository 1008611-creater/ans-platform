# Cloned reference repositories

All repositories are shallow clones under `references/repos` and are for local inspection.

| Directory | Upstream | Primary use |
|---|---|---|
| `web2api` | https://github.com/Endogen/web2api | Playwright browser pool and website-to-API recipe layer |
| `desafio-01` | https://github.com/FaBrCh/desafio-01 | FastAPI authentication, isolated Playwright context, Docker RPA pattern |
| `sample-browser-order-automation-agentcore` | https://github.com/aws-samples/sample-browser-order-automation-agentcore | Async queue, progress, worker orchestration, object storage architecture |
| `editapi` | https://github.com/iminoaru/editapi | Uploads, Postgres job persistence, video processing and output states |
| `ChromaFFmpeg` | https://github.com/leksautomate/ChromaFFmpeg | `X-API-Key`, media upload and persistent output URL patterns |

Refresh with `scripts/sync_repos.ps1`. Inspect changes before using updated code.
