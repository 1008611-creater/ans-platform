# ANS (`AI Never Stops`) 手绘水彩动画复利管线 (`ans-p5-brush-cartoon-animation` · V4.6 定稿版)

> [!IMPORTANT]
> **核心定位与品牌铁律**：
> - **`ANS` 的唯一官方全称是 `AI Never Stops`**（严禁误写为 `AI Native Society` 或 `AI Native Studio`）。
> - 本 Skill 基于开源仓库 **`JohnHeibel/ClaudeAnimationBase`**（`p5.js` WebGL 水彩手绘 + `p5.brush` 样条墨线 + 2D 高清文字叠加层 + Puppeteer 确定性帧步进渲染器），将主角内化为 **ANS 翡翠绿呆萌小恐龙（`dino`）** 与 **主理人独立开发者「我」（`creator`）**。
> - **视觉质量门禁**：任何新分镜或角色动作修改后，必须先用 `--loop=ans_sheet` 或 `--stills=...` 导出关键帧静帧图交由用户肉眼确认，确认通过后再执行全片 MP4 渲染。

## 一、 双主角 V4.6 定稿造型规范与防翻车铁律（`src/ans_chars.js`）

### 1. ANS 小恐龙 `dino(x, y, u, o)` —— V4.6 宽胖圆滚站立 + 短粗弧度小胖腿

#### 历史踩坑与核心审美红线（严禁回退）
- ❌ **严禁「头小肚子大」的梨形比例**：小头大肚会让萌系吉祥物显得臃肿畸形。必须保持 **大脑门与饱满婴儿肥脸颊（`rx = 4.88u`）宽度大于等于身体宽度（`rx = 4.82u`）**。
- ❌ **严禁「腿太长、身体太窄、偏瘦」**：不能画成细长豆芽菜或长裤腿。必须采用 V4.6 的 **横向加宽胖团子比例（宽高比接近 `1:1`）**，并将内侧裆部弧线压低至 `-1.12u`，露出 **短粗圆润、外侧带小鸡腿弧度的小胖短腿**。
- ❌ **严禁头顶 3 个凸起底部封口画黑线**：必须使用 `arcContourPts` 仅绘制顶部开放圆弧（`-0.94π` 至 `-0.06π`），让凸起与额头水彩底色 100% 无缝融为一体。
- ❌ **严禁手臂与肩膀交界处画黑圈、严禁尾巴位置过高与手臂打架**：手臂根部必须开放式无描边融入肩部（`x = ±4.38u, y = -4.55u`），上翘小尾巴必须固定在低位胯部（`y = -2.48u` 至 `-1.02u`）。

#### V4.6 关键几何参数（`curvyStandingDinoPts`）
| 部位 | 局部坐标（以脚底中心为 `0, 0`，单位 `u`） | 设计要点 |
| :--- | :--- | :--- |
| **大圆头顶与婴儿肥脸颊** | 头顶 `(0, -10.35u)`，脸颊 `(±4.86u..-4.88u, -7.45u..-6.05u)` | 饱满宽圆的大脑门与脸颊，奠定 Q 萌团子比例 |
| **宽厚圆滚身体** | `(±4.82u..±4.72u, -4.65u..-3.28u)` | 与脸颊等宽自然过渡，呈现胖乎乎的团子体积感 |
| **短粗弧度小胖腿与圆脚掌** | 外侧大腿弧线 `(±4.22u, -2.18u) -> (±3.48u, -1.35u)`，低脚踝微收 `(±2.68u, -0.82u)`，宽圆脚掌 `(±2.95u..±0.96u, 0.06u)`，裆部内拱 `(0, -1.12u)` | 整体单条连续样条曲线（`curv: 0.58`）一气呵成，短腿 Q 弹有弧度 |
| **奶白下脸颊贴片 & 圆肚皮** | 下脸颊 `ellPts(0, -6.32u, 3.68u, 1.24u)`；圆肚皮 `ellPts(0, -3.05u, 3.08u, 1.62u)` | 还原 `public/mascot/ans-mascot.png` 的标志性双奶白分区与底部立体暗部月牙 |

### 2. 主理人 / 「我」 `creator(x, y, u, o)` —— V4.6 青年神韵 + 多彩花冠 + 双梁中空黑框眼镜 + `ANS` 白T恤

#### 历史踩坑与核心审美红线（严禁回退）
- ❌ **严禁画成扁宽大饼脸**：必须使用 `creatorFacePts` 勾勒 **上宽下收的干净青年下颌线与微尖圆润下巴（`y = -5.28u`）**，还原站内真实照片 `public/catalog/resume-live.jpg`（`About LIU`）的年轻神韵。
- ❌ **严禁在鼻头正中画紫色圆球贴纸**：小尺寸下鼻头圆球会像小丑紫鼻头。鼻部使用干净利落的高鼻梁折线，趣味贴纸仅作为右脸颊的小巧蓝色五角星点缀（`x = 2.38u, y = -6.85u`）。
- ❌ **严禁头顶花朵同质化全白、严禁内部画车轮辐射黑线、严禁两侧伸出水平绿叶片像戴绿帽子**：
  - 使用 `distinctFlowerPts`（花谷深裂至 `0.42 * r` 的饱满圆弧花瓣，无内部杂线）；
  - 4 朵主花错落排布、色彩鲜明且互不遮挡：**左上珊瑚粉五瓣牡丹（`#FF7096` + 浅粉内晕 + 暖金花蕊）**、**正顶明黄六瓣万寿菊（`#FFC72C` + 珊瑚红花心）**、**右上天蓝四瓣绣球（`#5CB8FF` + 奶白花蕊）**、**最右薰衣草紫五瓣小花（`#C084FC` + 金色花蕊）**；
  - 叶片向上斜插在花朵后方，绝不向左右水平伸出成帽檐状。
- ❌ **严禁刘海遮挡眼镜双横梁中空结构**：
  - 眼镜必须采用 **上宽下收的潮流大黑框造型**，正中清晰画出 **上方眉梁横杠（`gy - 0.72u`）与下方鼻梁横杠（`gy - 0.06u`），两道横杠之间留出清晰的肤色镂空窗口（`中间两个横杠，上面还有一个，中间中空`）**；
  - 黑发采用微中分自然碎刘海，正中分缝上拱至 `-9.42u`，确保双横梁中空 100% 清晰显露。
- ✅ **白色圆领 T 恤胸前必须清晰印有 `ANS`**：
  - 在白色短袖圆领 T 恤（`-5.68u` 至 `-2.13u`）正胸前，用 `inkLine` 绘制字距舒展、笔触醒目的 **`A  N  S`**（中心分别位于 `lx - 1.22u`、`lx`、`lx + 1.22u`），下方衬托一条薄荷绿横条（`#9BE0C5`）。

## 三、 跨电脑一键启动与复利工作流命令

在新电脑拉取仓库或解压便携包后，进入 `ClaudeAnimationBase/` 目录即可一键执行：

```bash
# 1. 安装依赖（若已包含 node_modules 可跳过）
npm install

# 2. 一键渲染双主角 6 态设定图（约 4 秒，用于检查角色造型微调）
node render.mjs --loop=ans_sheet --sheet=0.4 --cols=1 --w=1280 --out=out/check/ans_chars_sheet.jpg

# 3. 一键渲染 5 幕核心关键帧静帧图（约 10 秒，用于先出样片肉眼确认质量）
node render.mjs --stills=1.8,4.6,7.6,10.5,13.6 --out=out/ans_day01_stills

# 4. 关键帧确认通过后，一键渲染 720p · 24fps 完整 15 秒 MP4 视频
node render.mjs --out=out/ans_day01_720p.mp4
```

### 扩展 Day 02 ～ Day 28 新视频的标准 3 步复利法
1. **直接复用 `src/ans_chars.js`**：在任何新场景中直接调用 `dino(x, y, u, { eyes, mouth, aL, aR, walk, sq, emote })` 与 `creator(x, y, u, { eyes, mouth, aL, aR, walk, sq, emote })`，无需重新画人设。
2. **新建场景文件 `src/scenes/ans_dayXX.js`**：复制 `src/scenes/ans_day01.js` 的 5 幕脚手架（自带暖白水彩墙面、彩灯串、木地板、顶部深色横幅与底部章节字幕条 `drawSubtitleBar`），仅替换中间的场景道具与文案。
3. **先跑 `--stills` 过审美门禁，再跑全片 MP4**：严格遵循「先出样片审美确认、后上线」铁律。
