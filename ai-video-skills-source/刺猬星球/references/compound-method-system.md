# 刺猬星球复利方法系统

> 定位：将单篇知识卡编译为可调用的方法节点。本文是整理者建立的系统层，不是刺猬星球课程原文。

## 一、统一方法节点

每条可复用方法都必须写成：

```text
问题信号
→ 决策门
→ 输入契约
→ 方法动作
→ 固定变量
→ 可变变量
→ 中间产物
→ 输出契约
→ 验收门
→ 失败回退
→ ANS证据
```

### 字段定义

- **问题信号**：从画面、声音、动作、连续性或客户目标中观察到的具体失败表现。
- **决策门**：判断本节点是否适用，以及为什么不先调用其他节点。
- **输入契约**：人物、场景、道具、参考视频、脚本、时间轴、声音或授权等前置事实。
- **方法动作**：本节点真正改变的创作或制作动作。
- **固定变量**：实验期间不应改变的身份、产品、脚本、版本、比例或验收目标。
- **可变变量**：本轮只改变的一个方法变量，例如镜头角度、条件图、动作顺序或风格版。
- **中间产物**：资产表、镜头表、首尾状态、提示词、声音表、对照样片等。
- **输出契约**：下游节点可以直接消费的字段和文件。
- **验收门**：可从文件、画面、声音或回执中检查的通过条件。
- **失败回退**：失败时只回到最早缺口，不让下游猜测补上游事实。
- **ANS证据**：可公开展示的输入、过程、输出、验收记录和客户反馈；没有真实回执只能标待验证。

## 二、主链调用图

```text
HWC-065 / HWC-067：人物与资产身份
             ↓
HWC-066 / HWC-026：画面目的与构图
             ↓
HWC-079：人物—环境—行为因果
             ↓
HWC-070：全局设定—单镜头指令—首尾衔接
             ↓
HWC-074 / HWC-A16 / HWC-A21：品牌片、产品变化、统一风格资产
             ↓
HWC-075：当空间、表面或形状需要额外结构控制时选择条件图
             ↓
HWC-076：开场关系与首尾状态
             ↓
HWC-078 / HWC-048：画面时间轴、BGM、音效与角色声音
```

案例卡 `a1–a21` 默认处于“证据库”层，不自动成为主链硬节点。只有经过对照实验并达到迁移门，才可升级为方法节点。

## 三、跨卡调用决策树

### 1. 人物身份或资产不稳

- 信号：脸型、服装、发型、道具或场景在镜头间漂移。
- 先调用：HWC-065 / HWC-067。
- 必须产出：人物母图、状态资产、道具资产、场景布局和调用标注。
- 不要先做：镜头炫技、复杂动作或声音设计。

### 2. 画面好看但不知道在表达什么

- 信号：主体、视线、视觉动线和画面重点不明确。
- 先调用：HWC-066 / HWC-026。
- 必须产出：画面目的、主体关系、景别/机位选择理由和构图验收项。

### 3. 人物像摆拍或动作机械

- 信号：人物只是站着、笑着或执行无因果动作；道具只是装饰。
- 先调用：HWC-079。
- 必须产出：人物身份、所在环境、动作触发、执行、结果和下一状态。

### 4. 多镜头无法接起来

- 信号：上一镜结束状态与下一镜开始状态不一致。
- 先调用：HWC-070，必要时交叉 HWC-076。
- 必须产出：全局保持项、单镜头开始—发生—停点、首尾衔接表。

### 5. 空间、表面或形状结构失控

- 信号：布局、深度、轮廓或材质不稳定。
- 决策：先判断文字和普通参考是否已经足够；只有结构信息确实缺失时，再调用 HWC-075 或 a16。
- 必须产出：控制目标、条件图职责、对照版本和限制边界。

### 6. 品牌片缺少可见卖点或统一质感

- 信号：产品功能没有转成画面变化，或各段视觉质感断裂。
- 先调用：HWC-074 / HWC-A21；汽车TVC等结构控制案例可参考 a16。
- 必须产出：产品功能—可见变化—视觉线索—镜头路线—统一风格资产。

### 7. 开场没有抓住注意力或首尾断裂

- 信号：普通开场、特效堆叠、结尾无法承接。
- 先调用：HWC-076。
- 必须产出：开始状态、唯一核心关系变化、稳定元素、最终状态。

### 8. 画面完成但声音像后贴上去

- 信号：BGM抢动作、音效不在时间点、对白没有角色状态。
- 先调用：HWC-078；角色声音问题再调用 HWC-048。
- 必须产出：时间地图、BGM、Foley/Transition/Hit/Sound Design/Drone清单、试听验收。

## 四、最小实验协议

任何整理者推导在升级为“可复利规则”前，至少执行一次单变量对照；涉及跨模型迁移时，至少需要两个任务或两个模型的结果。

### 实验记录字段

| 字段 | 内容 |
|---|---|
| 实验编号 | 例如 EXP-CW-001 |
| 目的 | 要验证哪个判断 |
| 输入版本 | 资产、脚本、参考、提示词版本 |
| 固定变量 | 不允许改变的条件 |
| 单一可变变量 | 本轮只改变什么 |
| 对照组 | 不使用该方法的版本 |
| 实验组 | 使用该方法的版本 |
| 模型/版本/日期 | 真实回执，不从文章猜 |
| 输出文件 | 候选片段、截图、音频或日志 |
| 验收指标 | 可见/可听、可复核 |
| 失败变量 | 最早失败的节点 |
| 结论 | 仅限本实验范围 |
| 迁移等级 | 不可迁移 / 单案例 / 待复核 / 初步可迁移 |

### 最小指标示例

- 人物：身份特征保持项中，抽检多少项仍成立。
- 镜头：开始—发生—停点是否可复述；运动是否服务画面目的。
- 行为：是否存在触发—执行—结果；道具状态是否改变。
- 连续性：相邻镜头首尾状态是否匹配。
- 声音：对白、动作音和BGM是否在目标时间点进入或退出。
- 商业片：产品功能是否能从画面中被指出，而不是只靠旁白解释。

每个已验证节点必须留下真实回执；没有回执只能是“待验证方法”。

| 类别 | 验收项 | 通过标准 | 证据文件 | 状态 | 最早失败变量 | 复核日期 |
|---|---|---|---|---|---|---|
| 资产 | 人物/道具/场景身份 | 关键保持项成立 | 资产图/资产表 | 待验收 |  |  |
| 镜头 | 画面目的与机位 | 机位能解释画面目的 | 镜头表/候选片段 | 待验收 |  |  |
| 表演 | 动作因果 | 有触发、执行、结果 | 候选片段 | 待验收 |  |  |
| 连续性 | 首尾状态 | 相邻镜头可承接 | 连续性表/片段 | 待验收 |  |  |
| 声音 | 时间对齐 | BGM/音效/对白不互相遮蔽 | 音频版本 | 待验收 |  |  |
| 授权 | 素材/品牌/人物 | 有使用边界与记录 | 授权说明 | 待确认 |  |  |
| 商业 | 客户可见结果 | 有输入、输出和客户反馈 | 交付回执 | 待验证 |  |  |

## 六、ANS应用包模板

```text
【客户问题】客户看到了什么失败表现？
【调用顺序】先调用哪张卡，为什么；后续卡如何接手。
【输入清单】客户素材、品牌目标、授权、参考、脚本、比例和输出要求。
【过程产物】资产表、镜头表、提示词、候选片段、声音表、验收台账。
【最小交付】一条可回看样片或一套可复用模板；不承诺超出证据范围的效果。
【验收标准】客户可以从画面/声音/文件中逐项确认的指标。
【失败回退】最早失败变量和返工范围，不默认全量重做。
【证据包】输入、过程、输出、版本、平台、日期、验收和客户反馈。
【公开内容】去敏后的前后对比、方法拆解或案例；不泄露客户私密信息。
【不承诺】未实测模型能力、未确认版权/授权、未核验参数和成功率。
```

## 七、升级规则

- “卡片写完”不等于“方法成立”。
- “一次成功”不等于“可迁移”。
- “两个相似案例”仍不等于“跨模型通用”。
- 只有来源证据、对照实验、真实回执和验收台账同时具备，才可把状态升级为“初步可迁移”。
- 新增文章默认进入证据库层；主链只接收经过审计的节点。
