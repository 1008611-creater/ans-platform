# Chinese Commerce Script

Use this before writing Chinese short-video口播, subtitles, cover text, and live-commerce lines.

## Spoken Test

Every line must pass this test:

> Could a fruit seller, shop owner, or主播 say this while doing the action on camera?

If the answer is no, rewrite it. Do not put strategy language into the script.

## Hard Rules

- Use short spoken clauses. Prefer 6-14 Chinese characters per breath.
- The first 1-3 seconds must be a filmed event with the product visible or being handled, not a topic sentence.
- Give the speaker a stance, doubt, identity, or reason to film now. A script with no speaker position usually sounds translated.
- Put an action in the sentence: 剥、掰、挑、装、称、拍、看、尝、寄、拿掉.
- Use viewer-facing words: 你看、先别、最怕、这一颗、这一批、想看、我给你.
- Let the product proof carry the claim. Say "皮一掰，水就挂手上" instead of "汁水充足".
- Attach every selling point to a scene. Do not list features that are not visible in the shot.
- Use one idea per line. Split long logic into two spoken lines.
- Use platform-native light CTA: "想看打包我拍给你", "评论区说一声", "要哪种规格我给你拍".

## Forbidden Analysis Voice

Never write these as口播:

- "这盒才成立"
- "这套逻辑成立"
- "核心不是..."
- "商业主张是..."
- "降低用户怀疑"
- "建立信任感"
- "证明履约能力"
- "完成成交收口"
- "这口要的是..."
- "产品价值在于..."

These can appear in planning notes, never in the spoken script.

## Fruit Commerce Patterns

**First 3 seconds**

```text
先别下单，我剥一颗给你看。
买荔枝礼盒，别先看盒子，先看果。
这一颗剥开，你就知道水分够不够。
```

**Buyer doubt**

```text
礼盒最怕外面挺体面，里面一口干。
别只看包装，里面的果才要紧。
送人最怕什么？盒子好看，果不好吃。
```

**Proof**

```text
你看，皮一掰，水就挂手上。
这颗不是最大，但水分很稳。
果肉要亮，不能发暗。
软的、压伤的、有裂口的，我们都拿掉。
```

**Gift close**

```text
送人看盒子，吃的人看这一口。
想要这一批，我按这个标准给你挑。
要看打包，评论区说一声，我拍给你。
```

## 30-Second Fruit Script Template

```text
0-3s:
<一句动作钩子，最好带“先别/我剥/你看”>

3-6s:
<一句买家最怕的问题>

6-12s:
<镜头能看到的第一条证据>

12-18s:
<分拣/装箱/挑坏果证据>

18-24s:
<送礼/自吃场景，但别说空话>

24-30s:
<轻 CTA，让用户评论、看打包、问规格>
```

## Cover Text

Keep cover text short:

- 先剥一颗
- 水挂手上
- 装前再挑
- 送人不虚
- 今天这批

Avoid:

- 高端品质
- 源头直发
- 匠心甄选
- 爆汁鲜甜到停不下来
- 礼盒才成立
