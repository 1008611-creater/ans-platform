# 知识卡质量审计

逐项回答并保留证据：

- [ ] 输入清单覆盖全部文档、截图、图片、视频和附件。
- [ ] 用户明确排除项已排除并写明原因。
- [ ] 每张卡有来源链接、标题、修改时间和实际读取范围。
- [ ] 课程原文、操作方法、案例/示例、整理者推导分开。
- [ ] 每条关键结论有原文依据或明确标记待补。
- [ ] 搜索摘要没有冒充完整正文。
- [ ] 图片、视频、附件缺口已记录。
- [ ] 模型、平台、参数、成本、成功率和版本结论没有未经核验地泛化。
- [ ] 案例品牌、人物和单次效果没有升级为通用规则。
- [ ] 每条复利规则有适用条件、不适用边界和最小验证。
- [ ] 模板使用占位符，没有把案例参数写成固定答案。
- [ ] 验收清单能从提示词、文件或画面中验证，不只写抽象形容词。
- [ ] ANS应用判断与课程事实分开。
- [ ] 编号稳定，待定位项没有被后续文档占用。
- [ ] 重复规则已交叉引用，没有制造平行事实。
- [ ] 未修改飞书原文，未公开发布或产生外部费用。

## 置信度

- 高：主要正文和关键媒体均核验，来源完整。
- 中：正文可见范围充分，但部分媒体/附件待补。
- 低：主要依赖截图、摘要、搜索结果或局部片段。
