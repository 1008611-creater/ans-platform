# 对话蒸馏 Skill — 从对话记录中提取、分类、保存提示词

## 女娲式六维并行蒸馏

受 `mini-tiangong-drama` 女娲式蒸馏启发，将对话中的提示词资产按六个维度并行提取：

| 维度 | 提取内容 | 存到分类 |
|---|---|---|
| **视频提示词** | Seedance 2.5 / 其他 AI 视频的完整提示词 | `seedance-2-5` 或 `ai-video` |
| **图片提示词** | AI 图片生成的提示词、参数、风格描述 | `ai-image` |
| **模板结构** | 可复用的提示词模板、变量占位符、适配规则 | `prompt-templates` |
| **工作流模式** | 代码、脚本、脚本片段、工作流程 | `general-work` |
| **效果备注** | 提示词的使用效果、评分、优化建议 | 附在提示词的 description 中 |
| **经验教训** | 什么有效、什么无效、踩坑记录 | `general-work` |

## 触发条件

当用户说以下任意一句话时触发：
- "把对话里的提示词提取出来"
- "蒸馏一下今天的对话"
- "存一下这段时间用过的提示词"
- "把刚才的提示词整理一下存起来"
- "女娲蒸馏"
- 或者类似意图

## 工作流程

### Phase 1：扫描对话，标注可提取的提示词

逐段分析当前对话，找出所有包含以下特征的内容：

1. **完整提示词** — 提供给 AI 模型（Dola / Seedance / ChatGPT 等）的完整提示词文本
2. **提示词模板** — 包含变量占位符（如 `{topic}`、`{style}`）的结构化模板
3. **效果评价** — 对提示词使用效果的描述（"效果很好"、"跑出来不对"、"评分 S+"）
4. **优化建议** — 对提示词的具体改进方向

对每个候选内容，标注：
- 标题（从内容提炼）
- 完整内容
- 描述（用途、效果、注意事项）
- 类型（VIDEO / STRUCTURED / TEXT）
- 分类（seedance-2-5 / ai-video / ai-image / general-work / prompt-templates）

### Phase 2：分类决策树

```
提示词内容 → 是否包含 Seedance 2.5 特定参数（fps、时长、运镜、国风等）?
  ├─ 是 → seedance-2-5
  └─ 否 → 是否包含 AI 视频生成参数（运镜、转场、音效、节奏等）?
       ├─ 是 → ai-video
       └─ 否 → 是否包含图片生成参数（光线、构图、风格、色彩等）?
            ├─ 是 → ai-image
            └─ 否 → 是否包含模板变量（{xxx}、[xxx]、占位符）?
                 ├─ 是 → prompt-templates
                 └─ 否 → general-work
```

### Phase 3：标注使用场景

对每条提取的提示词，标注明确的使用场景说明：
- **什么时候用**：这个提示词适合什么画面、什么工具、什么需求
- **什么效果**：用了之后大概出什么效果
- **选它不选别的的原因**：同分类下多条提示词，什么场景该选哪条

格式示例：
```
使用场景：当你要拍天宫大殿内部，人物极小、突出建筑巨构感时用。效果：庄严压迫的巨殿比例揭示。
```

### Phase 4：保存到提示词库

对每条提取的提示词，调用 `save_prompt` 工具保存：
- `title`：提炼的标题
- `content`：完整提示词内容
- `type`：VIDEO / STRUCTURED / TEXT
- `description`：用途、效果、注意事项
- `category_slug`：分类决策树结果

### Phase 4：验证

保存后搜索确认已入库，向用户报告结果。

## 脚本辅助

当对话记录较多或需要批量处理时，使用以下脚本：

```bash
python "C:/Users/lsb/.workbuddy/skills/prompt-vault/scripts/save_prompt.py" \
  --title "提示词标题" \
  --content "提示词内容" \
  --type VIDEO \
  --description "用途和效果备注" \
  --category seedance-2-5
```

## 外部源蒸馏（别人分享的高质量提示词）

### 支持的来源

| 来源 | 输入方式 | 处理方法 |
|---|---|---|
| **网页链接** | 粘贴 URL | 抓取页面内容，提取提示词 |
| **GitHub 仓库** | 粘贴仓库链接 | 读取 README、prompts.csv、.md 文件 |
| **纯文本** | 粘贴文本 | 直接分析提取 |
| **截图/图片** | 上传图片 | 提取文字后分析（需 OCR 能力） |
| **社交媒体** | 粘贴帖子链接/内容 | 提取正文中的提示词 |
| **PDF/文档** | 上传文件 | 读取后提取 |

### 触发词

- "把这篇[链接]里的提示词提取出来"
- "这个 GitHub 项目里的提示词帮我存一下"
- "别人分享的这段提示词帮我存到库里"
- "把这个网页里的提示词蒸馏进来"
- "导入这个仓库的提示词"

### 工作流程

#### Phase 1：获取内容

根据来源类型获取原始内容：
- **URL** → WebFetch 抓取页面，提取正文
- **GitHub** → 读取仓库的 prompts.csv、README、prompts 目录下的 .md 文件
- **文本** → 直接使用
- **图片** → 读取图片，提取文字

#### Phase 2：AI 识别与提取

对原始内容执行以下分析：

1. **识别提示词边界** — 区分提示词正文、说明文字、示例代码
2. **提取元数据** — 标题、用途、适用模型、预期效果
3. **质量评估** — 判断是否值得入库（排除过于简单、过时、不完整的提示词）
4. **分类决策** — 按分类决策树自动分到对应分类

#### Phase 3：批量保存

对每条提取的提示词执行：
1. 去重（检查标题或内容是否已存在）
2. 调用 `save_prompt` 保存
3. 记录来源（在 description 中标注来源 URL）

#### Phase 4：报告

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  外部源蒸馏报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  来源: https://github.com/xxx/awesome-prompts
  共提取: 12 条提示词
  已去重: 3 条已存在，跳过
  新增: 9 条
  ─────────────────────────
  Seedance 2.5:   2 条
  AI 视频:        3 条
  AI 图片:        2 条
  提示词模板:     1 条
  日常工作:       1 条
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
