# Usage：原文逐条对照与自查清单

## 用户原文（权威，逐条执行）

### 聊天界面 6 条
1. 中文输入法还在选字时（isComposing 或 keyCode 229），按回车不发送；选字结束后 500ms 内的回车也拦掉。
2. 离底部 40px 以内才自动跟随新消息；用户一滚动就停止跟随；离底部超过 120px 时显示「跳至最新」按钮。
3. 边框只套一层：容器里的按钮不加边框，鼠标悬停时变底色；描边改用 inset box-shadow，避免布局抖动。
4. 外圆角 = 内圆角 + 内边距。
5. 拖动分栏时给右侧预览盖一层透明遮罩；按 Esc 恢复原来的比例，双击回到 50/50，左栏超过 82% 时自动收起右栏。
6. 长文件名中间用省略号，后缀完整保留。

### 高定 UI 10 条铁律
1. 去边框：靠 1%–3% 微明度分层，禁纯黑 #000。浅色 #f5f5f3/#fcfcfb，暗色 #0b0b0a/#151515/#1a1a19/#20201e。
2. 输入框：聚焦不加 outline，加深双环 box-shadow 造咬合感。
3. 暗色补偿：字重全降 40（如 400→360）防白字发胖。
4. 流式打字：单字 90ms 从 blur(6px) 到清晰，缓动 cubic-bezier(.215,.61,.355,1)，相邻字错开 30ms 晕开。
5. 行内图标：vertical-align:-0.125em 对齐中心。
6. 数字防抖：加 tabular-nums 锁等宽。
7. 丝滑折叠：免 JS 算高，用 Grid 0fr→1fr 过渡。
8. 防孤字：正文加 text-wrap:pretty。
9. 动效性格：拖拽用过阻尼弹簧(1200/80)零回弹咬死；点赞/对勾用欠阻尼(380/18)微弹。
10. 反馈自熄：复制对勾 2.5s 后自动淡出恢复。

## 补充红线（来自参考仓库）
- 最小字号 12px；一页 ≤4 种字号。
- 不用「·」做文案分隔，改用留白或弱色标签。
- 不用左边缘彩条卡片；圆角和阴影克制使用。
- 一个操作区最多 1 个主按钮。
- 移动端：可点区域 ≥44px，底部固定按钮避让 `env(safe-area-inset-bottom)`，含表单的浮层不允许点遮罩静默关闭。
- 状态真实：执行中/完成/失败以真实事件为准，不用计时器伪造进度。

## 交付自查
- [ ] 搜不到 `#000`、`black`、`rgb(0 0 0` 作为颜色（透明遮罩除外）
- [ ] 新增输入框聚焦是双环、无 outline
- [ ] 暗色截图里正文不发胖
- [ ] 回车发送的地方都过了输入法守卫（含 500ms）
- [ ] 消息列表 40/120 跟随规则
- [ ] 嵌套圆角满足外 = 内 + 内边距
- [ ] 计数/时间/价格是 tabular-nums
- [ ] 折叠用 grid 0fr→1fr
- [ ] 正文 text-wrap: pretty
- [ ] 动效区分拖拽（过阻尼）和点赞/对勾（欠阻尼），减弱动效时关闭
- [ ] 复制反馈 2.5s 自熄
- [ ] 无小于 12px 的字、无「·」分隔
