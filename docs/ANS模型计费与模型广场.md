## 计价规则

每次新请求保存独立、不可变的计价快照：官方价格来源及核对时间、站内美元额度兑换系数及确认时间、消费倍率、APIC 回执中已含的倍率、单次授权上限。预占、结算和迟到回执恢复使用同一份快照。

**最终积分 = 按模型标价计算的美元费用 × 10 × 模型消费倍率。**

基础兑换固定 **1 元 = 1 美元额度 = 10 积分**；不使用实际 USD/CNY 汇率，也不乘 6.7。GPT 保留 0.16 消费倍率，DeepSeek 和 Opus 保留 1 倍。每 1 美元标价费用，GPT 扣 **1.6 积分**，DeepSeek/Opus 扣 **10 积分**。

若 APIC 的美元回执已经包含消费倍率，先消除回执中已含的倍率，再按 ANS 规则换算。GPT 的真实 APIC 分层表达式已经包含 0.16，不能重复乘。采购折扣仅用于成本管理：Opus 上游采购 0.8 不改变用户选择的 1 倍售价。

## 保护边界

- 用户于 2026-10-16 更正：**1 元 = 1 美元额度 = 10 ANS 积分**；取消此前确认的 6.7 换算。这是站内额度兑换约定，不采用实际美元兑人民币汇率。不计算模型消费倍率时，每 1 美元额度消耗 **10 积分**。
- 用户已明确确认保留各模型倍率；“不算倍率”仅指基础兑换说明。现有 v2 配置字段 `fx.usdCny` 在本次商业额度规则下明确填 `1`，其含义是每美元额度对应的人民币价格，不是实时外汇报价。不得将已撤销的 6.7 配入生产，也不改变缺配置时拒绝收费的规则。新请求保存不可变快照；历史账单不重算。生产环境尚未应用本次变更。
- 单价展示独立于单次消费上限；每百万价格高于一次授权上限不代表该模型没有价格。实际请求仍受单次、累计及并发上限约束。
- 原始 APIC quota 与 ANS 积分分别保存，不允许根据积分反造 quota。结算证据中的应收、实收和平台承担差额使用同一积分单位。
- 老请求没有 v2 快照时继续原有恢复规则，不重新计算历史余额；已有但损坏的 v2 快照不能降级为老规则。
- count_tokens 仅做本地保守计数，不执行模型、不扣积分、不触发回执恢复，也不因单次消费上限拒绝结构合法的计数请求。
- Opus 仍未启用；单次供应商测试成功不等于 Claude Code、流式工具和 ANS/APIC 权威结算全部验收。

## 模型广场

ANS 本地入口 `/workspace/models`；算力中心增加直达入口。页面迁入 APIC/New API 广场的模型搜索、供应商/端点/状态筛选、卡片/表格、标准美元与积分价格、1M/1K 单位、排序、详情与复制功能；余额和身份仍由 ANS 管理。

目录只读取 APIC 公共元数据，不携带用户令牌或上游密钥，不显示私有分组。APIC 未公开 GPT 不表示内部渠道没有路由；“目录已公开”也不代表已经完成实时生成验收。暂未公开的模型显示有核对日期的官方参考价，Opus 明确待开放。读取失败不保留虚假的可用状态。

对分层/表达式计费不执行外部表达式，也不把旧 model_ratio 误作有效价格。New API 项目为 AGPL；本候选使用 ANS 原有组件独立实现目录界面和公共数据适配，没有复制其后台、账号、钱包或管理源码。现有 APIC 服务的许可证义务不因目录适配而改变。

先完成独立审查、隔离 PostgreSQL 迁移与金额约束验证，按用户更正的 1 元兑换 1 美元额度规则准备发布配置，保留已确认的模型消费倍率，并确认目标 main 和生产版本。提交、PR、合并及生产部署须在授权范围内完成。新迁移保留历史分支，不修改老账单；它扩展金额与模型约束，因此不能只上传页面。

上线必须将准确版本的应用、新约束和已核准计价配置作为同一批发布；没有新配置时，新请求保持拒绝收费。回滚应用前先停用新的计费入口，保留数据库新约束、原始回执和历史快照，不能用旧代码恢复 v2 未结算请求。不得通过删除新证据或重跑历史迁移来回滚。
