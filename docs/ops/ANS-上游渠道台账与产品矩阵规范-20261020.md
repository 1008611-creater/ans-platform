## 三、 ANS 品牌、封面与专属 Skill 资产铁律

1. **品牌唯一官方全称**：
   - **`ANS` = `AI Never Stops`**（严禁在任何代码、文档、视频字幕或对外介绍中误写为 `AI Native Society` 或 `AI Native Studio`）。
2. **项目封面与视觉制作铁律**：
   - **真实截图驱动**：制作或更新任何站内项目封面时，必须先截取对应站点的真实线上界面作为 `image25_gen.py --ref` 参考图，调用原版 `oil-cover` 管线生成，保证「封面画面与点进去的实际网站 100% 一致」。
   - **小恐龙按需克制出场**：常规工具/项目封面专注展示产品真实 UI 与成果，不强行塞入小恐龙；仅在明确以小恐龙伴侣/3D 展厅为主题的页面或 `oil-visual` 漫画解释插图中出现小恐龙。
   - **先审样片后上线**：任何新生成的封面或视觉资产，必须先输出样片经肉眼确认通过后，方可替换线上静态资源。
3. **核心专属 Skill 资产目录（已归档入 GitHub 仓库 `ai-video-skills-source/`）**：
   - `ans-ui-ux-baseline`：ANS 前端、文案与 UI/UX 交付基线（含禁用词黑名单与双盲对抗审查机制）。
   - `ans-brand-film-live-tour`：ANS 官网实机导览与产品发布宣传片管线。
   - `ans-hyperframes-launch-video`：16:9 瑞士网格宣发视频与逐句配音同步管线。
   - `ans-p5-brush-cartoon-animation`：V4.6 手绘水彩双主角（薄荷绿小恐龙 `dino` + 创作者 `creator`）动画管线。
   - `ans-eternal-pet-3d-pipeline`：宠物照片 -> 四视图 -> Tripo 3D -> Blender 防水微浮雕手办与桌宠管线。
   - 原版开源视觉套件：`oil-cover`、`oil-ui`、`oil-frontend`、`oil-visual`、`oil-tone`、`beautify-github-readme`、`mg-styles-15`。
