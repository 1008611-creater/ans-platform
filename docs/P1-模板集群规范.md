# ANS P1 模板集群规范

> 状态：实施中（模板 CRUD + 审核 + 展示已完成，执行看板为后续 P2）
> 分支：feat/ans-p0-p1
> 关联代码：`src/lib/template-service.ts`、`template-review.ts`、`template-access.ts`

## 1. 目标

建立「提示词模板集群」：创作者可提交结构化模板（表单 Schema + Prompt 正文），经 AI 初审 + 人工复核后发布，供社区按场景/领域检索使用。后续（P2）对接运行与算力结算（`Run` 模型已建）。

## 2. 模板生命周期（状态机）

```
DRAFT ──提交──▶ PENDING ──AI 初审 PASS──▶ (人工) ──发布──▶ PUBLISHED
  ▲                 │                        └──驳回──▶ REJECTED
  └──编辑/另建修订  │
      PUBLISHED ──(另建修订草稿)──▶ DRAFT
      REJECTED ──(编辑后重新提交)──▶ PENDING
```

规则：
- **可编辑状态**：仅 `DRAFT` / `REJECTED`；已发布模板只能「另建修订草稿」（`revise` 接口复制内容生成新 DRAFT，审计记录 `TEMPLATE_REVISION_CREATED` 并带 `sourceTemplateId`）。
- **AI 初审**：提交与复查时自动执行三维打分 `{ compliance, quality, intent }`（见 `template-review.ts`）；结论 `PASS`/`FAIL`。
- **人工复核**：`PENDING` + AI 初审 `PASS` 才允许发布；驳回必须填理由（`reviewNote`）。不能审核自己的模板。
- **乐观锁**：所有状态变更走 `updateMany`（匹配 `id+authorId+status+updatedAt`），失败返回 409；变更与审计同事务。
- **审计**：每次状态变更写 `AuditLog`（`before`/`after` 含 status、reviewScore、updatedAt），动作枚举 `TEMPLATE_CREATED/EDITED/SUBMITTED/AI_REVIEWED/AI_RECHECK_REQUESTED/PUBLISHED/REJECTED/REVISION_CREATED`。

## 3. 内容 Schema（服务端强校验）

- `title` 2–120 字；`summary` ≤300；`description` ≤8000；`promptBody` 10–30000 字（含 `{{key}}` 变量占位）。
- `formSchema`：≤30 个字段，`key` 唯一且匹配 `^[a-zA-Z][a-zA-Z0-9_]{0,49}$`；类型 `text|textarea|number|select`；select 必须有 options。
- 严禁传入审核/系统字段（`.strict()` 拒绝未知键）。

## 4. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/templates?domain=&scene=&page=` | 公开列表（24/页，仅 PUBLISHED） |
| GET | `/api/templates/[id]` | 公开详情（仅 PUBLISHED 可读） |
| POST | `/api/templates` | 创建草稿（登录） |
| PUT | `/api/templates/[id]` | 编辑草稿/驳回稿 |
| POST | `/api/templates/[id]/submit` | 提交审核（触发 AI 初审） |
| POST | `/api/templates/[id]/revise` | 已发布 → 另建修订草稿 |
| GET | `/api/templates/mine` | 我的模板（含状态） |
| GET/POST/PUT | `/api/admin/templates*` | 后台队列 / 人工复核 / AI 复查（管理员） |
| 页面 | `/templates`、`/templates/new`、`/templates/mine`、`/templates/[slug]`、`/admin/templates` | 浏览/创建/管理/详情/后台 |

## 5. 展示默认值

- 分类：复用 `Category`（domain = 一级分类、scene = 二级场景）。
- 公开列表卡片：标题、摘要、输出类型、分类；不暴露未发布内容与审核字段。
- 「我的模板」：全部状态可见，含审核结果与驳回理由。

## 6. 既定默认值（产品决策）

| 决策点 | 默认值 | 说明 |
|---|---|---|
| 模板 SOP | 后续采用**执行看板** | 本轮不建看板；`docs/` 以规范文档为准，执行看板（P3）复用 `/admin` 框架 |
| 发布门槛 | AI 初审 PASS + 人工复核 | 双网关，禁止纯 AI 直发 |
| 消耗结算 | `estimatedCost` 预估点数 | 实际消耗与 `Run` 结算在 P2 实现 |
