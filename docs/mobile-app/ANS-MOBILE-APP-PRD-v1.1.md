## 一、要解决的问题

打开 App 像在看缩小的网页，具体有 5 处：

1. **滑到底还有网页页脚**：隐私政策、服务条款、版权一出现，就露出是网页。
2. **长页面没有分段**：农客松主会场（`/competitions/agrihackathon`）在 390×844 下要滚 4～5 屏才能看完赛题、日程、榜单和成果墙。
3. **广场筛选条折行**：分类和操作按钮在窄屏折成多行，把第一张项目卡挤出首屏。
4. **「工作台」像后台**：没有手机 App 常见的「账户顶卡 + 宫格入口 + 列表」结构。
5. **小恐龙挡按钮**：右下角浮窗在窄屏和页面主按钮重叠，展开后也不是底部抽屉。

## 二、手机和电脑的分工

原则：手机做随身、高频、短时的事；电脑做长时间、大屏的生产。

| 模块 | 手机端（390×844 单手竖屏） | 电脑端（≥1280px） |
|---|---|---|
| 赛事（农客松） | 报名领 20 积分、分段看赛题、日程、榜单，从相册或文件交参赛凭证，分享拉票 | 写长方案、传大附件、评委打分与后台配置 |
| 项目广场 | 单列大图刷项目，点赞收藏，复制电脑端链接 | 工作模式：分屏写代码、实时预览、多轮 Agent 调试与发布 |
| 我的（工作台、积分） | 积分余额、签到领赠点、扣费流水、管理战队 | Toonflow、Easel、Hypit 画布，API Key，完整账单 |
| 小恐龙 | 圆章 + 底部半屏抽屉，对话与快捷问题 | 右下角常驻伙伴，可停靠 |
| 市场、社区 | 双列商品流、动态流（社区由「社区页」那条线负责，本 PRD 只管壳层） | 上架编辑、长文发帖 |

## 三、手机端判定规则（v1.1 新增）

页面里有三种判断，各管各的，不混用：

| 判断 | 条件 | 管什么 |
|---|---|---|
| **手机布局** | 视口宽度 `< 768px`（Tailwind `max-md:`） | 分段栏、单列卡、钱包顶卡、小恐龙抽屉、页脚隐藏 |
| **底部 Tab 栏** | 视口宽度 `< 1280px`（沿用现状 `xl:hidden`） | Tab 栏和主内容底部留白；平板（768～1279）有 Tab 栏，但保留页脚和桌面内容布局 |
| **App 环境** | 安卓：UA 含 `ANSMobileApp/`，服务端渲染时给 `<html>` 加 `data-app-shell="android"`，首屏不闪；iOS 主屏：客户端 `matchMedia('(display-mode: standalone)')` 或 `navigator.standalone` 为真时补 `data-app-shell="ios"` | 只管三件事：不再显示「下载 App」引导；页脚在 App 内无论宽度都隐藏；重度画布显示「去电脑上操作」提示 |

**布局只看宽度，不看 App 环境**。手机浏览器打开网站，看到的和 App 里一样；App 环境只决定「要不要提示下载」这类和装没装 App 有关的东西。

## 四、功能需求

> **契约**：`PRIMARY_NAVIGATION` 与 `MobileTabBar` 的 6 个路由（`/explore`、`/hubs`、`/community`、`/competitions`、`/market`、`/workspace`）、顺序和 `aria-current` 逻辑不动。移动端规范建议 Tab 栏 3～5 个，ANS 保留 6 个：360px 宽时每项 60px，仍满足 44px 热区，文案都不超过 3 个字。之后如果要合并入口，另开需求。

### 4.1 App 壳层

1. **App 环境标记**：按第三节规则实现 `data-app-shell`，配套 `useAppShell()` 供客户端组件读取。
2. **页脚**：手机布局或 App 环境下隐藏。隐私政策、服务条款、帮助、GitHub、「手机端 App」这几个链接移到「我的」页底部的「关于与帮助」列表，保证仍能找到。
3. **顶栏**：
   - 一级页（6 个 Tab 对应的页面）：左边页名，右边是积分胶囊（已登录，点了去 `/workspace/credits`）和头像入口。手机上不再出现汉堡菜单，因为 Tab 栏已经覆盖全部一级入口；汉堡里的二级入口并进「我的」。
   - 二级页（详情、提交、设置等）：左边是 44×44 的「返回」按钮。没有站内历史时，回到所属一级页。
4. **二级页隐藏 Tab 栏**：进入二级页时隐藏底部 Tab 栏，把底部留给内容或页面主按钮（移动端规范硬规则）。哪些路由算一级页，由 `PRIMARY_NAVIGATION` 加首页 `/` 决定，写成纯函数并配单测。
5. **返回手势**：安卓物理返回和侧滑返回已由原生壳 `onBackPressed → webView.goBack()` 处理，网页不用重复实现。iOS 主屏模式没有浏览器返回键，二级页的「返回」按钮是唯一出口，不能省。
6. **滚动**：`html, body` 加 `overscroll-behavior-y: contain`；横滑容器加 `touch-action: pan-x` 和 `overscroll-behavior-x: contain`，防止带动整页晃。全站在 360 和 390 宽度下 `scrollWidth ≤ innerWidth`。

### 4.2 赛事：农客松随身参赛（`/competitions/agrihackathon`）

1. **置顶闯关卡**：首屏第一张卡显示五步进度（报名领 20 积分 → 看赛题 → 交作品 → 查公开展示 → 分享）。当前步骤下面是唯一一个全宽主按钮（48px 高）。步骤状态以接口真实数据为准，未登录时显示第 1 步。
2. **分段栏**：闯关卡下方吸顶，4 段等宽：闯关、赛道、榜单、成果墙（2～4 项用分段控制器，不用横滑 Tab）。点击时原地切换内容，不再整页长滚。电脑端（≥768）保持原来的完整展示，现有测试的 DOM 断言不变。
3. **提交页**（`/competitions/agrihackathon/submissions`）：
   - 输入框 16px 字号（防 iOS 聚焦放大），最小高度 44px；聚焦时 `scrollIntoView({ block: 'center' })`。
   - 文件选择直接调系统相册或文件（原生壳 `onShowFileChooser` 已支持多选和拍照）。已选文件的长文件名中间省略、保留后缀（复用 `src/lib/ui/middle-ellipsis.tsx`），完整名放在 `title`。
   - 提交按钮吸底，`padding-bottom: max(16px, env(safe-area-inset-bottom))`。键盘弹起时安卓壳会把 WebView 缩到键盘上方（原生层已处理 IME inset），按钮不会被盖住。

### 4.3 项目广场（`/explore` 与 `/`）

1. **分类胶囊**：单行横滑，不折行；当前选中项自动滚到可见区域；两端加淡渐隐，提示还能滑。第一个胶囊左边留 16px，不抢 iOS 边缘返回手势。
2. **单列大卡**：16:9 封面（`aspect-ratio: 16/9; object-fit: cover`），下面是标题、作者和分类，加一个主按钮。有封面时，长描述在手机上不显示，进详情再看。
3. **详情页底部**：只有一个主按钮「打开项目」，「复制电脑端链接」做成次要按钮。复制后图标变对勾，2.5 秒后自动恢复（复用 `src/lib/ui/copy-feedback.ts`）。

### 4.4 我的（`/workspace` 与 `/workspace/credits`）

1. **账户顶卡**：头像、昵称、`@username`、可用积分（大号数字，`tabular-nums`），加两个次要入口：领农客松积分、积分明细。顶卡和页面底只差 1～3% 明度，不用深色黑卡。
2. **2×2 宫格**：我的项目、我的战队、收藏、模型广场。
3. **列表**：设置、关于与帮助（承接页脚链接）、退出登录。
4. **重度画布提示**：在手机上打开 Toonflow、Easel 等画布时，顶部显示一条提示：「这个工具适合在电脑上操作，手机上只能看。」，旁边是「复制链接」按钮。

### 4.5 小恐龙（`DinoGuide` 移动端）

1. **收起态**：44×44 圆章，位置在 Tab 栏上方 16px（二级页没有 Tab 栏时贴近安全区底边）。滚动时如果和页面主按钮重叠，就让开（优先让主按钮）。
2. **展开态**：底部半屏抽屉，取 60% 高度档位，可上拉到 80%。顶部有 36×4 的拖拽条，下滑可以收起；内部列表滚到顶后继续下拉，才算收起。上半部分是 3D 舞台，下半部分是 3 个快捷问题和输入框。
3. **抽屉里有输入框，所以点遮罩不收起**（移动端规范硬规则），只能用关闭按钮或下滑收起。打开时锁住底层页面滚动，关闭后恢复原来的位置。
4. **对话细节**（大厂 UI 聊天 6 条，直接复用 `src/lib/ui/` 里已有的 `ime-enter-guard`、`follow-bottom`、`stream-text`，不另写）：
   - 中文输入法选字时回车不发送，选字结束 500ms 内的回车也拦掉。
   - 离底部 40px 以内才自动跟随新消息；离底部超过 120px 时显示「跳至最新」。
   - 回复逐字出现：每字 90ms，从 blur(6px) 到清晰，相邻字错开 30ms。开启「减弱动态效果」时直接显示全文。

## 五、分期（v1.1 重排）

每期一个 PR。全部是网页改动，部署后 App 里立即生效，不用重发 APK。

| 期 | 范围 | 验收要点 |
|---|---|---|
| 1 壳层 | 4.1 全部 | Tab 契约测试、`site-frame`、`header-logout`、`learning-navigation` 全绿；新增「一级页判定」和「App 环境标记」单测；冒烟脚本补 390×844、360×800 两档：无横向溢出、二级页无 Tab 栏、手机宽度无页脚 |
| 2 赛事 | 4.2 全部 | 农客松 3 组测试全绿；分段栏在 360 宽不折行 |
| 3 广场与我的 | 4.3、4.4 | `compute-benefits`、`workspace-navigation` 测试全绿；页脚原有的链接都能在「我的」里找到 |
| 4 小恐龙 | 4.5 全部 | `dino-guide-accessibility`、`dino-task-guide`、`companion-dock-in-panel` 测试全绿；冒烟 0 条 NaN；输入法守卫与 40/120 跟随有单测 |
| 可选 安卓 1.3.1 | 原生壳背景色 `NAVY` 改为跟随网页底色（浅色 `#f5f5f3`、暗色 `#0b0b0a`），状态栏图标深浅跟随 | 需要发 APK，按 `ANDROID-RELEASE.md` 走；等第 1 期上线后再决定 |

**顺序理由**：壳层影响每一页，收益最大、风险最小；赛事接着农客松宣发；小恐龙刚因为 NaN 让 CI 红过两次，3D 舞台在手机上的性能也最没底，所以放最后单独做。

**不在范围内**：社区页（由「社区页」那条线负责），市场商品流，iOS 原生壳。

## 六、红线

1. `ANS` 的全称只写 `AI Never Stops`。
2. 不虚构数据：不做假在线人数、假下载量、假进度；状态以真实事件为准，不用计时器伪造。
3. 文案不用「赋能、矩阵、闭环、底座、心智、主理人」等词，也不用「·」做分隔。
4. 现有测试零回归，原有断言不删不改；新增行为配新测试。
5. 每期交付前按 UI 规范第五节的自查清单逐项核对，附 390×844 截图。
