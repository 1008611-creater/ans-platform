# ANS（AI Never Stops）手机端 App UI 设计规范（v1.1）

- **文档版本**：v1.1（2026-10-31），替代 v1.0（2026-10-30，Gemini 起草）
- **关联 PRD**：`docs/mobile-app/ANS-MOBILE-APP-PRD-v1.1.md`
- **权威顺序**：用户指定的「大厂 UI」16 条（`docs/design/dachang-ui.md`）> 本规范 > `ans-ui-ux-baseline`。移动端细节参考 Ludi-Herry 的 `mobile-design-system-skill`（安全区、热区、抽屉、键盘），只取它的硬规则
- **目标视口**：390×844（iPhone）与 360×800（安卓），手机布局断点 `< 768px`（判定规则见 PRD 第三节）

## v1.1 相对 v1.0 的改动

| v1.0 写法 | v1.1 改为 | 原因 |
|---|---|---|
| 深海蓝 `#0A1633` 闯关主卡、钱包黑卡，微冷灰 `#F4F6F8` 底配纯白卡 | 全部用现有 `--background` / `--card` / `--muted` / `--surface-raised` 四层，相邻只差 1～3% 明度 | 大厂 UI 第 1 条：去边框靠微明度分层；深色大卡在浅色页里是强对比色块 |

## 一、设计方向

打开第一眼是一个干脆的掌上工具：每屏只有一个视觉主角，核心操作都落在屏幕下半部分，单手拇指够得着。

不像网页的关键，是骨架而不是装饰：固定顶栏、独立滚动的内容区、固定底栏、不出现网页页脚；长内容用分段切换代替长滚动；浮层统一从底部升起。

## 二、Token（只用现有变量，不新增色值）

### 2.1 颜色与分层

| 层 | 浅色 | 暗色 | 变量 | 手机端用在 |
|---|---|---|---|---|
| 页面底 | `#f5f5f3` | `#0b0b0a` | `--background` | 内容区背景 |
| 卡片 | `#fcfcfb` | `#151515` | `--card` | 闯关卡、项目卡、账户顶卡、宫格 |
| 次级面 | `#efefec` | `#1a1a19` | `--muted` | 分段栏底、胶囊底、输入框底、按钮 hover |
| 抬起面 | `#e9e9e6` | `#20201e` | `--surface-raised` | 分段栏选中滑块、抽屉里的选中项 |

- 品牌主色只用在：唯一主按钮、Tab 选中图标、进度实心点。不铺大面积色块。
- 描边用 `box-shadow: inset 0 0 0 0.5px var(--hairline)`，不用 `border`。
- 不出现 `#000`，遮罩用 `rgb(26 26 25 / 32%)`。

### 2.2 字号（一页最多 4 种，最小 12px）

| 用途 | 字号 | 字重（浅色 / 暗色） |
|---|---|---|
| 页名 | 20px | 600 / 560 |
| 卡片标题 | 16px | 600 / 560，最多 2 行 |
| 正文、输入框 | 16px（输入框必须 16px，防 iOS 聚焦放大）；正文 14px | 400 / 360 |
| 辅助信息、Tab 文案、徽标 | 12px | 500 / 460，数字 `tabular-nums` |

正文 `text-wrap: pretty`，标题 `text-wrap: balance`。文案不用「·」分隔，用留白或弱色标签。

### 2.3 间距、圆角、热区

- 页面左右内边距 16px，卡片间距 12px，卡片内边距 16px。
- 圆角：卡片 20px，卡片里的元素 20 − 16 = 4px 起算；全宽主按钮单独放在卡片底部、内边距 12px 时，按钮圆角 = 20 − 12 = 8px。嵌套时先定外层，再推算内层。
- 可点区域 ≥ 44×44px（安卓按 48dp 更好），相邻可点项间距 ≥ 8px。小图标用 padding 撑出热区。
- 主按钮高 48px；一个区域最多 1 个主按钮。

### 2.4 安全区

- 顶栏：`padding-top: env(safe-area-inset-top)`。
- Tab 栏、吸底按钮：`padding-bottom: max(12px, env(safe-area-inset-bottom))`。
- 内容区底部留白：有 Tab 栏时 `calc(4rem + env(safe-area-inset-bottom))`（现状），二级页无 Tab 栏时按吸底按钮高度留白。
- 安卓壳（SDK 35+）已在原生层给系统栏、刘海和键盘让出 padding，WebView 内 env 为 0，上面的写法在安卓上自然退化，不要再加固定像素。

## 三、页面骨架

### 3.1 壳层：顶栏 + 内容区 + Tab 栏

```
┌───────────────────────────────────────┐
│ 页名                    [积分 120] [头像] │  一级页顶栏 h-12，sticky，--background
├───────────────────────────────────────┤
│                                       │
│  内容区（px-4，卡片间距 12）              │
│                                  (🦖) │  小恐龙圆章 44×44，Tab 栏上方 16px
├───────────────────────────────────────┤
│ 项目  Hub  社区  赛事  市场  工作台        │  Tab 栏，--card，inset 顶部发丝线
└───────────────────────────────────────┘

二级页顶栏：[← 返回]  页名（单行截断）        不显示 Tab 栏
```

- Tab 选中态：图标加粗、文字换前景色，背后是 `--muted` 面块（不用描边、不用主色底）。按下时 `active:scale-[0.97]`，过渡 200ms。
- 积分胶囊：`--muted` 底，数字 `tabular-nums`，整个胶囊热区 ≥ 44px 高（视觉高度可以 28px，用 padding 撑开）。
- 手机上隐藏页脚；App 环境下无论宽度都隐藏（PRD 第三节）。

### 3.2 赛事：闯关卡 + 分段栏

```
┌───────────────────────────────────────┐
│ ┌───────────────────────────────────┐ │
│ │ 第 1 步，共 5 步                       │ │  --card，圆角 20
│ │ ●──○──○──○──○                       │ │  当前步主色实心点，其余 --muted
│ │ 报名后领 20 积分                       │ │
│ │ ┌───────────────────────────────┐ │ │
│ │ │          立即报名                 │ │ │  唯一主按钮 h-12，圆角 8
│ │ └───────────────────────────────┘ │ │
│ └───────────────────────────────────┘ │
│ ┌ 闯关 ┬ 赛道 ┬ 榜单 ┬ 成果墙 ┐            │  分段栏 sticky top-12，--muted 底
│ └──────┴──────┴──────┴────────┘          │  选中滑块 --surface-raised，--spring-drag 平移
│  （当前分段内容）                          │
└───────────────────────────────────────┘
```

- 分段栏 `role="tablist"`，每段 `role="tab"` + `aria-selected`，内容 `role="tabpanel"`。360px 宽下 4 段等宽、不折行（每段约 82px）。
- 只有手机布局下分段；≥768px 保持现有完整展示，现有测试的 DOM 不变。
- 步骤完成：圆点用 `--spring-pop` 微弹一次；减弱动态效果时直接显示终态。

### 3.3 广场：横滑胶囊 + 单列大卡

```
│ [全部] [AIGC] [Web 应用] [3D 互动] [科研…   →│  单行横滑，左边留 16px，右端渐隐
│ ┌───────────────────────────────────────┐ │
│ │            16:9 封面                   │ │  aspect-ratio 16/9，object-fit cover
│ ├───────────────────────────────────────┤ │
│ │ 个人学术主页生成器                        │ │  卡片标题 16px
│ │ @liushubin   Web 应用        [打开]    │ │  辅助 12px；唯一按钮
│ └───────────────────────────────────────┘ │
```

- 胶囊容器：`overflow-x: auto; touch-action: pan-x; overscroll-behavior-x: contain; scrollbar-width: none`；选中项 `scrollIntoView({ inline: 'center' })`。
- 卡片阴影不能被横滑容器的 overflow 截断，截断时改用 inset 发丝线。

### 3.4 我的：账户顶卡 + 宫格 + 列表

```
│ ┌───────────────────────────────────────┐ │
│ │ (头像) 昵称  @username                  │ │  --card
│ │ 可用积分                                │ │

│ │ [领农客松积分]  [积分明细]                  │ │  次要按钮，--muted 底，无描边
│ └───────────────────────────────────────┘ │
│ ┌─────────────────┐ ┌─────────────────┐   │

│ ├─────────────────┤ ├─────────────────┤   │

```

### 3.5 小恐龙：圆章 → 底部抽屉

- 收起：44×44 圆章，`--card` 底加 inset 发丝线；`bottom: calc(4rem + 16px + env(safe-area-inset-bottom))`，`right: 16px`；二级页无 Tab 栏时下移。
- 展开：底部抽屉，默认 60% 屏高，可拖到 80%；顶部圆角 20px，拖拽条 36×4、`--muted`。上部 3D 舞台约 200px，下部是快捷问题胶囊、消息列表和输入框。
- 升降：位移用 `--spring-drag`（过阻尼，不回弹），减弱动态效果时直接切换。
- 遮罩：`rgb(26 26 25 / 32%)`，点击不收起（抽屉里有输入框）；收起方式是关闭按钮、下滑，或安卓返回键。
- 打开时锁住底层滚动（`position: fixed` 并记录 `scrollY`，关闭时恢复）；关闭动画期间遮罩 `pointer-events: none`，防止点击穿透到下层。
- 输入框：聚焦双环 `--focus-ring`，没有 outline；回车走 `src/lib/ui/ime-enter-guard.ts`；消息跟随走 `follow-bottom.ts`；逐字出现走 `stream-text.tsx`。

## 四、动效

| 场景 | 参数 |
|---|---|
| Tab、分段、胶囊按下 | `active:scale-[0.97]`，200ms `--ease-out-cubic` |
| 分段滑块平移、抽屉升降、拖拽吸附 | `--spring-drag`（1200/80，不回弹） |
| 步骤完成、点赞、复制对勾 | `--spring-pop`（380/18，微弹）；复制对勾 2.5s 后淡出 |
| 折叠展开 | `.ans-collapse`（grid 0fr → 1fr），不用 JS 量高度 |

所有动效都加 `motion-reduce:transition-none`，或在 `prefers-reduced-motion: reduce` 下直接显示终态。
