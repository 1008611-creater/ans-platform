# ANS (AI Never Stops) 手机端 App 前端 UI/UX 设计规范文档 (UI Design Spec v1.0)

- **文档版本**：v1.0（2026-10-30）
- **设计基线**：融合 `oil-ui` + `oil-frontend` + `ans-ui-ux-baseline` 五大铁律
- **目标设备视口**：`390×844`（iPhone 标准竖屏）与 `360×800`（Android 主流竖屏），兼顾 `ANSMobileApp/1.2.0` 原生 APK 容器与 iOS Standalone WebClip

---

## 一、设计北极星与视觉调性（Design North Star）

> **设计北极星**：「瑞士网格极简效率（Linear Mobile）× 翡翠绿活力卡片流（App Store Today / Duolingo）」——**打开第一眼是干脆利落的掌上工具，每一屏只有一个视觉主角，单手大拇指在屏幕下半区就能走完核心任务。**

### 1.1 为什么之前的界面像「缩小的电脑网页」？（视觉诊断与修正对照表）

| 维度 | ❌ 网页缩放态（当前问题） | ✅ 原生 App 态（本规范目标） |
|---|---|---|
| **页面外框** | 有网页 `Footer`、长页面滚到底露出版权页脚、背景通体发平 | **固定顶栏 + 独立滚动内容区 + 固定底栏（无网页 Footer）**，背景微灰/深蓝衬托纯白/深色圆角卡片 |
| **导航方式** | 顶部折叠汉堡菜单 + 底部 Tab 两套重复的 6 项导航 | 底部 6 栏 Tab 为唯一主导航；顶部栏在手机端只展示**当前页名 + 快捷积分胶囊 + 个人入口** |
| **长内容组织** | 农客松 5 个模块从上到下垂直堆叠 `4000px+` | **横向分段控制器（Segmented Control）**，点击标签原地切换，单屏高度控制在 `1.5 屏` 以内 |
| **弹窗与浮层** | 居中模态框或右下角大尺寸悬浮窗挡住按钮 | 移动端一律采用 **底部圆角抽屉（Bottom Sheet，`rounded-t-3xl`）**，支持下滑收起 |
| **主操作按钮** | 跟在文字段落后面，大小不一（`h-8`/`h-9`），位置随内容漂移 | **全宽大圆角主按钮（`h-12` / `48px`，`rounded-2xl`）** 或 **底部吸顶操作栏（Sticky Action Bar）** |

## 二、全局色彩、排版与空间 Token（Mobile App Tokens）

### 2.1 核心色板（严格沿用 ANS 品牌色并强化移动端层级对比）
- **App 品牌主色（Emerald Accent）**：`#10B981`（浅色模式按钮实底 `#059669`，深色模式高亮 `#34D399`）
- **App 深海夜空底色（Navy Shell / Wallet Card）**：`#0A1633`（用于 App 启动壳层、农客松置顶闯关主卡、个人中心算力黑卡）
- **移动端页面画布底色（App Canvas Background）**：
  - Light：`#F4F6F8`（微冷灰底，让 `#FFFFFF` 纯白卡片不靠粗边框也能自然浮起）
  - Dark：`#090D16`（卡片底色 `#111827`，边框 `rgba(255,255,255,0.08)`）
- **文字对比度红线**：正文主色对比度 `≥ 7:1`，次要说明文字对比度 `≥ 4.5:1`（严禁使用低于 `/70` 透明度的浅灰字）。

### 2.2 手机端字号与行高阶梯（禁止桌面端超大字号撑爆窄屏）
- **App 页面大标题（Page Title）**：`20px`（`text-xl font-bold tracking-tight leading-snug`），最多 1 行（超出截断或自适应为 `18px`）
- **区块/卡片主标题（Card Title）**：`16px`（`text-base font-semibold leading-snug`），最多 2 行（`line-clamp-2`）
- **正文与表单输入（Body / Input）**：`14px`～`16px`（注意：移动端 `<input>` / `<textarea>` 字号建议 `16px` `text-base` 以防止 iOS Safari 聚焦时自动放大页面！）
- **辅助胶囊与角标（Badge / Meta）**：`12px`（`text-xs font-medium tabular-nums`），严禁出现小于 `11px` 的微缩文字。

### 2.3 触控热区与安全区规范（Thumb Zone & Safe Area）
- **最小触控尺寸**：所有可点击按钮、Tab 项、分段标签、返回键的物理点击区域 **`≥ 44px × 44px`**（`min-h-11 min-w-11`）。
- **刘海屏与底部横条安全区**：
  - 顶部栏：`pt-[env(safe-area-inset-top)]`
  - 底部 Tab 栏：`pb-[env(safe-area-inset-bottom)]`
  - 页面主内容区底部留白：`pb-[calc(4.5rem+env(safe-area-inset-bottom))]`，确保最后一张卡片绝不被底部 Tab 栏或小恐龙圆章遮挡。

## 三、核心界面组件与分页面 UI 布局规范

### 3.1 全局壳层：`Header` + `SiteFrame` + `MobileTabBar`

```
+---------------------------------------------------+
| [Logo] ANS                    [⚡ 20 积分] [头像] |  <- App Top Bar (h-12, sticky top-0)
+---------------------------------------------------+
|                                                   |
|   Main Scrollable Viewport (px-3.5 py-3)          |
|   - 卡片圆角统一 rounded-2xl (16px)               |
|   - 卡片间距统一 space-y-3.5 (14px)               |
|   - 移动端隐藏网页 Footer                         |
|                                           +-----+ |
|                                           | 🦖  | |  <- 迷你小恐龙悬浮章 (44x44, bottom-20)
+-------------------------------------------+-----+ |
|  🧭广场   🏛️Hub   💬社区   🏆赛事   🛍️市集   👤我的 |  <- MobileTabBar (6 cols, fixed bottom-0)
+---------------------------------------------------+
```

- **收敛顶部汉堡抽屉**：既然底部已有 6 栏 `MobileTabBar`（覆盖全部 6 个一级导航），在 `< 768px` 手机视口下，顶部栏弱化冗长菜单，突出右侧 **「当前积分胶囊（点击直达 `/workspace/credits`）」** 与个人头像菜单。
- **隐藏网页 Footer**：在 `src/components/layout/footer.tsx` 中增加 `hidden md:block`，手机视口下不再渲染网页底部版权条。

### 3.5 3D 小恐龙伴侣（`DinoGuide`）：「右下角轻巧徽章 → 底部半屏抽屉」

- **收起态（手机端 `< 768px`）**：右下角 `bottom-[calc(4.25rem+env(safe-area-inset-bottom))] right-3`，尺寸控制在紧凑圆章，绝不遮挡页面中间与左侧的主表单按钮。
- **展开态（手机端 `< 768px`）**：采用底部滑出半屏面板（`rounded-t-3xl border-t bg-background/95 backdrop-blur-xl max-h-[68vh]`），顶部居中 `w-10 h-1.5 rounded-full bg-muted` 拖拽横条，上半部展示 3D 小恐龙互动舞台，下半部展示快捷问题胶囊与输入框。

## 四、动效与手感规范（Motion & Haptics Feel）

1. **三处核心动效**：
   - **底部 Tab 与分段切换**：选中背景块平滑过渡（`transition-all duration-200 ease-out`），点击按钮带微缩放按压反馈（`active:scale-[0.98]`）。
   - **底部抽屉（Bottom Sheet）升降**：采用 `cubic-bezier(0.32, 0.72, 0, 1)` 阻尼曲线（iOS 原生抽屉同款曲线），时长 `260ms`。
   - **农客松闯关步骤完成反馈**：步骤圆点点亮时伴随翡翠绿光晕过渡。
2. **无障碍降级**：所有过渡动效必须包含 `motion-reduce:transition-none`，尊重系统减少动态效果设置。
