# ADR 0001：工作流采用有限 DAG

## 状态

已接受

## 背景

ANS 需要把 Prompt、模板和模型调用组合成可复用能力，但首版必须保持可验证、可限流和可审计，不能直接引入开放式自主 Agent。

## 决策

工作流使用有限 DAG：节点有明确类型和资源限制，边传递结构化数据，服务端在执行前完成无环校验和拓扑排序。

首版限制：最多 50 个节点、单节点最长 120 秒、最多重试 3 次。平台统一模型池和用户自带 Key 通过同一运行接口执行，凭证不进入客户端。

## 结果

- 可以稳定验证工作流结构。
- 可以为每个节点记录耗时、错误和成本。
- 可以在后续增加条件、分支和并行，但不破坏执行边界。
- 暂不支持无限循环、任意代码执行和无白名单工具调用。
