# ANS P0 账号地基规范

> 状态：实施中（注册链路已完成，昵称修改 / 邀请审计补全中）
> 分支：feat/ans-p0-p1
> 关联代码：`src/lib/registration.ts`、`src/lib/registration-delivery.ts`、`prisma/schema.prisma`

## 1. 目标

为 ANS（AI 原生社区平台，ans.cauai.fun）建立账号地基：注册入口安全可用、身份展示匿名化、邀请关系可审计。

## 2. 既定默认值（产品决策，已确认）

| 决策点 | 默认值 | 落点 |
|---|---|---|
| 公开展示 | 只展示昵称，不收集/不展示真实姓名 | 注册只收 `name`（昵称）；`User.nickname` 与 `User.name` 同值初始化；profile 页仅展示昵称 |
| 改昵称 | 30 天可改一次 | `User.nicknameSetAt` 冷却起点；修改接口强制 30 天间隔（补全中） |
| 邀请关系 | 仅管理员可审计 | `InviteCode` / `InviteRedemption` 全量落库；admin 审计入口（补全中） |
| 邀请资格 | 仅 `cau.edu.cn` 精确域名免邀请码 | 服务端硬校验邮箱域名，前端仅提示 |
| 邀请码使用上限 | 单个码最多 5 次 | 服务端事务内用 `updateMany` 条件递增核销 |

## 3. 注册链路（已完成并测试）

```
POST /api/auth/register/config   → 下发 Turnstile siteKey（供前端渲染）
POST /api/auth/register/code     → 校验 Turnstile → 发 6 位邮箱验证码（Resend）
POST /api/auth/register          → 校验 Turnstile + OTP + 邀请码 → 建号
```

### 3.1 安全设计

- **人机验证**：Cloudflare Turnstile，`action=register`，服务端 siteverify 校验 `hostname` 与 `action`。
- **邮箱验证码 OTP**：
  - 库中只存 `sha256(email + code + SECRET)` 摘要，不存明文；
  - 校验用 `timingSafeEqual`，避免时序侧信道；
  - 10 分钟有效，用后即焚（事务内 `deleteMany` 精确消费）。
- **限流**：基于 PostgreSQL advisory lock（`pg_advisory_xact_lock`）+ `VerificationToken` 计数行：
  - 发码/重发：60 秒冷却，10 分钟窗口内最多 5 次；
  - 注册尝试：10 分钟窗口内最多 5 次，超过返回 429 + `Retry-After`。
- **邀请码核销**：`updateMany` 条件（`usedCount < min(5, maxUses)` 且未过期）原子递增，杜绝并发超用。
- **请求体**：限制 16KB，严格 UTF-8 JSON 解析，错误响应不携带请求数据/凭据。
- **邮箱唯一**：大小写不敏感查重 + 数据库唯一约束兜底（`email_taken`）。
- **昵称**：注册时共享 `name`；`username` 自动生成 `u_<uuid>`（不公开），避免枚举。

### 3.2 依赖配置（上线前必须注入）

```
NEXT_PUBLIC_TURNSTILE_SITE_KEY=   # 前端渲染
TURNSTILE_SECRET_KEY=             # 服务端校验
RESEND_API_KEY=                   # 验证码邮件
EMAIL_FROM=                       # 发件人地址
```
缺任一配置 → `/api/auth/register/*` 返回 503「注册服务尚未配置完成」。

## 4. 数据模型

```prisma
model User {
  nickname      String?   // 匿名展示名，独立于 username
  nicknameSetAt DateTime? // 改昵称冷却起点（30 天一次）
  createdInvites  InviteCode[]        @relation("InviteCreator")
  redeemedInvites InviteRedemption[]
  templates       Template[]
  runs            Run[]
}

model InviteCode {
  code      String   @unique
  creatorId String
  maxUses   Int      @default(5)
  usedCount Int      @default(0)
  expiresAt DateTime?
}

model InviteRedemption {
  codeId   String
  usedById String
  usedAt   DateTime @default(now())
  @@unique([codeId, usedById])
}
```
