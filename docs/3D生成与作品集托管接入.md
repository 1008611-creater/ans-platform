## 本机启动

凭据已由用户保存于 `%LOCALAPPDATA%/ANS/credentials/tripo3d.credential.xml`，用同一 Windows 用户运行。DPAPI XML 只能在该 Windows 用户环境解密，不放进 Git 或托管服务器。

```powershell
./scripts/visual-worker/start-local.ps1 -Mode preflight
./scripts/visual-worker/start-local.ps1 -Mode start
```

preflight 只登录和读模型配置；start 会按用户在 ANS 确认的任务上传图片并生成。不要在没有真实测试授权时启动提交模式。常驻运行可由 Windows 任务计划程序在登录时启动此脚本，失败后重启；启动目录指向本工作区，同一账号只启动一个实例。服务默认 journal 位于 `%LOCALAPPDATA%/ANS/tripo-journal`，只记录提交意图与任务 ID，不记录密码、token 或图片。

提交前取消可退积分。提交后保留结果并等待费用核对。若上游 POST 的响应丢失，进入 `NEEDS_REVIEW`，不会重新生成；若任务 ID 已保存，重启后继续查询原任务。最终保存结果允许相同文件重试，不会重复创建资产。上游失败和格式不支持的补偿由运营核对，不自动推断上游已退费。

使用 Cloudflare for SaaS 的 Custom Hostnames，并先按照官方说明准备 fallback origin 与 Worker 路由。普通 Worker custom domain 配置本身不能替代客户域名接入。实际 DNS 与证书配置需确认所用 Cloudflare 账户、套餐和域名后实施。

## 2026-10-14 计费与输入保留修复

启用付费生成必须明确配置大于零、最多六位小数且不超过 10000 的 ANS 积分价格。空值、空白、零、负数、指数形式及无效价格全部关闭新任务，不调用付费模型。人民币和积分换算仍沿用 1 元 = 10 积分；上游积分不等于 ANS 积分。

新增迁移 `20261014150000_visual_input_retention`：每位用户最多一个不可变上传意图，任务增加输入删除时间。任务预约先检查余额，再提交上传意图；主事务再次核对余额并扣费，随后写入精确输入、保存任务并移除意图。输入写入失败或事务失败时，独立补偿先核对已提交任务；提交响应丢失但任务存在时保留输入，查询或删除失败时保留意图。

本地输入以独占创建写入，相同路径只能接受完全相同的字节。活跃写入尚未结束时拒绝清理；过期意图不等于写入已结束。进程重启、多实例、存储模式变化和 S3 上传结果不明时，缺少写入完成证据，保留意图并返回 503。不得仅凭超过两分钟删除对象。人工恢复须先停止相关写入服务，核对数据库任务、精确对象和供应商上传状态，再在独立维护事务处理；没有确认对象写入被停止时不能删除意图。S3 自动中止不是远端写入停止证明。

成功、失败和取消等明确终态在事务提交后清理原输入，保留成功 GLB 和网站产物。取消退款最多一次；存储清理失败不会回滚已完成的退款。NEEDS_REVIEW 保留输入。新预约先重试本人终态清理，仍有未清理输入则拒绝继续写盘。活跃上传返回 409，客户端可重试原幂等键。

`ANS_VISUAL_MAX_RETAINED_INPUTS` 默认 32，范围 1—1000。全局计数包含任务原输入和未解决上传意图；单图模式默认最多 640 MB 新输入；新增多视角模式每份私密输入包上限 110 MB，32 份的保守容量上限为 3.52 GB。不包括成功模型、已发布网站和历史孤儿文件。该限制保证输入故障不会产生无限上传容量；应另监控持久卷实际空间并备份产物。

生产发布前需将视觉任务、AIGC 交付和输入保留迁移一起纳入精确 SQL 哈希与备份恢复演练；迁移在明确发布步骤执行，运行镜像入口仍不执行 DDL。本次修复验证仅使用独立 PostgreSQL、临时输入目录和现有只读参考素材，不调用付费模型或操作生产数据库。
