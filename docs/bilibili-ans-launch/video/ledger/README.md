# 运营账本

把「发布 → 数据 → 下一期选题」闭环起来，替代凭感觉运营。

## 每天一条命令

```powershell
python ledger.py --records ledger/records.json --comments --label "dayN"
```

- 读的是 B站**公开接口**，不需要登录（只有发视频才要凭据）；
- 每次运行把一条快照追加到 `ledger.jsonl`，并打印与上一条的增量（播放/点赞/投币/评论）；
- `--comments` 会额外抓最新评论，用来决定下一期做什么（对标账号的经验：评论区点菜比闭门造车更准）。

## 记录来源

`publish.py` 发布成功时会自动把 bvid 追加到 `records.json`，所以正常情况下你不需要手工维护这个文件。

## 为什么重要

对标账号「Claude大小姐在运营」Day0 拿到 34 万播放，Day2 掉到 1.36 万——**数据不追踪，就不知道是哪一期开始掉的、掉在哪个指标上**。
账本让「哪一期值得加更、哪种标题更吃得开」变成可比较的数字，而不是印象。
