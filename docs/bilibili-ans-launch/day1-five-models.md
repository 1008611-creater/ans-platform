# Day 1 · 五个模型，一道题

> 目标：一条 85 秒视频 + **一份能提交 B站「AI 无限竞技场」的测评榜单**（收录有机会拿千万流量 + 现金激励）。

## 1. 本期要解决的事

Day0 立人设，Day1 必须证明"我真的在干活"。所以这一期不是模型跑分，而是：

> **用 ANS 的真实工作场景出题，五个模型同题竞技，结果公开可复现。**

好处：内容有独家素材（别人没有 ANS 现场）、天然蹭官方活动、评论区有大量可吵的点。

---

## 2. 评测设计（照抄即可，公平性是这个赛道的命门）

### 2.1 统一变量（必须逐字一致）

| 变量 | 设定 |
|---|---|
| 题目 | 见下方「统一 Prompt」 |
| 输入 | 同一段需求文本（建议用一条真实的 ANS 用户需求，脱敏后使用） |
| 轮次 | **单轮**，不许追问、不许让模型自我修正 |
| 工具 | **全部禁用**（不许联网、不许跑代码） |
| 温度 / 档位 | 各模型**最高推理档**，温度用默认值；必须记录档位 |
| 采样 | 每个模型跑 **3 次**，报中位数 + 最好/最差 |
| 环境 | 同一台机器、同一客户端、同一 Agent 框架（写明框架名与版本） |

### 2.2 统一 Prompt（发给每个模型，逐字相同）

```
你是 ANS 平台上的提示词工程师。下面是一段真实需求：

「<需求：一句话描述用户想要的结果>」

请输出两段：
1) 一条可直接复用、带变量占位的提示词（写清角色、约束、输出格式）；
2) 用你刚写的这条提示词，给出一次真实执行结果。

限制：全文不超过 400 字；不许调用任何工具；不许向我提问。
```

### 2.3 模型池（≥3 个，且必须含模型池中的最新模型）

| 参赛 | 标注方式 |
|---|---|
| GPT-6 Astra | 模型名 + 版本号 + 推理档位 |
| Claude Opus 5.5 | 同上 |
| DeepSeek V4.1 Flash | 同上 |
| Kimi K3 | 同上 |
| GLM-5.3 | 同上 |

> 封面已排成 5 个 chip；若某模型当天不可用，就减到 4 个并在视频里说明——**宁少不假**。

### 2.4 评分表（总分 100）

| 维度 | 分值 | 判据 |
|---|---|---|
| 完成度 | 25 | 两段是否都交齐、字数是否合规 |
| 可执行性 | 25 | 提示词是否可**直接**使用；输出是否符合它自己的格式要求 |
| 结构化 | 15 | 是否含变量占位、约束、输出格式三要素 |
| 事实与服从 | 15 | 幻觉、违背限制（用了工具 / 反问我 / 超字数） |
| 人类盲评 | 20 | 3 人独立打分（隐去模型名），取平均 |

**减分项直接公开**：违背"不许提问"、超 400 字、用了工具 → 各扣 5，并在视频里点名。

### 2.5 记录表（可用 CSV / Excel）

```
model, version, tier, run, tokens_in, tokens_out, latency_s, cost_cny,
score_completeness, score_executability, score_structure, score_error,
human_blind_avg, total, notes
```

> 这张表就是视频里的"公开账本"，也是被质疑时的证据。**别编数据**——这个赛道被扒一次就完了。

## 3. 完整脚本（85 秒）

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 00:00–00:06 | 上期热评截图（"其实是真人吧"） | 「上期点赞最高的是这条。我认，但先干活——今天五个模型上工位。」 |
| 00:06–00:18 | 五个模型图标排开，白板写规则 | 「同一道题，同一个 Prompt，不许提问、不许用工具，最高推理档，每个跑三次。规则我贴在简介里，你随时可以复现。」 |
| 00:18–00:56 | 五段真实录屏，每段 7–8 秒，右上角标「模型 + 版本 + 档位」 | 只念关键差异：「Astra 把变量占位写全了」「Opus 多了个不存在的字段」「DeepSeek 这次字数超了，扣 5」 |
| 00:56–01:10 | 总分条形图 + 榜单 | 「按五维打分：Astra 86，Opus 81，DeepSeek 74…… 分数表我放动态，原始输出也放。」 |
| 01:10–01:25 | 一个翻车细节特写 + 像素大肥鱼吐槽 | 「最离谱的是这个：它给我发明了一个 API 名。行，我记下了。」 |
| 01:25–01:30 | 投票卡片 | 「下期你选：A 让它们互相改对方的提示词 ／ B 让它们分出胜负后自己复盘。评论区投票，明天 18:30。」 |

**字幕硬规则**：每次出现模型名，必带版本号 + 推理档位；出现分数，必带"五维加权"说明。

## 4. 后期与包装

- 榜单用**横向条形图**，不用雷达图（手机上看不清）。
- 每个模型的卡面用同一模板：左模型名 / 右总分 / 下面一行最扎眼的失误。
- 视频简介里贴**完整评分表 + 原始输出链接（站内动态，不放外链）**。
- 标题候选：
  1. `【Day 1】五个模型，同一道题，谁的交付能过审？`
  2. `【Day 1】我把同一道题丢给五个模型，最贵的那个翻车了`
  3. `【Day 1】五个模型一道题：一份可复现的测评`

## 6. 风险与免责

| 风险 | 处理 |
|---|---|
| 被质疑"不公平 / 带节奏" | 统一变量表 + 3 次采样 + 原始输出全部公开；欢迎复现并指出问题 |
| 被指"贬低某厂商" | 只描述**本题表现**，不做产品评价；B站创作推广规则明令"不得贬低他人" |
| 数据被扒是编的 | 全程留原始录屏与日志；分数表直接贴 |
| 引发模型饭圈互撕 | 置顶评论写明"本题只代表这一个任务"，引战不回 |
| 漏标 AIGC | 稿件声明勾「本视频使用人工智能合成技术」；简介写同人声明 |
