# 首日互动脚本（发布后前 24 小时）

> 为什么单独做一份：对标账号 Day0 能拿 34 万播放，靠的不只是片子，是**发布后 24 小时的互动密度**。
> B站推荐机制看的是「完播 + 互动 + 二次打开」，评论区热起来，系统才会继续给量。
> 下面全部是**可直接复制**的话术，按顺序做就行。

## 0. 发布前 1 分钟（缺一会被打回）

- [ ] 创作中心勾选 **「AIGC 内容声明」**（B站 2023 起强制，漏标会被补标/打回/下架）
- [ ] 分区：生活·日常（或 科技·计算机技术 tid=188）
- [ ] 封面已上传（`video/out/cover-1920x1080.png`）并确认在移动端不糊
- [ ] 简介不含外链/二维码/联系方式（新号尤其敏感）

## 1. 发布后立刻：置顶评论（决定评论区的走向）

**Day 0 置顶：**

> 这条是 Day 0。从今天起，这个账号由一只像素恐龙运营。
> 想先看什么，评论区点菜：
> ① 让它自己写脚本 ② 让它做表情包 ③ 让它去 ANS 后台看真实数据
> 我每天把数据更新在这条置顶下面。

**Day 1–4 置顶（每期换一条）：**

> Day N 打卡。上一期的坑/结论在这条置顶下面，数据我每天更新。
> 你觉得这期结论站得住吗？站不住就骂，我下期拿它做实验。

## 2. 发布后 3 分钟：发一条动态

**Day 0 动态：**

> 把 B站账号交给一只像素恐龙的第 0 天。
> 它今天给自己画了 128 个表情，还抢了我的工位。
> 明天开始，它要自己选题、自己做视频、自己回评论——我会把每天的失败也发出来。

> 配图：`video/out/ans-day1-cover.png` 或直接放 9 宫格表情包（`assets/dino-stickers/` 里的 GIF）

## 3. 评论回复话术（按类型，避免每条重复）

| 评论类型 | 回复模板 |
|---|---|
| 催更 | 「在做了，明天 18:30。你要不要点个菜，我优先做你点的。」 |
| 问工具/模型 | 「真数据都在这期的评分长图里，模型名和原始输出我都放出来了，可复核。」 |
| 质疑「这是 AI 装的吧」 | 「对，脚本和配音都是 AI，只有审核和数据是真的。所以我每期都放原始输出。」 |
| 夸可爱 | 「替小恐龙谢谢你。它现在有 128 个表情，想看哪个？我做。」 |
| 提反对意见 | 「这条我记进下期选题了。如果我错了，我下期用实验打自己脸。」 |
| 广告/引流 | 不回复，直接删除 + 拉黑（回复会把它顶上去） |

**原则**：
1. **前 20 条评论 30 分钟内全部回复**（这是拉互动权重最关键的动作）；
2. 回复里**带一个问题**（引导二次回复，评论数才涨）；
3. 争议不删不吵，转成下期选题（把负面变内容）。

## 4. 数据动作（配合 `ledger.py`）

| 时间点 | 动作 |
|---|---|
| 发布 +1h | 看**完播率**（< 25% 就是开头 3 秒有问题，下次改钩子） |
| 发布 +6h | 看**评论关键词**，回复一轮 |
| 发布 +24h | 跑 `python ledger.py --records ledger/records.json --comments --label "day0-24h"`，记录播放/点赞/投币/评论 |
| 发布 +72h | 对比 Day1 期数据，决定 Day1 的标题要不要换风格 |

> 每日 20:30 有定时任务自动跑账本并报增量（已配置）。

## 5. 红线（新号最容易被限流的几件事）

- 一天连发多条（按排期日更即可）；
- 简介/评论里放外链、二维码、联系方式；
- 自称「官方」或贬低其他账号；
- 买量/刷播放（B站识别后直接清零+降权）。
