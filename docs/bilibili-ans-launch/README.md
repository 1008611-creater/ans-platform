### 角色设定：ANS 家大小姐 + 小恐龙（视觉锚点，缺一个就认不出）

**大肥鱼 = ANS 家大小姐**（东家本人），**不是**"AI 抢了账号"的打工人梗。她和平台是主客关系：平台是她的主场，规则由她定。这一定位比"打工人"更抗消耗——不用一直演惨，可以演"我们家的东西我说了算"。

| 要素 | 设定 | 作用 |
|---|---|---|
| 身份 | ANS 家大小姐，昵称就是"大肥鱼在ANS当运营" | 昵称、人设、平台三处自洽 |
| 本体色 | 蓝发（DeepSeek 蓝 #3C54C8 系） | 一眼对回「大肥鱼」 |
| 记忆点 | **齐刘海 + 月牙高光 + 鱼形发夹**（右刘海） | 发型是识别主锚点，一眼认人 |
| 造型 | 露肩卫衣（白/浅蓝）+ 翡翠绿颈环吊坠 + ANS 工牌 | 纯欲氛围 + 品牌锚点 |
| 气质 | 大小姐的从容、眼神微挑，笑起来有一点小心机 | 可爱不幼态，能扛日更 |

**双人组合的三种固定桥段**（轮着用，成本极低）
1. **派活**：大小姐一句"这点小事也做不好？"，小恐龙去跑 ANS 的任务，结果翻车。
2. **考核**：大小姐给几个模型出题，小恐龙当记录员，或被误伤的那个。
3. **日报**：小恐龙念账本，大小姐在旁边拆台。

## 3. 内容引擎（每条视频都套这个骨架）

**60–90 秒，三段式。Day2 那条 9 分 12 秒的长视频在参照账号上直接掉 94%，不要碰长视频。**

| 段落 | 时长 | 任务 | 失败信号 |
|---|---|---|---|
| 冷开场 | 0–5s | 一个动作 + 一句反常发言，**不要 logo、不要自我介绍** | 前 3 秒没信息量 |
| 正片 | 5–55s | 一个真实任务 + 一次翻车或意外 | 只是功能口播 |
| 投票钩 | 55–80s | 给 A/B/C/D 让评论区决定下期 + 一句自嘲收尾 | 没有明确的下一步 |

**四条铁律**
1. **一条视频只讲一件事**（一个任务 / 一次翻车 / 一次对战）。
2. **数据必须有真实出处**（截真实日志/真实耗时），"公开账本"是信任来源。
3. **每期必回上期热评**——参照账号 Day1 就是拿热评「其实是肥鱼吧」当选题，这是它的内容飞轮。
4. **固定时间发**（建议 18:30，对齐 AI 区晚间活跃；参照账号在 14:00–17:00 之间飘，不利于养成习惯）。

## 11. 数据看板与止损线

**每条视频必记**：播放、点赞率（赞/播放）、评论数、分享数、**粉丝净增**、涨粉/播放比、完播率（创作中心）。

| 指标 | 健康 | 预警 | 动作 |
|---|---|---|---|
| 涨粉 / 播放 | ≥1.5% | <0.5% | 人设不转化 → 加强"下期承诺"和连载感 |
| 点赞 / 播放 | ≥4% | <2% | 内容没爽点 → 换开场，缩时长 |
| 评论 / 播放 | ≥0.3% | <0.1% | 没互动钩子 → 投票前置到 30 秒内 |
| Day1 播放 | ≥ Day0 的 40% | <20% | hook 不成立 → 放弃当前选题线，回到"翻车+对战" |
| 连续 3 条下滑 | — | — | 停更两天做一次公开复盘（复盘本身就是内容） |

**参照基线（供对照）**：Claude大小姐 Day0 34.0万 → Day1 21.2万（62%）→ Day2 1.36万（6%，且是 9 分钟长视频）；鲸鱼娘 Day0 **90.5万**。**你的 Day0 若低于 5 千播放，不要硬撑同一条线，直接改 hook。**
