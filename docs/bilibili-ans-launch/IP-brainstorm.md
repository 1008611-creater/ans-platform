# 小恐龙 IP · 网感 / 设计感 / 玩法 / IP 价值 脑暴

> 目标：把「ANS 小恐龙」从一个吉祥物，做成**有辨识度、可复用、能传播、能变现**的账号 IP。
> 现状：已有 Q 版形象（头 > 身）+ 9 组序列帧（走路/待机/动作/表情包×3/站起来）+ 6 个循环 GIF。

## 0. 一句话定位（先定人格，再谈素材）

> **「ANS 的实习生小恐龙」**：一只在公司里摸鱼、搬砖、偶尔干出大活的 Q 版像素小恐龙。

它是账号的**第二人格**：**大小姐负责决策，小恐龙负责执行、翻车、卖萌和挨骂**。这条分工一旦固定，所有内容都有了出处：
- 视频里：大小姐出题，小恐龙去做 → 翻车 → 大小姐拆台
- 评论区：小恐龙出来回「收到！」「已摸鱼」「裂开了」
- 动态里：每天账本由小恐龙出面发

## 3. 网感玩法（拿到就能用）

1. **图片评论回复**：每条视频挑 3–5 条评论，用对应表情回复（B站支持图片评论）——最高性价比的"活人感"。
2. **视频花字**：情绪点直接贴表情，代替语气字幕（比文字更抓眼）。
3. **举牌互动**：置顶评论「举牌说你想说的」，把留白牌子做成可复用模板。
4. **每日账本配图**：当天什么状态就配什么表情（摸鱼/加班/暴富/裂开）。
5. **固定口头禅**：给小恐龙定 3 句台词，反复出现（「已摸鱼」「收到！」「裂开了」）。
6. **转场动画**：用 walk / standup 做镜头转场（"它走过来"接下一个镜头）。
7. **等待镜头**：视频里「正在跑模型…」用 idle 循环，天然的解释性画面。
8. **撞脸联动**：和鲸鱼娘同框——两个"在运营"的角色互怼，赛道内自带话题。

## 4. 设计感（让它不像随手画）

- **统一构图**：所有表情固定安全边距、**脚踩同一条基线**（脚本已做底部对齐）。
- **动效三原则**：呼吸感（待机必须轻微起伏）／预备-动作（跳之前先蹲一下）／跟随（尾巴和手晚 1 帧）。
- **色板纪律**：只允许上面 6 色，新图不许出现新颜色。
- **成套出现**：表情永远 9 格成组，不零散发布——成套才有"这是套资源"的感知。
- **命名规范**：`dino-<组名>-<序号>`，方便脚本批量调用、也方便别人二次创作时溯源。

## 5. IP 价值阶梯

| 阶段 | 动作 | 价值 |
|---|---|---|
| **L1 素材** | 序列帧 + 表情包成套产出（已具备） | 内容成本趋零，账号形象统一 |
| **L2 人格** | 让它回评论、发动态、当视频里的"实习生" | 观众会开始喊它的名字，形成记忆点 |
| **L3 传播物** | 投稿 B站动态表情 / 做成手机壁纸、输入法皮肤、桌面宠物 | **破圈**：别人主动传播你的 IP |
| **L4 周边** | 徽章 / 亚克力挂件 / 贴纸包；**接 ANS 已有的 3D 打印管线**（拓竹 4 色 AMS 直接打小恐龙手办） | 变现 + 实物曝光 |
| **L5 品牌资产** | 官网加载动画、空状态、错误页；开源项目 README 吉祥物 | 从"账号资产"升级为"公司 IP" |
