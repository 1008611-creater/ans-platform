# 《ANS · AI Never Stops》
## AI 项目发现、创作与交易平台 · 权威版本制作与上线方案

## 一、产品定位与制作目标
你是一名世界顶级的互联网产品负责人，同时具备产品经理、交互设计师、视觉设计总监、前端架构师、后端与数据库架构师、支付与计费工程师、性能工程师、安全工程师、内容编辑、测试负责人与发布工程师的全部能力。

请独立完成 **ANS（AI Never Stops）** 的权威版本，并上线到 https://ans.cauai.fun 交付验收。
这是一个已经在运行的真实网站，有真实用户、真实积分余额和真实订单。仓库 `1008611-creater/ans-platform`，技术栈 Next.js App Router、React、TypeScript、PostgreSQL、Prisma，生产部署在 `haika-1757`。

用户来到 ANS，可以发现值得用的 AI 项目，在主题 Hub 里系统学习，用 Agent 和工作流真正把事情做出来，把作品拿去社区展示和参赛，再把能交付的成果放进市场出售，赚到的积分继续用来创作。

本项目最重要的三个制作关键词：
- **真实可信**：页面上每一个数字、每一个状态、每一件商品、每一次扣费都是真的。宁可展示一个设计精良的空状态，也绝不展示一条编造的数据。
- **审美强**：拥有统一、克制、成熟的视觉语言，像一款被精心打磨的独立产品，而不是功能拼盘、后台模板或 AI 生成的套壳站。
- **快**：国内用户打开任何一页都不需要等待，任何操作都有即时反馈。

ANS 不能只是一堆能点开的页面，而应当是一个用户愿意每天打开、愿意充值、愿意把作品放上来、愿意推荐给同学的产品。

## 二、品牌与文字
1. `ANS` 只能写作 **AI Never Stops**。
2. 站内助手统一叫 **Agent**，工作台的创作空间叫 **工作模式**。界面、URL、商品标题和交付文本里都不出现任何内部代号（Pi Agent、Pi-Codex、Pi Tool 等）。
3. 文字像一个靠谱的同行在说话：直接、具体、短。不用 `赋能`、`矩阵`、`闭环`、`底座`、`四段式`、`主理人`、`欧皇`、`天选锦鲤`、`暴击` 这类词，不用营销腔和感叹号堆砌。
4. 说明文字分层：一眼能看懂的按钮和布局不加小字；次要参数悬停才出现；长规则、价目表、示例收进可展开区域。同一条规则在一个页面只说一次。
5. 中英文双语完整，所有界面文字走 i18n。

## 三、信息架构
全站只有六个一级入口，每个入口一句话就能说清它是干什么的：

| 入口 | 用户来这里做什么 |
|---|---|
| `/explore` 项目广场 | 发现真实、值得用的 AI 项目，看清它能做什么、怎么开始 |
| `/hubs` Hub 与工作流 | 按主题（CAUHub、VibeHub、AIGC、全栈开发）系统学习，一键运行经过审核的工作流 |
| `/community` 社区成长 | 展示作品、交流、积累真实的成长记录 |
| `/competitions` 赛事活动 | 报名、组队、提交、评审、公示结果，每一步可追溯 |
| `/market` 市场 | 买卖真实可交付的工具包、服务与可运行工作流 |
| `/workspace` 工作台 | 我的项目、工作模式、Agent、积分与账单 |

**重点要求：**
1. 任意页面三次点击之内到达任意核心功能。
2. 桌面和手机都是一等公民。手机有底部导航，375px 宽度下任何页面都没有横向滚动。
3. 首页在三秒内让第一次来的人明白：这是什么、对我有什么用、第一步点哪里。

## 四、代码收敛与架构重建
这是速度和质量的最大杠杆：先收敛，再按产品重建。

### 收敛
1. 仓库里只留网站本身。
2. 删除所有从线上路由不可达的代码、组件、内容和资源；已退役的旧地址保留 308 跳转，代码一律删除。
3. 删除脏内容：编造的统计与动态、夸大的商品文案、写死的价格与倍率、不存在的模型名、硬编码的界面文字。
4. 数据库表和数据不随代码删除；不再使用的表先停止读写，归档另行评估。

### 重建
1. 按六个入口组织功能模块；账号、积分账本、模型网关、计费策略、i18n、UI 组件库、存储作为共享平台层。
2. 依赖方向清晰：页面 → 组件 → 领域与契约 → 服务端；客户端永远碰不到数据库和密钥。用自动检查守住边界和死代码，让收敛后的代码不再长回来。
3. 价格、倍率、模型可用性各只有一个真实来源，展示和扣费读同一份数据。
4. 每个模块都有精心设计的空状态、加载状态、错误状态和权限状态。

拒绝"先全部推倒再慢慢补"。网站始终在线，每一步都能单独上线、单独回滚。

## 五、核心体验
### 项目广场与 Hub
- 图像优先：每个项目都有一张能单独拿来做宣传的封面。
- 项目详情只写真实信息：它是什么、能做什么、怎么开始；没有虚构的拆解、评分和使用人数。
- Hub 的成员由人工策展；还没有内容的 Hub 用一个好看、有引导性的空状态，而不是显示一个冷冰冰的 0。

### Agent 与工作模式
- Agent 回答直接、准确，能调用站内工具查询真实数据、替用户起草项目、推荐下一步。
- 每次付费调用前先报价，用户确认一次，执行中看得到进度，结束后看到实际花费。
- 上游不可用的模型在选择器里灰显并说明原因，绝不让用户确认一笔注定失败的调用。
- 在工作模式里写代码、改代码、预览成果是一个流畅的整体体验。

### 社区与赛事
- 作品、点赞、评论、成长记录全部来自真实用户行为。
- 赛事从报名到公示的每一步都有状态、时间和记录；没有确认的日期就写"待确认"。

### 市场
- 每件商品的标题、描述、交付清单都与实际交付一致；交付不到位的商品不上架。
- 购买、交付、确认、评价、退款、卖家收入，每一步都有记录、都能对账。

### 积分与计费
- 充值固定 ¥1 = 10 积分。
- 模型消耗按"官方美元价 × 快照汇率 × 10 × 模型倍率"计算，倍率只来自计费策略这一个来源。
- 每一笔扣费都能在账单里看到模型、用量、倍率、金额和时间；不确定的扣费有明确的处理流程，不会悄悄变成零，也不会悄悄多扣。

## 六、视觉与交互
整体定位：克制、通透、有质感的现代产品设计。

**重点要求：**
1. 统一的字体、字号层级、间距、圆角、阴影和色彩体系；深色和浅色模式都精致。
2. 图像优先：封面、作品截图和预览承担主要信息，文字只补充图像说不清的部分。
3. 每张卡片只有一个主要操作。
4. 动效流畅、克制、有意义：状态变化、展开收起、页面切换都有反馈，没有花哨的装饰动画。
5. 每一页都经得起截图：拿任意一页做宣传图都不丢人。

拒绝模板感、拼贴感、过度渐变和霓虹、信息密度失控、按钮堆叠，以及任何"看起来很忙"的假活跃。

## 七、性能
1. 国内普通网络下，任意公共页面首字节小于 800ms，最大内容绘制小于 2.5s；并发访问时不明显变慢。
2. 每页只下发它用到的文案和数据。
3. 匿名可访问的公共页面能被 CDN 缓存，登录相关部分在客户端补齐。
4. 数据库查询并行化，跨地域往返次数降到最少；必要时评估数据库就近部署。
5. 所有性能结论以真实测量为准，分清源站、服务器前置层、CDN 和用户网络各自的耗时。

## 八、安全、可靠与发布
1. 密钥只在服务端，永不进入浏览器、日志或仓库。
2. 涉及钱的每一步都有幂等键、事务、审计记录和对账。
3. 每项改动一个 PR，CI 全绿（`Test`、`Authority`），并由不带作者上下文的独立审查者盲审，结论贴在 PR 上，阻断问题处理完再合并。
4. 带数据库迁移的发布先通过生产备份的真实恢复验证。
5. 生产发布、生产数据库写入和支付配置变更，执行前向负责人确认；上线后在公网用桌面和手机各走一遍核心路径，留下截图和测量数据。

为了以最快速度交付一个可以验收、可以骄傲展示的版本，先完成能体现 ANS 全部核心魅力的权威版本：

**首个版本包含：**

3. 价格、倍率、模型可用性全站一致，Agent 从报价到账单完全对得上。
4. 市场上架的每件商品都与交付一致。
5. 公共页面达到第七节的性能目标。

**实现真实可用的核心路径：**
发现项目 → 进入 Hub 学习 → 用 Agent 或工作流做出成果 → 看到真实花费 → 发布到社区或参赛 → 上架市场 → 被购买 → 收入回到账户 → 继续创作。

## 十、最终质量要求
本项目必须始终坚持以下最高优先级：

**第一优先级：真实可信**
随机抽查任意页面上的任意数字、任意一笔扣费、任意一件商品，都能在数据库和账本里找到来源，报价、扣费、账单三者一致，买到的东西与描述一致。

**第二优先级：审美强**
第一次打开的人仅凭一张截图就能感受到这个产品的品位和用心。每一页都有统一的视觉语言、清晰的信息层级和恰到好处的留白。

**第三优先级：快**
公网实测达到第七节的指标；任何操作都有即时反馈，没有让人怀疑"是不是卡住了"的时刻。

不允许为了增加功能数量而牺牲真实性和品质。宁可减少入口里的次要功能、减少商品和内容数量，也要保证呈现出来的每一页都真实、精致、流畅。

**最终目标：** 交付一个真实可信、审美极强、快速流畅的 AI 项目平台。
一个第一次来的用户，五分钟内能独立走完核心路径，并且觉得：这个网站是认真做的，我可以相信它。

可以自由、独立地决定产品取舍、技术方案和实施顺序，以已上线、可验收、真实可信和完成度作为最终交付标准。
