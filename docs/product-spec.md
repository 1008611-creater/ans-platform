# ANS 产品规格

## 定位

面向 CAU 学生的 AI 能力社区。ANS 与 CAUHub 同源但独立运行，首期通过学校邮箱和邀请码控制成员入口。

## 核心用户

- 学生：发现、运行、收藏、复用能力。
- 创作者：创建 Prompt、模板和工作流。
- 审核者：维护内容质量和校园合规。
- 管理员：管理成员、权限、配额和审计。

## 核心循环

当前已实现：`发现 → 运行 → 收藏 → 复用`

下一版本先执行 [V0.2 十人验证](./V0.2-十人验证.md)：`选择项目 → 填写事实 → 生成成果 → 确认 → 导出`。真实工作流、额度和公开审核在验证通过后继续。详见 [MRD](./MRD.md)、[PRD](./PRD.md)、[BRD](./BRD.md)。

## 首期内容

Prompt、模板、有限 DAG 工作流。工作流支持 Prompt、模板、模型调用、条件和输出整理节点，不支持开放式自主 Agent。

## 非目标

- 不做泛化社交网络。
- 不开放完全匿名注册。
- 不把 CAUHub 和 ANS 合并为一个数据系统。

## 关键失败场景

- 邮箱未验证、邀请码失效或超限。
- 内容未通过审核。
- 工作流存在环、节点非法或额度不足。
- 模型调用超时、失败或返回不可用结果。
- 用户没有权限访问私有内容。

## 审核策略

模板和工作流采用「AI 初审 + 人工复核」两层把关：AI 负责初筛合规、质量与意图，
人工负责最终判断且不能审核自己的内容。AI 服务不可用时内容保持待审，
只有「服务端从未配置初审」这一种情况才退回纯人工把关，且该降级原因对审核者可见。

## 长期方向与当前范围

长期方向是面向学生的 AI 原生社区与成果生产平台，围绕求职、赛事、作品和能力提升提供引导、内容、工作流、团队协作及成果展示。该愿景按[平台方向与落地路线图](./ANS平台方向与落地路线图.md)分阶段展开。

当前最近的产品门槛仍是 V0.2 私密学生项目包十人验证。新手增长体系、开放作品广场、完整赛事系统、外部 Agent 联动、多端原生客户端和商业化均不自动并入 V0.2；它们须等前置验证、授权模型和运营责任具备后再进入独立版本。
