# 项目广场与三类详情页

## 目标
L，多模块公开产品界面。以 main fbffecec 为基线，隔离分支实现，提交 PR 交 ANS-01 主控审查发布。
REQ-001：项目详情突出真实成果、适用人、准备条件、开始步骤、门槛、来源与许可。浏览不执行、不扣费。
REQ-002：新增至少12个不重复的高质量项目，逐个读官方仓库/文档，提供具体做法和限制；补全重点旧项目指南。
REQ-003：工作流展示已发布版本的真实输入、执行顺序/依赖、产出与人工决策边界；无效版本禁止运行。
REQ-004：市场展示真实商品版本、交付清单、价格档位、周期/修改、许可与卖家，保留订单与账户规则。
REQ-005：三类页面有独立结构和主操作，保持响应式、键盘操作、主题及中文/英文。
REQ-006：来源与核查日期可追溯，不虚构演示、维护、价格、评价或用户成果。

## 边界
NON-001：不改认证、支付、运行API、DB schema；不新增依赖，不触碰主控树、不独立部署。
NON-002：不新增大批测试；按用户要求做差异核对、类型、lint、构建与必要现有检查，不付费生成、不生产写入。
RULE-AUTH-001：主控统一合并发布；原账户边界及所有权不变。
RULE-DATA-001：只用已发布公共快照，不读取私人项目事实。
RULE-DATA-002：编辑指南绑定准确slug与来源URL，管理员替换来源后不得套用旧指南。

## 分工
TASK-001：根代理负责公开项目详情、集成、翻译合并与发布交接。
TASK-002：内容代理负责新增内容及来源核实，不改公共页面与共享翻译。
TASK-003：工作流代理负责详情和专属组件样式；翻译独立JSON由根代理合并。
TASK-004：市场代理负责详情和专属组件样式；翻译独立JSON由根代理合并。
TASK-005：完成后独立审查代理逐项核对，不修改实现。

## 验收
AC-001 (REQ-001,005)：项目首屏明确成果与真实入口，正文有做法、门槛、来源、相关项目，无假运行按钮。
AC-002 (REQ-002,006)：至少12新项目来源明确、分类合法、不重复；每项有官方引用、实际日期、具体操作与限制，重点旧项目有专用指南。
AC-003 (REQ-003,005)：工作流按真实定义展示，保留登录回跳、收藏、主人管理、收费确认，无效版本不挂载执行表单。
AC-004 (REQ-004,005)：市场展示精确版本与真实交付/许可；保留免费/付费、积分/现金、特殊编辑器、主人/匿名状态。
AC-005 (REQ-005)：类型及相关lint通过，实际核对桌面手机布局与溢出，失败如实记录。
AC-006 (REQ-006)：提交无密钥、env、用户素材；审查和PR区分完成与未验证，未部署不声称上线。
