# 市场个人网站产品交付记录

本轮按用户 2026-10-15 确认的方向收尾；早期通用工作流广场方案为历史内容。PR 91，任务分支 `codex/workflow-studio-foundation-20261014`，已同步主分支 `7cd2fbd8`，保留四视图生成和小恐龙恢复更新。本轮交付是开发与 PR，未合并 main、未部署生产。

## 实现

- 一级发现入口仅项目广场和市场；通用 `/workflows`、公开详情及旧配方详情引导到市场。私密作者工具、审核、执行 API、运行历史和计费保留。
- `/market/resume-website` 保留完整专用 3D 演示与模型、贴纸、镜头、内容编辑器。市场壳说明真实成果、所需资料、免费编辑导出、独立 AI 费用、版本、隐私与许可。已配置能力与未开放能力分别显示。
- 文案任务进入原有 3D 编辑器与交付面板；完整规范化输入摘要匹配后，用户主动应用文字。模型、镜头、贴纸保留，可撤销；更改内容后核对确认失效。文案 HTML 明确标注为非 3D 成品。
- 已保存私密网站从工作台恢复后，继续使用同一已审核市场版本的文案入口；商品撤下时仍允许手动编辑已保存作品。
- 市场规范别名核对平台注册、作者、精确 slug、当前已审核发布版与完整执行绑定，拒绝历史匹配接管。
- 普通运行恢复按账号与工作流保存任务引用和原意图位置；刷新先读取状态，未知状态持续只读查询，不重新执行收费请求；终态保护和精确旧意图清理避免晚到状态与旧 key 污染。
- 手机工具栏采用两行，预览与交付按钮不挤成竖排，时间线给站点底栏留出空间。市场页面只保留一个 main 与主标题，移除嵌入重复导航。清理无依据的五分钟承诺和英文乱码。
- PRODUCT、DESIGN、AGENTS、架构总纲与 ADR 统一后续市场产品标准：真实成果、明确输入与费用、专用成果编辑、共享执行和完整交付；不以通用运行表单代替产品。

## 实际验证

- 14 个受影响测试文件，208 个用例通过，包括运行恢复、账号隔离、平台配方、市场绑定、文案应用、3D 编辑、导航和主分支四视图界面。
- 全量 ESLint：0 error、355 warning；没有声称清零存量 warning。最后新增的恢复页面另做相关 ESLint，通过。
- 全量生产与测试 TypeScript 通过；使用隔离生成的当前 Prisma client，未修改共享 node_modules。
- 最终 webpack 生产构建通过：108 个静态页；分层 1149 文件、六类约束通过；113 文档链接通过；diff --check 通过。
- 隔离 PostgreSQL 的新空数据库部署当前 87 个迁移，包括主分支已有的四视图迁移。未修改生产或共享数据库。
- 真实浏览器登录合成账号、填写内容、新增镜头、下载草稿并重新导入；浏览器 POST 建立真实任务，通过真实执行引擎和真实 HTML 产物适配器运行。只替换模型处理器为确定性合成文案，不调用付费上游。
- 浏览器看到成功记录后主动应用、确认、保存私密 v1、下载完整 HTML，并从保存入口重新打开。数据库核对模型、贴纸保持，镜头值按 1e-12 容差保持；JSONB 浮点末位差异未当成几何变化。导出 HTML 为 7,632,524 字节，包含内嵌运行时与模型。
- 未配置模型的一次真实失败退回一次积分；第二次模拟模型成功后余额从 100 变为 98。打开和恢复页面未新增任务。仅证明隔离计费记录与状态链，不等于生产计费验收。
- 浏览器检查中文、英文、390px 手机布局、旧配方链接到市场的跳转、未保存退出阻止和恢复页历史读取。手机与桌面最终截图留在本地证据目录。

## 验证边界与发布交接

- 真实模型质量、图片/3D 付费生成、在线托管、域名、线上账号和生产计费本轮没有试跑。页面根据配置显示真实可用范围，不把未开放服务当成已完成交付。

- 本地服务用 localhost 默认来源完成写入；127.0.0.1 来源的写请求被同源保护拒绝，没有为验收关闭此保护。
- 沿用现有 three.js 运行时和既有参考素材，无新增依赖、第三方代码拷贝或生产图片修改。本轮核查 three.js 编辑器历史序列化与 Reactive Resume 的编辑/导出结构作为方法参考，不宣称移植其实现。来源：https://github.com/mrdoob/three.js/blob/dev/editor/js/History.js ，https://github.com/reactive-resume/reactive-resume 。
- 本地 DB、合成账号、脚本、截图、构建和日志均位于 Git ignored `.workbuddy/evidence/market-maturity/`，不上传。
- 主控按 PR 的精确 head 审查，适用 CI 通过后合并 main；部署明确 main SHA，保留前一生产镜像/发布目录为回滚入口。本轮相对当前 main 无新增数据库迁移。发布前核对规范配方登记、模型 worker、费用配置、独立发布域名与未开放能力的呈现；发布后验收项目→市场→保存/导出及任务恢复。PR 与本地完成不代表已上线。
