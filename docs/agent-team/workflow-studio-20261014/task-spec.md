# 应用式工作流底座

任务等级 L。基准 main 50a80ea3，分支 codex/workflow-studio-foundation-20261014。

REQ-001：通用工作流采用成果优先的落地展示和可进入的工作室，左侧配置、右侧成果，兼容移动端、主题、键盘与减少动效。
REQ-002：不可变 definition 可携带有界 experience v1，阶段绑定真实节点。旧定义自动推导；固定 resume recipe 不变，不放宽其精确校验。
REQ-003：作者默认可视化编辑名称、输入、模型步骤和产物。已有复杂分支与未知 config 保留，通过高级 JSON 编辑。任何编辑后必须重新验证，未保存离开保护。
REQ-004：公开项目可作为创建参考，保留出处和输入/产物说明。只创建私有草稿，不自动执行外部代码，不自动建立未经审核的公开联动。
REQ-005：工作室复用现有运行、账号隔离、收费、幂等和恢复链。状态来自真实运行记录，无模拟完成/进度。结果安全预览、复制、导出。
REQ-006：工作流目录与 hub 成员工作流显示同一成果形式，只投影审核发布版本的有界信息。
NON-001：不改变支付、认证、数据库迁移、现有3D专用编辑器；不接入虚构图片/视频/外部源码运行器；不自行生产部署。
RULE-AUTH-001：来源仅服务器公开项目目录，输入不自动存 localStorage，不公开用户资料。
RULE-DATA-001：体验元数据只控制展示。markdown 禁用原始 HTML；不任意执行生成 HTML。
AC-001：旧定义进入工作室；准备阶段不显示假结果，成功后可预览/复制/导出，失败状态明确；移动端不溢出。
AC-002：重复阶段、未知节点、重复绑定、漏节点、逆向阶段顺序被拒；recipe 精确校验保持。
AC-003：可视化新建和编辑并校验保存；既有高级定义无损；改动后校验失效；离开提醒。
AC-004：项目详情有创建入口，带公开来源预填，登录回跳保留来源，未找到来源明确返回提示。
AC-005：运行复用收费入口，重复点击不创建第二次；真实节点记录显示；未知连接只查状态；退出不丢正在运行的状态。
AC-006：目录展示仅由审核发布定义推导公开元数据，不泄漏 config/review/私有草稿。
AC-007：类型检查、相关 lint、已有 workflow 风险验证、生产构建与本地浏览器视图完成并区分未验证生产运行。
