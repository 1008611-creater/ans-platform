# Design

Preserve the deployed ANS system: Next.js, Tailwind, Radix/shadcn controls, system sans font, light/dark CSS tokens and primary accent. Audience browses on laptops and phones in campus/daytime environments, so retain both existing themes with the user's setting.

Use existing PageHeading, ans-product-shell/container/catalog grid and authentic GitGlow covers. Hub directory uses four distinguishable organizational/category entries with actual destinations, compact descriptions and honest content counts. Keep six primary navigation items without a More overflow list; collapse to a mobile sheet when needed. Account menu contains personal utilities, not public content categories.

Spacing and typography follow existing app classes. Long headings wrap, navigation states are visibly distinct, controls remain keyboard focusable and touch friendly. No new font download, ornamental animation or decorative glass/gradient. Motion only communicates state and respects reduced motion. Do not create or modify production bitmap art during this refactor.
