# ANS IP 像素卡通形象生产线

输入「要什么动作」→ 输出**可直接用的透明序列帧 + 精灵图 + GIF + 网页图集 + 质检报告**。

---

## 1. 形象规范（Lock，违反即重出）

### 1.1 比例（硬指标，2026-10-21 实测定稿）

| 指标 | 目标值 | 说明 |
|---|---|---|
| **头宽 / 整体身高** | **0.85 – 0.90** | 头又**宽**又扁圆，是全身最宽处 |
| 身宽 / 头宽 | 0.75 – 0.85 | 身体明显小于头 |
| 最宽处高度 | 40% – 45% | 视觉重心偏上 |
| **脖子** | **绝对没有** | 头身直接相连、无分界线，平滑过渡成一颗团子 |

> **翻车记录**：只写「头占 60% 高」而不锁**头宽**，模型会把头变窄变高（实测掉到 0.79），整体被拉长，立刻不可爱。
> **比例必须写成数字，并且必须用 `--ref` 锁住。**

### 1.2 色板
薄荷绿 `#9BE0C5` / 奶油白 `#FBF6E9` / 深蓝描边 `#1B2559` / 亮绿高光 / 淡粉腮红 / 金色点缀。

### 1.3 脸与眼睛系统
大黑眼珠 + 白色高光 + 横向奶油白下脸块 + 小 U 微笑 + 淡粉腮红。
眼睛六式：豆豆眼（默认）/ 弯眼（开心）/ 半眯（无语）/ 空心大眼（震惊）/ 黑点+汗（尴尬）/ 灰白（石化）。**新表情一律从这六式组合**。

## 2. 权威图（不可自行替换）

**`assets/ans-ip-authority-board.png` = 用户指定的权威板。**

1. 权威板由**用户指定**，代理**不得自行挑选或替换**；
2. 用户给的图**原样归档**，不要重新解释；
3. 权威板对应「最早那批」源图（`dino-anim-walk` / `dino-memes` / `dino-memes2`）——**这批源图就是权威本身，不要「改良」它们**；
4. 其它动作组用权威板做 `--ref` 重出。

> 翻车记录：本技能第一版自己从成品里挑了一张帧当权威，被用户否掉：「你找到那个权威图不是我给你的权威图」。

## 3. 首选：一次出 8×8 = 64 格

**一次生成里 64 格共享同一次采样，风格 / 比例 / 描边天然一致**，约 55 秒；分组出图要 8 次调用且会互相漂。

```powershell
& "<python>" "C:\Users\lsb\.codex\skills\image2.5genskill\scripts\image25_gen.py" ``
  --model gpt-image-2.5-sunburst-c --size 2880x2880 --quality high ``
  --ref assets/ans-ip-authority-board.png --prompt "<64 格提示词>" ``
  --out assets/gen/dino-grid-8x8.png

python scripts/grid_64.py      # 切 64 格 → 抠白 → 归一化 → 帧 + 主图 + 8 行动画 + GIF + 总览 + 质检
```

- **尺寸必须 `2880x2880`**（模型支持的最大方形），8×8 时每格 **360px**。
- 提示词三段：**整体要求**（8 列 8 行、每格同一角色、严格对齐、居中、比例配色一致）→ **逐行逐格动作**（64 格必须各不相同）→ **禁止项**（不要网格线/文字/水印/阴影；每格完整、不断裂漂浮、不画出格）。
- 网格的**格子边界就是裁剪线**：速度线、火焰、道具会被切到邻格，切格后必须目视检查。

## 4. 切帧管线

```powershell
python scripts/sprite_frames.py        # SETS 表驱动
python scripts/grid_64.py              # 8×8 网格专用
```

流程：**边界洪泛抠白 → 按网格切格 → 内容裁剪 + 水平居中 + 底部对齐归一化 → 帧 + 单行精灵图 + GIF + 总览 + 质检**。

> 警告：抠白必须用**从画面边界洪泛**（只删与边界连通的白色）。用「白色→透明」一刀切会把**眼白、爆米花、白色木牌**抠穿。

---

## 5. 缩放纪律（像素画专用，违反即糊）

**像素画只能用 NEAREST，永远不要 LANCZOS / BILINEAR。** 三步：

1. **BOX 下采样**到原生像素网格（本 IP 实测内容高度 **120 原生像素**）；
2. **硬 alpha**：alpha 阈值化（>110 → 255），否则 GIF 会出现半透明灰边；
3. **NEAREST 整数倍放大**（128 格 → ×1；256 → ×2；512 → ×4）。

> 翻车记录：用 LANCZOS 把 400px 帧缩到 256px 做贴纸，硬像素块被插值糊掉，用户一眼看出「像素太低了」。
> 颜色**不要**做调色板量化（会灰阶断层）；要更「像素」的观感就**降低原生网格高度**（如 72），而不是砍颜色。

---

## 6. 质检（必做，交付前逐格看图）

**脚本自动**：① 墨量离群 ② 相邻帧几乎相同 ③ 比例自检（`scripts/measure_proportions.py`）。
**人工逐格**：完整性（断肢/漂浮）、姿态是否真不同、朝向一致、描边闭合、内部白色是否被抠穿。

> 注意 1：带道具的帧最宽处会落在道具上，属正常。
> 注意 2：**墨量离群会被大件道具误报**（白板讲解 / 深夜加班实测为中位 1.4 倍，画面正常）。脚本只负责标红，**判红必须看图**，确认是道具就记「误报」，不要盲目重出。
> 注意 3：**质检不是可选项**——曾把「8 格几乎相同」「某格结构断裂」的成品直接交付，被用户当场指出。

## 8. 常见失败模式（都真实踩过）

| 症状 | 原因 | 处理 |
|---|---|---|
| 头变窄变高、整体拉长 | 没锁**头宽** | 写 0.85–0.90 数字 + `--ref` |
| 脖子明显、像拼起来的玩具 | 模型把头身当两个部件 | 明写「无脖子/无分界线/平滑过渡」+ `--ref` |
| 8 格几乎一样 | 姿态描述太模糊 | 每格逐条写清不同姿态 |
| 某格断裂 / 漂浮 | 模型漏画部件 | 明写完整性约束；看质检墨量离群 |
| 眼白 / 道具被抠穿 | 用了「白色→透明」 | 改用边界洪泛 |
| 播放抖动 | 各帧位置尺寸不一致 | 归一化：裁剪 + 居中 + **底部对齐** |
| 画面发虚、边缘糊 | 用了 LANCZOS 缩放 | 见第 5 节缩放纪律 |
| 出图比例风格漂了 | 代理自己挑参考帧 | 一律用用户指定的权威板做 `--ref` |
| SETS 换名了但「新图没生效」 | SETS 里文件名没跟着换 | 核对源文件名与生成一致 |
| skill 从技能列表消失 | YAML frontmatter 被破坏 | 检查文件首部 `name` / `description` 是否完整 |
