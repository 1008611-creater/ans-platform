# PRODUCT.md

## Product Purpose

刘曙宾的个人作品集与在线简历，部署在 https://resume.lsb0713.online。

它只服务一件事：让招聘方在 3 分钟内判断「这个人能不能做 AI 产品与智能工作台方向的工作」，
并留下可以继续细看的证据。不是博客，不是名片页，不做内容沉淀。

## Register

brand

理由：作品集本身就是被交付的设计对象。访客对页面的第一印象，就是他对我审美与工程能力的判断。
页面的表现形式不是承载内容的容器，它自己就是作品之一。

## Users

两类人，使用场景完全不同：

1. **招聘方与业务负责人。** 白天在办公室的显示器上打开，可能同时开着五个候选人的链接，
   注意力只有几十秒。他们要看的是：做过什么、做到什么程度、是不是真的自己做的。
2. **同行与合作方。** 深夜在笔记本或手机上打开，愿意慢慢拖动画廊、翻看细节。
   他们在意的是手感和完成度，会点开每一个案例。

第一类人决定我能不能进面试，第二类人决定我值不值得被推荐。两者都不能牺牲。

## Brand Voice

克制、笃定、有手感。

像一份排版讲究的印刷品，而不是一个网页。话少，但每一句都是真的。
不用感叹号，不用营销话术，不承诺做不到的事。

## Strategic Principles

1. **真实优先于好看。** 所有数字、项目、成果必须来自作者本人的真实经历，逐条可核对。
   宁可少写一个案例，也不编造一个数据。
2. **证据优先于形容词。** 「推进了复杂项目」不算证据，「77 个核心文件形成完整工程雏形」才算。
3. **第一屏就要有分量。** 访客不会滚动探索，第一屏必须直接给出作品本身，而不是先解释我是谁。
4. **深色克制。** 页面大部分是墨色，让作品截图自己发光。不用花哨装饰抢内容的注意力。
5. **手机端不将就。** 招聘方会在通勤路上用手机点开链接，移动端必须是完整体验，不是桌面端的缩水版。

## Anti-References

明确不要的东西：

- **模板化的个人主页**：头像加一句 slogan，下面一排社交图标。
- **hero 数字看板**：巨大数字加小标签加三个统计块，SaaS 落地页的陈词滥调。
- **卡片瀑布流**：等宽等高卡片重复排列，看不出主次。
- **玻璃拟态堆叠**：模糊半透明卡片，与纸墨方向直接冲突。
- **渐变文字**：装饰性大于表意，属于明确禁令。
- **荧光配色**：参考站使用的荧光薄荷绿一律不用。
- **用力过猛的动效**：滚动劫持、满屏粒子、进入前强制等待。

## Constraints

- 不引入需要付费授权的字体与素材，全部使用 SIL Open Font License 1.1 字体与作者自有项目截图。
- 不使用 Tailwind，手写 CSS 加设计 token。
- 尊重 `prefers-reduced-motion`，开启后停掉全部装饰性运动，内容保持完整可读可操作。
- 简历页需要能被单独分享并导出为 A4 PDF。
