## 1. 七维结构 schema

### 1.1 macrostructure（宏结构）

参考站是「单页 + 双视图」：

1. 全屏入场门，先做一次「是否带声音进入」的二选一；
2. 门后直接进入内容本体，没有 hero → 特性 → CTA 的分层营销结构；
3. 同一批作品用两种互斥视图呈现：立体画廊 / 巨型文字索引；
4. 固定 chrome 覆盖在内容之上，不随滚动消失；
5. 详情由独立页面承载，而不是弹层。

**采纳**：完整保留这套宏结构。
**偏离**：参考站的画廊是真三维 WebGL；本项目用 DOM 变换加透视投影实现螺旋，不做完整 WebGL。

### 1.2 hero archetype（主视觉原型）

参考站没有独立 hero 区块，进入即是可操作的画廊，画布本身就是页面。

**采纳**：首页首屏就是可拖动、可滚动的螺旋画廊。
**偏离**：作品集需要一次身份交代，参考站有品牌名可依赖，本项目在首屏左上角保留极短的一行定位信息。

### 1.3 display_role（展示字角色）

参考站是严格的两段式：展示字只用于条目名称，等宽小字承担全部元信息。

| 角色 | 变量 | 用途 |
|---|---|---|
| 无衬线 | `--font-sans` | 正文与标题主体 |
| 衬线斜体 | `--font-serif` | 只做单点强调，中文姓名与英文项目名 |
| 等宽 | `--font-mono` | 序号、类目、日期、按钮标签，全大写加宽字距 |

**偏离**：参考站展示字是纯几何无衬线。中文语境下把衬线斜体引入展示层，让中文与英文项目名形成对比，避开「又一个极简无衬线作品集」。

### 1.4 paper_band（纸与墨色带）

| 角色 | 参考站 | 本项目 |
|---|---|---|
| 墨 | 冷近黑 | `#0b0b0c` 中性偏暖墨 |
| 纸 | 冷近白 `#fafafa` | `#f2ede4` 暖骨白 |
| 强调 | 荧光薄荷 `#21ffc0` | `#ff4a2b` 朱砂 |

理由：项目里有两个强中国语境的作品（古建交互、品牌包装量产），朱砂是从项目本身长出来的颜色。

### 1.5 accent_hue_band（强调色相带）

参考站强调色只出现在当前态、悬停态与焦点环上。本项目沿用该约束，朱砂总覆盖面积控制在 5% 以内；深色底上的大面积色块一律不用，改由骨白面板承担「第二张纸」的角色。

### 1.6 density（密度）

参考站是低密度、大留白、强节奏。本项目取 `--beam: 1180px`（1600px 以上放宽到 1320px），`--margin: clamp(16px, 3.2vw, 34px)`，分隔只用 1px 发丝线，不靠卡片阴影堆叠层级。

### 1.7 treatments（固定 chrome 组件表）

| 参考站组件 | 本项目对应 | 变化 |
|---|---|---|
| 左上固定 logo | 姓名，悬停弹出一行方向标签 | 由姓名承担 |
| 顶部居中视图切换 | 胶囊分段控件「螺旋 / 索引」 | 同位置 |
| 右上菜单胶囊 | 展开为整屏骨白面板 | 与深色画布形成纸墨对撞 |
| 左下旋转徽章 | 环形文字「刘曙宾 · 作品集 · 2026 ·」 | 同位置 |
| 右下静音键 | 等宽标签的声音开关 | 带电平指示 |
| 全局自绘光标 | 圆点加滞后光环 | 可点元素上放大并转为朱砂 |

## 2. 动效参数

参考站的缓动是两个极端：大位移用指数缓出，小反馈用弹簧。本项目写入 `src/styles/tokens.css`：

- `--ease-expo-out: cubic-bezier(0.16, 1, 0.3, 1)` 面板、遮罩、页面前进
- `--ease-quad: cubic-bezier(0.45, 0, 0.55, 1)` 颜色与透明度
- `--ease-back: cubic-bezier(0.34, 1.4, 0.5, 1)` 小元件归位

附加约束：

- 不动画 CSS 布局属性，只用 `transform`、`opacity`、`clip-path`、`filter`；
- 不用 bounce 或 elastic 作为主缓动；
- `prefers-reduced-motion: reduce` 时停掉全部装饰性运动，内容保持完整可读可操作。

## 3. 被明确拒绝的做法

按 impeccable 的一阶、二阶反射检查，以下做法在本项目中属违规：

| 拒绝项 | 原因 |
|---|---|
| 荧光绿加纯黑加冷白 | 一阶反射，直接照搬参考站配色 |
| `#000` 与 `#fff` 纯色 | 中性色必须向品牌色相偏移 |
| 渐变文字 `background-clip: text` | impeccable 绝对禁令 |
| 玻璃拟态卡片堆叠 | 绝对禁令，与纸墨方向冲突 |
| 巨型数字加小标签加三个统计块 | 绝对禁令里的 hero-metric 模板 |
| 同尺寸卡片网格重复 | 绝对禁令 |
| 双色斜切 hero、霓虹渐变 | 二阶反射，AI 味最重的两个默认审美家族 |
