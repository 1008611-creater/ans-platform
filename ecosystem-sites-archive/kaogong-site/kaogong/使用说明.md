# 备考题本 · 使用说明

河北省考 C 卷（行政执法）专用练习本。**154 套真题 / 8442 道题**，手机、电脑都能用，**完全离线**。

---

## 〇、最省事：直接用已经部署好的站点

浏览器打开：

    https://kaogong.cauai.fun/

第一次打开会出现**中文登录页**，输入访问口令即可（口令单独告知，不写在本文件里）。
登录一次，这台设备会记住 **180 天**，之后打开直接进，不用反复输入。

> 忘记口令怎么办：口令由题本所有者掌握，找他/她要一个新的即可。
> 如果看到的是浏览器自带的英文「用户名 / 密码」弹窗，说明服务器的鉴权服务临时异常，
> 站点自动切回了备用方式，此时用 `owner` + 同一个口令也能进，不影响使用。

打开后建议立刻做一件事：**把整套题存到本机**。

首页有一张「离线题库」卡片，点「下载全部题库到本机」，等它显示
**整套题已存到本机：154 / 154 套**即可。之后断网、飞行模式都能照常刷题。

第一次打开时应用会自动在后台下载题库，看到进度条不用管它，继续做题就行。

## 一、推荐方式：装成手机 App

双击这个文件：

    web/启动-手机访问.bat

会弹出一个黑色窗口，里面列出两个地址：

- **本机打开**：`http://localhost:8765/`
- **手机打开**：`http://192.168.x.x:8765/`（手机要连**同一个 WiFi**）

在手机浏览器里打开「手机打开」那个地址，然后：

- **iPhone**：Safari 底部「分享」→「添加到主屏幕」
- **安卓**：Chrome / 夸克 / 微信浏览器 → 菜单 →「添加到主屏幕」/「安装应用」

添加后手机上会出现「备考题本」图标，点开就是全屏，和 App 一样用。

> 第一次打开会自动把整套题库存到手机里。之后**电脑关机、手机断网也照样能用**。
>
> 用完关闭：直接关掉那个黑色窗口就行。

如果电脑上没有 Node 或 Python，这个脚本会提示你，改用下面的方式二。

## 二、最省事的离线方式

不想开服务器，就直接把这个文件发到手机（微信、QQ、数据线都行）：

    web/备考题本-单文件版.html

用手机浏览器打开就能用，**所有题目都在这一个文件里**，不需要网络、不需要电脑。
缺点是每次要从文件里打开，不能添加到主屏幕。

## 四、功能

- **行测刷题**：一题一屏，点选项立刻判对错，附详细解析
- **限时模考**：按考场节奏倒计时，中途不显示对错，交卷后统一出分
- **筛选练习**：练习页顶部可切「全部 / 未做 / 错题 / 收藏」，只刷没做完的或只重做错题
- **错题本**：答错的题自动收集，集中重做（提分最快的一步）
- **收藏**：每题右上角点星星，把好题、易错题收进「收藏」，考前集中看
- **搜索**：首页或「进度」页搜题干关键词，在全部 8442 道题里找同类题
- **申论精读**：「作答要求」和「给定资料」分栏切换，参考答案点击展开
- **进度保存**：做到哪、对几道，自动存在手机本地，关掉再打开接着做
- **字号**：练习页右上角的 A 键，小 / 标准 / 大随便切
- **进度导出**：换手机时把进度复制出来，在新手机上粘贴回去

## 五、需要知道的两件事

**1. 图形题原图：已配 915 题，仍缺 516 题。**

全库 8,442 题里有 **1,431 题带图形**（判断推理、数量关系、资料分析的图、表、材料）。
应用已把其中的 **915 题**配上了原图，另有 **155 份材料图**：

- 题目里**直接显示原图**，点图片可以放大看细节；
- 选项本身是图的（如「下列哪个图形符合」），也一并显示；
- 材料题的资料图在「给定资料」里显示。

仍然缺图的 **516 题**，是上游数据集本身就没有收录图片的卷子（主要是重庆选调、
黑龙江公安、事业单位联考、广东科学推理，以及浙江/江苏部分数量关系）。
遇到这些题，应用会明确提示「请对照纸质原卷」，你仍然可以在应用里选答案、记错题，
并可以点「跳过本题」不占用练习节奏。

在题库列表里，每套卷都标了「含图 N（已配 M）」，可以据此挑图片齐全的卷子先做。

**2. 单文件版没有图片。** `备考题本-单文件版.html` 为了控制体积没有内嵌图片，
打开时会在顶部提示「图片不可用」。需要看图请用站点或「启动-手机访问.bat」的方式。

**3. 版权。** 题目内容与图形原图来自 GitHub 上公开整理的两个数据集
（`xianhua1/Huahuagongkao`、`ERRRC/xingcezhenti`），两者**都没有附带开源许可证**。所以：

- 可以自己用、给对象用
- **不要**公开部署到网上、不要分享给不特定的人、不要商用

所有答题记录只存在你自己的设备里，不会上传到任何服务器。
