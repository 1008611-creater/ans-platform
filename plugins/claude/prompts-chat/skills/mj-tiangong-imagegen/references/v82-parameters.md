# Midjourney V8.2 权威参数表（2026-08-24 核实）

依据：Midjourney 官方文档（docs.midjourney.com）+ V8.2 API 实测记录（2026-07-27）。被拒绝的参数提交即失败，不要写进提示词。

## 支持的参数（天宫生图会用到的）

| 参数 | 全名/别名 | 作用 | 天宫场景用法 |
|---|---|---|---|
| `--v 8.2` | version | 指定模型版本 | **每条必写**，锁 8.2 |
| `--ar` | aspect ratio | 画幅 | `9:16`（抖音漫剧默认）/ `16:9`（横幅概念图）/ `1:1`（道具档案）。不写默认 1:1 |
| `--raw` | raw mode | 降低模型默认美学偏向，更贴提示词 | 写实天宫场景/角色定妆建议加 |
| `--stylize` / `--s` | stylize | 风格化强度 | 商业写实 200–300；概念艺术/仙侠氛围 400–600；强风格化 ≤750 |
| `--chaos` / `--c` | chaos | 结果随机度 | 稳定资产图 0–10；探索阶段 10–25 |
| `--no` | no | 负面排除（**正文禁写否定句**） | `--no text, watermark, western palace, ...` |
| `--hd` | — | 原生 2048 高分辨率（1.5× 计费） | 验收用母图加；探索阶段用标准档省额度 |
| `--sd` | — | 标准分辨率 1024 | 快速探索 |
| `--sref <URL>` | style reference | 风格参考图 | 系列一致性：垫已验收天宫图 |
| `--sw 0–1000` | style weight | 风格参考强度 | 见 reference-image-playbook |
| `--oref <URL>` | omni reference | 锁人物/物件的身份与形态（**取代 --cref**） | 陈青等角色跨图一致性 |
| `--iw` | image weight | 提示词内嵌图片 URL 的影响权重 | 图生图（垫图+新描述）时用 |
| `--seed` | seed | 随机种子 | **MXAI 代理未开放此入口**，复现改用"同提示词+同垫图+同旋钮值"，满意图回记图片URL/任务ID 而非 seed |
| `--repeat` / `--r` | repeat | 一次跑多组 | 批量出候选 |
| `--p` / `--profile` | personalization | 个性化风格档案 | 可选；V8.2 换过图像池，先跑测试批 |
| `--tile` | tile | 无缝平铺 | 纹理素材 |
| `--weird` / `--w` | weird | 怪诞度 | 天宫默认不用 |

## 已废除 / 被拒绝的参数（写了会失败或被忽略）

| 参数 | 状态 | 替代方案 |
|---|---|---|
| `--cref` / `--cw` | ❌ 仅 v6/v6.1/niji6 有效 | 角色一致性改用 `--oref` |
| `--q` / `--quality` | ❌ V8.1 起移除 | 用 `--hd`/`--sd` 控制分辨率 |
| `--turbo` | ❌ V8 系无 turbo | 用标准或 `--relax` |
| `--niji` | ⚠️ 独立动漫模型 | 本项目要"真人实景质感的写实天宫"，不用 niji；3D 国漫角色走写实锚点而非日系 |

## 提示词正文规则（V8.2 特有）

1. **自然语言成句**：40–80 词，写清空间关系、光线方向、遮挡、纵深。不堆关键词。
2. **禁画质词**：`4k / ultra-detailed / masterpiece / professional / best quality` 全部不写。
3. **正文禁否定句**：不要写 "no people / without text"；排除项进 `--no`。
4. **一图一风格锚点**：只指定一个风格（如 "cinematic film still" 或 "high-end photorealistic concept art"），不混叠。
5. **参数全放末尾**，参数与正文之间留空格，参数之间不加标点。

## 西游之重铸天庭 · 项目权威档（2026-08-26 定案，本项目唯一使用）

```text
--v 8.2 --ar 2:3 --stylize 400 --chaos 12
```

- 抖音发布改 `--ar 9:16`；探索阶段可换 `--sd` 省额度，定稿再 `--hd`。
- **全链禁 `--raw`**（2026-08-26 实证：raw 关闭风格化直奔摄影，把 CG 仿真人拉成真人摄影，是"太真人/太脏"主因之一）。
- 风格锚注入：`--sref <验收图URL> --sw 150`；参考图只锚风格不锚身份。

## 天宫三档预设（通用模板，西游项目内被上方权威档覆盖）

### 档 A：资产定妆（角色/道具母板，要求高度可控、低随机）
```text
--v 8.2 --ar 9:16 --raw --stylize 250 --chaos 5 --hd --no text, watermark, logo
```
> ⚠️ 西游项目禁用本档（含 --raw）。

### 档 B：场景母图（天宫/战场环境，电影感）
```text
--v 8.2 --ar 9:16 --raw --stylize 500 --chaos 12 --hd --no text, watermark, logo, crowd
```
> ⚠️ 西游项目禁用本档（含 --raw）。

### 档 C：氛围探索（海报/开场镜头，强风格化）
```text
--v 8.2 --ar 16:9 --stylize 650 --chaos 18 --no text, watermark, logo
```
> ⚠️ 西游项目不使用本档（stylize 过高会导致主体漂移，以权威档 400 为准）。

> 探索阶段把 `--hd` 换 `--sd` 省额度；构图锁定后再跑 `--hd` 出母图。
