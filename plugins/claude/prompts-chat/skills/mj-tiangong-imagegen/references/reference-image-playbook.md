# V8.2 参考图手册：类型、关联度旋钮与一致性工作流

MJ V8.2 的参考图有四种用法，各自控制不同的"关联度"。**一图只能用一种主旋钮**，混用会互相打架。

## 一、四种参考方式与关联度旋钮

| 方式 | 语法 | 控制什么 | 关联度旋钮 | 天宫用途 |
|---|---|---|---|---|
| 风格参考 | `--sref <图片URL>` | 色调、光线、质感、整体氛围（不锁构图与内容） | `--sw`（style weight） | **系列一致性的主力**：垫第一张验收通过的场景母图，让整部剧同一"摄影质感" |
| 身份参考 | `--oref <图片URL>` | 人物/物件的身份与形态（V8 取代 --cref） | 默认生效，强度不可细调，靠提示词补充 | 陈青/熊妖等角色跨图锁脸锁服装；流光剑等关键道具锁形态 |
| 图生图 | 提示词开头放 `<图片URL>` + 描述 | 构图+内容+风格全面继承 | `--iw 0–2`（image weight） | 同场景换机位/换光线；`--iw` 低=只借色调，高=贴死原图 |
| 垫图（首帧） | 提示词开头放图片 URL（同图生图但目的不同） | 给视频流程锁首帧构图 | `--iw` | 为 Seedance 2.5 I2V 准备承接帧 |

## 二、关联度取值速查（实测建议起点）

### `--sw`（风格参考强度）
| 取值 | 效果 | 何时用 |
|---|---|---|
| `--sw 0` | 几乎不影响 | 验证参考图是否造成污染 |
| `--sw 50–150` | 轻染：只带色调倾向 | 参考图与新提示词题材差异大（如拿场景图垫角色） |
| `--sw 200–400` | 标准：色调+光感明显同源 | **默认档**，同系列场景母图 |
| `--sw 500+` | 强绑：几乎复刻质感 | 同场景多机位、要求肉眼同源 |

### `--iw`（图生图权重）
| 取值 | 效果 | 何时用 |
|---|---|---|
| `--iw 0.5–1` | 轻借色调与氛围，构图自由 | 只想要"同光线同色调"的新构图 |
| `--iw 1–1.5` | 构图大体继承 | 同场景换机位 |
| `--iw 2` | 贴死原图 | 微调原图（换时间/天气） |

## 三、一致性工作流（整部剧同源的关键）

1. **先出锚点图**：第一张场景母图不垫任何参考图，纯提示词跑（档 B），跑 4 张选 1。
2. **验收锚点**：过 `chinese-celestial-palace` 质量门 → 这张图成为本剧**风格锚**，回记其图片URL/任务ID（平台无 `--seed`）。
3. **后续全部场景垫锚图**：`--sref <锚图URL> --sw 300`，只换五层里的主体层与机位。
4. **角色用 `--oref`**：角色定妆图验收后，该角色每次出场都带 `--oref <角色图URL>`；场景里出现该角色时同时带 `--sref`（场景锚）+ `--oref`（角色身份）。
5. **复现靠垫图，不靠 seed**：所有验收通过图的**图片URL/任务ID** 回记到 `asset_manifest`；返工靠"同提示词 + 同垫图 + 同旋钮值"复现，不再依赖 `--seed`。

## 四、硬边界

- 参考图只用：本项目已验收图、用户明确提供的合法素材。**不垫第三方版权图、不复刻受保护作品画面**。
- 参考图职责唯一：`--sref` 只锁风格，`--oref` 只锁身份；不要让一张图同时承担两种职责的期望。
- 新题材首跑不垫图：先验证纯提示词骨架，垫图是第二步收敛手段，不是拐杖。
