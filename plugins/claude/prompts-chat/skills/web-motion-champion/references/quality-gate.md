# 高质量动效质量门

## 硬门

任何一项为否都拒绝进入实现：

1. 动效有一个明确的用户或业务工作。
2. 来源是官方页面、官方仓库或用户已购买的官方资源。
3. 许可允许当前商业终端产品使用，并已记录必要声明。
4. 与当前框架、渲染方式和动画/滚动 Owner 兼容。
5. 有移动端与 `prefers-reduced-motion` 路径。
6. 不遮挡 CTA、导航、表单、媒体控制或正文。
7. 可在路由退出/组件卸载时完整清理。
8. 禁用动画后内容仍完整、可读、可操作。

## 100 分评分

| 维度 | 权重 | 高分含义 |
| --- | ---: | --- |
| 页面目标匹配 | 25 | 明显强化当前主任务，而非装饰堆叠 |
| 品牌与视觉整合 | 20 | 像本产品原生设计，不像粘贴的 Demo |
| 交互与无障碍 | 15 | 键盘、触摸、焦点、低动态均完整 |
| 性能与降级 | 15 | 首屏成本受控，低端设备有替代 |
| 可维护性 | 10 | 依赖少、边界清楚、可清理、可测试 |
| 响应式质量 | 10 | 各视口重新构图，不只是缩小 |
| 来源与许可 | 5 | 官方、版本和许可记录完整 |

- `80–100`：允许实现。
- `65–79`：修改方案后重新评分。
- `<65`：拒绝，换候选。

Star、浏览量、案例数量和“看起来高级”只能帮助发现候选，不计入硬门，也不能补偿性能、许可或可用性失败。

## 常见失败

- 为每个标题逐字动画、每张图视差、每个按钮磁吸。
- 长时间 pin、自动播放大视频、粒子 Canvas 与 WebGL 同时运行。
- 直接复制 Demo 的品牌、文案、照片和完整布局。
- 用桌面 hover 作为唯一操作路径。
- 为一个小效果引入第二套动画引擎。
- 只看本地截图，不测试动画生命周期和真实交互。
