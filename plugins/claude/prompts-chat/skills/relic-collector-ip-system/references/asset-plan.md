## Asset Principle

- every object must feel ordinary, worn, and rule-bearing;
- avoid luxury production design;
- satisfaction comes from precise ownership reversal, not random floating debris;
- emotion should sit in wear, route marks, repair tape, labels, scratches, and repeated use;
- keep 16:9 horizontal narrative composition as the default.

## Asset Gate

- `A01` must lock silhouette, coat logic, canister placement, scanner shape, sealing gun, and white glove language.
- `A03` must make the thieves read as a black-market sealed-building crew, not generic survivors.
- `A05` must prove the hook reads in one frame: stolen objects are dragging themselves back inside.
- `A06` must make the fan, bus card, and white glove action clear.
- `A10` must show precise return paths, not chaotic supernatural levitation.

## Identity-Fix Workflow

When high-emotion or high-action frames keep the mood but lose the approved collector identity:

1. do not start with a longer text reroll;
2. use `A01` as the identity reference;
3. use the best existing scene frame as the composition reference;
4. run image-to-image correction;
5. only return to pure text rerolls if the dual-reference route fails repeatedly.
