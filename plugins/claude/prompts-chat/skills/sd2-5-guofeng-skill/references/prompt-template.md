## 参考图 / 多模态使用边界

默认输出 T2V。只有用户明确提供并要求使用参考素材时，才输出 I2V 或多模态版，并读取 `moodboard-reference-prompt-template.md`：

- 情绪板只负责艺术方向、摄影语言、景深、颗粒、色彩、光影、材质、空间层次和整体氛围；不是首帧，不锁人物脸；
- 角色图只负责身份、脸、发型、服装与可信年龄；不继承原场景或原剧情；
- 场景图只负责空间布局、前中后景与光线方向；
- 道具图只负责形状、材质和状态；
- 首帧图才负责 I2V 初始画面中的人物、空间和道具状态；
- 视频参考只负责明确指定的运动或节奏；
- 每个参考必须写“参考什么 / 不参考什么 / 在本镜头如何生效”；
- 任何参考都不得替代本集原创动作因果、镜头目的和连续性事实。
