# 情绪板参考图提示词框架

> 用途：在 Seedance 2.5 图生视频或需要先做视觉资产的流程中，将用户实际上传的参考图编译为职责明确的视觉控制语句。
>
> 原则：参考图不是“把图里的人和物搬进新画面”。先提取视觉规律，再用于原创画面。除非用户明确授权角色参考，否则不得继承人物脸、服装细节、剧情、文字、logo、水印或逐帧构图。情绪板只负责审美标准，不是首帧图。

## 一、先分图，不混用职责

| 图片类别 | 可以提取 | 不可以继承 | 在 I2V 中的职责 |
|---|---|---|---|
| 视觉风格参考图 | 艺术方向、摄影语言、镜头距离、景深、颗粒、空间气质、发型与服装的类型感 | 原人物脸、具体剧情、原姿势、逐帧构图、文字与标识 | 约束整体审美和镜头观看方式 |
| 色彩与光影参考图 | 主色、辅助色、亮度关系、光源色温、光向、阴影密度、氛围 | 具体建筑/道具/人物身份、画中文字 | 约束色彩脚本和世界内光源 |
| 人物角色参考图 | 人物气质、可信年龄、面部特征方向、发型轮廓、服装身份 | 原场景、原剧情、原姿态、原文字和商标 | 仅锁本镜头的角色身份与脸部连续性 |
| 场景/首帧资产图 | 空间布局、前中后景、光线方向、道具初始状态 | 角色身份、后续动作、故事因果 | 仅作 I2V 起始空间与状态事实 |

> 情绪板只负责“画面审美标准”；它不是首帧图，也不能替代角色、场景或道具资产。

## 二、可直接套用的参考图职责提示词

将实际上传的图片替换为 `{{Image 1}}` 等占位。只保留确实存在的图片类别；不要虚构图片编号。

```text
请根据我上传的全部参考图片进行综合创作。参考图不是复制对象，而是不同维度的视觉控制输入。先按职责提取规律，再创作一个原创画面；不得照搬参考图的人物、剧情、文字、logo、水印、品牌、可读招牌、独特角色设计或逐帧构图。

【视觉风格参考】
{{Image 1}} {{Image 2}} {{Image 3}}
这些图片仅作为整体视觉风格参考。提取：艺术方向、摄影语言、镜头质感、景深关系、胶片/数字颗粒、真实摄影效果、发型与服装的类型感、人物与空间的比例、整体审美和氛围。
保持：新画面在摄影观看方式、空间层次、材质可信度和整体气质上与参考图同向。
不继承：参考图中的人物脸、具体事件、姿势、文字、logo、水印、品牌、逐帧构图。

【色彩与光影参考】
{{Image 4}} {{Image 5}}
这些图片仅作为色彩与光影参考。提取：主色调、辅助色、明暗关系、光源颜色、光源方向、阴影密度、局部点色和氛围感。
保持：新画面采用相同的调色方向与可解释的世界内光源关系；人物、空间与道具必须共享同一光线。
不继承：参考图的具体场景、人物身份、文字和标识。

【人物角色参考】
{{Image 6}}
这张图片仅作为人物角色参考。提取：人物气质、可信年龄、面部特征方向、发型轮廓、服装身份和自然皮肤受光。
保持：本镜头人物在上述身份特征上稳定；自然皮肤纹理、五官比例和年龄感可信。
不继承：原场景、原动作、原剧情、文字、logo、水印和配饰品牌。

【视觉要求】
保持：真实摄影质感、自然皮肤纹理、可信材质、前中后景空间层次、统一视觉风格、人物与环境共享光线。
避免：AI塑料感、过度磨皮、廉价商业广告风、风格混乱、五官异常、结构错误、模板脸、脸部漂移、无因运镜、随机文字、字幕、水印、logo。

【最终创作目标】
{{画面内容的提示词}}
```

## 三、国风 I2V 专用补充块

在上方通用框架之后，补入已经确认的剧本、资产和镜头事实；情绪板不得代替这些事实。

```text
【本镜头原创事实】
时代与社会环境：{{时代/地域/行业}}
场景身份：{{正在发生的具体生活事件}}
人物身份：{{角色身份、任务、当前状态}}
关键道具：{{名称、初始状态、使用目的}}
动作链：{{触发信息 → 身体微反应 → 选择 → 主动作 → 可见结果}}
镜头目的：{{观众本镜头必须看清什么}}
镜头关系：{{景别、机位高度、前中后景、允许的轻微运动及停止点}}

【图生视频边界】
把情绪板作为审美参考，不作为首帧。I2V 首帧仅以{{实际首帧图片编号}}锁定人物、空间和道具初始状态；角色参考仅锁脸与服装身份；情绪板不替代动作因果。禁止把参考图中的人物、剧情、文字或构图直接复刻到本镜头。
```

## 四、提交前审计

- 所有 `{{Image n}}` 是否都确实存在且类别正确。
- 是否写清每类图“参考什么 / 不参考什么 / 如何生效”。
- 风格图是否被误当角色图；情绪板是否被误当首帧。
- 用户未给角色图时，是否避免复用风格图人物的脸。
- 色彩与光线是否已转成方向、照射对象和阴影关系，而非只写“高级电影感”。
- 最终画面内容是否由独立的原创事实、动作链和镜头目的决定。
