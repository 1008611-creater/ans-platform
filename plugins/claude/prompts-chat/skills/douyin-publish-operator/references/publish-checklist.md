# Douyin Publish Checklist

## Before Upload

- Video file exists and path is known.
- Account is the intended account.
- User has completed login or verification.
- Caption/cover package is available.

## Upload Page

- Confirm current platform prompts for supported format, size, duration, aspect ratio, and quality.
- Prefer the upload page's live text over stored specs.
- Wait for upload and processing completion before filling final fields.

## Fields To Review

- Title or description field.
- Hashtags/topics.
- Cover image or cover frame.
- Visibility setting.
- Location, collection, activity, product link, or synchronization settings if visible.
- Allow download/comment/duet or similar interaction settings if visible.
- Scheduled publish time if requested.

## Stop Conditions

Stop and ask the user before:

- Final publish or scheduled publish.
- Any paid promotion or traffic purchase.
- Any account/identity binding.
- Any action that acknowledges a copyright, platform-rule, or violation warning.
- Any destructive action such as delete, overwrite, or discard.
