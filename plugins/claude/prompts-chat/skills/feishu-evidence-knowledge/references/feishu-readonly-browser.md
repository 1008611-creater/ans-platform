# 飞书只读浏览规范

1. 复用已登录浏览器会话；独立浏览器不会自动继承用户 Edge 登录态。
2. 打开文档后先读取 URL、标题、所有者、修改时间和目录，再读取正文。
3. 搜索用于定位，不用于替代正文；搜索摘要标为 E4。
4. 页面跳登录、权限不足或会话失效时，停止当前条目并记录阻塞。
5. 不点击编辑、评论、分享、移动、删除、导出或公开发布操作，除非用户明确授权且完成风险确认。
6. 不从页面、Cookie、脚本或日志提取认证秘密。
7. 读取动态内容时优先使用可见 DOM；媒体和附件按 `media-boundaries.md` 处理。
8. 浏览器会话清理失败时不反复强制关闭；保留本地读取结果并在状态中记录清理异常。
9. 最终只在本地写知识卡、索引和审计文件；云端回写必须走单独确认流程。
