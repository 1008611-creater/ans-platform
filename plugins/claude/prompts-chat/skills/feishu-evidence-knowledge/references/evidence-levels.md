# 证据等级与引用规则

## 等级

- **E1 原文文字**：已在有权限的飞书文档页面读取到的正文、标题、目录、表格文字。
- **E2 清晰图片/截图**：图片或截图中可辨识的文字和视觉事实；记录图片来源。
- **E3 媒体核验**：实际播放视频、查看关键帧、读取音频或打开附件后得到的事实；记录页码、时间点或文件名。
- **E4 搜索摘要/页面预览**：只用于定位文档和初步线索，不替代原文。
- **E5 整理者推导**：归纳、跨任务迁移、ANS应用、商业判断或模型选择建议。

## 强制标注

每条关键结论写明：

```text
原文依据：章节/段落/页码/时间点
证据状态：明确 / 方法 / 案例 / 推导 / 待核验
适用条件：
不适用边界：
最小验证：
```

## 禁止事项

- 不把 E4 搜索摘要写成完整原文。
- 不把 E5 推导写成课程原话。
- 不把单个品牌、人物、模型、平台、参数、时长、比例、成本或成功案例写成跨任务规则。
- 不在证据不足时补写图片或视频细节。
