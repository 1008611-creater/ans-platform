# 天宫情绪板（Moodboard）制作与调用规范

> 版本：v1.0｜日期：2026-08-25
> 适用：天宫/天庭/仙宫/云上宫阙题材的静态生图、图生视频、文生视频提示词编译。

## 1. 定位

天宫情绪板不是第二套 DNA，也不是把参考图全部塞进提示词。它是一个**参考图职责分配层**：

- **天宫四类 DNA Skill**负责不可变的视觉硬约束，按类别分别校验：
  - A 类远景巨构：建筑身份、云海物理、尺度、主光、视角
  - B 类人物：体态、面部、发型、服饰、动作、情绪、五大原则
  - C 类中近景日常：POV/OTS 规则、前景遮挡、窗光/门光
  - D 类素材道具：材质系统、道具形制、使用状态、光响应
- **天宫情绪板 Skill**负责从一组参考图中提取当前任务需要的风格、摄影、色彩、光影、人物与道具关系。
- **剧情/资产事实**负责回答"画面里具体是谁、在哪里、做什么、用什么道具"，不能由参考图推断。
- **生图 Skill / 生视频 Skill**负责把前两层编译成对应平台的可执行提示词。

调用关系：

```text
新剧本事实 + 用户参考图
          ↓
天宫情绪板 Skill：分类、提取、分配参考职责
          ↓
天宫四类 DNA Skill：按类别分别校验硬约束
          ↓
MJ 生图 Skill / Seedance 生视频 Skill：编译提示词
          ↓
对应平台验收
```

## 2. 四类参考图目录

在项目中按以下四类整理，不混用职责：

1. `人物/`
   - 人物气质、体态、年龄感觉、发型轮廓、服饰层次、表情克制程度；
   - 不直接继承人物身份、脸、对白、原剧情。
2. `远景巨构/`
   - 天宫尺度、建筑群、云海地形、天瀑、门洞、空间纵深和构图；
   - 不直接复制参考帧的建筑排列或具体镜头。
3. `中近景日常/`
   - 中近景、第一人称 POV、第三人称 OTS、人物与门窗栏杆/宫檐/云雾的关系；
   - 不把人物关系参考误当角色身份锁定。
4. `素材道具/`
   - 门、瓦、玉石、木构、栏杆、云、光、雾、水、金属、丝绸、天书、法器等局部材质与使用状态；
   - 不单独决定整张图的风格和剧情。

一张图可以在多个类出现，但每次调用必须写清它在当前镜头中的唯一职责。

## 3. 情绪板提取步骤

### 第一步：建立参考图清单

为每张图登记：

- `ref_id`：如 `人物_01`、`巨构_03`；
- 来源视频/素材批次；
- 所属分类；
- 画面内容简述；
- 可继承维度；
- 不可继承内容；
- 服务的镜头类型。

### 第二步：按职责提取

#### A. 视觉风格参考

提取：

- 艺术风格：高端中国仙侠 3D 国漫电影感、柔和美型人物、真实空间纵深；
- 摄影语言：远景全景、门洞框景、肩后观察、第一人称发现式观看、稳定慢镜头；
- 发型特点：高束发、长发披散、发带、玉簪或简洁冠饰，发丝受真实风向影响；
- 服装风格：长袍、轻纱、披帛、窄袖内层、宽袖外层，白/月白/淡青/灰青基底；
- 审美方向：修长、清俊、轻盈、出尘、克制，不网红化、不浓妆化；
- 整体氛围：敬畏、空灵、清冷、温柔、孤寂、神性、超然。

保持：整体视觉风格与参考图的共同规律一致，不复制单张图的具体人物或布局。

#### B. 摄影与镜头参考

提取：

- 镜头质感：电影级、柔和 Bloom、真实物理光照、HDR、微弱胶片颗粒；
- 景别关系：巨构远景人物 1%-3%；中近景人物约 15%-45%；
- 景深关系：中近景人物清晰，背景巨构仍可读；远景保持深焦与尺度证据；
- 框景与遮挡：门柱、窗框、竹叶、栏杆、衣袖或肩部形成前景层；
- 视线关系：人物不看镜头，看远方、门内、云海、光柱或天瀑；
- 画面目的：远景建立敬畏，中近景让观众进入角色视线，POV 负责发现，OTS 负责观察和情绪反应。

#### C. 色彩与光影参考

提取：

- 主色：暖白、雪白、浅石、暗青、灰青；
- 辅助色：朱红、暗金、矿物青绿、冷蓝；
- 明暗关系：暗前景/暗部留细节，暖光只击中叙事主体；
- 光源颜色：单一主光，冷环境光与局部暖光破口形成冷暖对撞；
- 氛围感：体积云雾、光柱、光尘、镜面水、金色云海、边缘轮廓光。

保持相同调色方向，但不把“暖金”扩展成满屏红金，不把雾气做成纯灰罩。

#### D. 人物角色参考

提取：

- 人物气质：清俊、出尘、安静、坚定、若有所思；
- 年龄感觉：以剧情资产单独确定，参考图只提供成熟度和气质方向；
- 面部特征方向：精致、自然、克制，默认侧脸/侧后脸/逆光轮廓；
- 体态：修长、肩颈舒展、腰线自然、动作轻盈；
- 服饰：材质层次、衣领、袖口、腰带、发饰、衣摆运动。

保持人物的视觉特征方向，不锁定参考图原人物的身份、姓名、具体脸、对白、道具或原剧情。

#### E. 道具与素材参考

提取：

- 材质：朱漆木、暗木梁、青灰瓦、汉白玉、丝绸、金属、岩石、雾水；
- 使用状态：被手扶、被光照、被雨雾打湿、被云遮挡、被人物携带或放置在台基上；
- 结构关系：道具和人物的接触面、受力关系、投影与反光。

保持道具的材质逻辑和使用状态，不把道具参考变成整张图的剧情新增。

## 5. 用户提供的提示词框架（标准化版本）

```text
请综合理解所有已上传参考图片。参考图不是用来复制对象，而是按职责提取视觉规律。

【视觉风格参考】
从指定参考图提取艺术风格、摄影语言、发型轮廓、服装层次、审美方向和整体氛围；保持共同视觉风格，不复制原人物身份、原剧情、具体文字或逐帧构图。

【摄影风格】
继承参考图的镜头质感、景深关系、前中后景、框景/遮挡、人物占比和观看视线；根据目标镜头选择远景巨构、中近景空间关系、第一人称 POV 或第三人称 OTS。

【色彩与光影参考】
提取主色、辅助色、明暗关系、主光方向、光源色温、体积雾、边缘光、反射和 Bloom；保持统一调色方向，执行天宫 DNA 的单一主光和克制强调色。

【人物角色参考】
只提取人物气质、年龄感觉、体态、面部方向、发型和服饰层次；保持人物审美方向，不锁定参考人物身份、具体面孔、原剧情或原对白。

【素材道具参考】
只提取材质、结构、受光、反射和使用状态；道具必须服从当前剧本事实。

【最终创作目标】
将以上参考规律与以下已确认画面事实融合：<画面内容提示词>。
先通过对应类别 DNA 校验（A 远景巨构 / B 人物 / C 中近景日常 / D 素材道具），再输出平台对应的生图或生视频提示词。
```

## 6. 硬边界

- 情绪板不能覆盖剧本事实；
- DNA 不能被单张参考图推翻；
- **四类 DNA 独立、不可互相替代**——人物需求不能只读远景巨构 DNA，道具需求不能只读人物 DNA；
- 参考图只提取规律，不复刻人物脸、对白、logo、水印、文字、版权角色或逐帧构图；
- 生图和生视频都必须经过情绪板摘要 + 对应类别 DNA 校验；
- 参考图没有提供的内容不得假装存在；
- 需要生成新人物时，优先使用"人物审美 + 角色事实"，不把远景巨构图中的人物误当作角色锁定图。
