# P1视觉、色彩与声音创作基准

## 1. 范围

只建立项目已确认的视觉类型。真人实拍、三维国风漫剧或其他已确认类型均可使用，但同一项目只能继承一种已确认的成像/渲染母语；不得因本参考文件把既定风格改为三维国风，也不得混用互相冲突的真人摄影与三维材质规则。

## 2. 从剧本推导

先判断类型/子类型、年代与地域、现实程度、情绪温度、空间规模、叙事速度和主要视觉矛盾，再选择或继承视觉与声音系统。不能先选炫技效果再强套剧本。

## 3. 视觉参考

- 默认1部主要参考，必要时最多增加1部补充参考。
- 参考后明确借鉴维度：光线、色调、空间压迫、尺度、材质、大气、表演距离或镜头调度。
- 主要参考决定全片视觉母语；补充参考只解决1个清楚维度。
- 没有准确参考时使用与已确认视觉类型一致的语言，不强行列片名。
- 参考必须立即翻译成可见参数，禁止只写“某导演式氛围”。

## 4. 成像与镜头系统一致

真人实拍锁定摄影介质、摄影机或胶片、镜头家族、画幅和帧率；三维项目锁定渲染质感、镜头运动惯性、镜头焦段语言、画幅和帧率。两类参数不得并列伪装成同一管线，不在此处预写具体分镜机位。

## 5. 风格锁定组成

使用一段中文自然语言，逗号和分号组织，不用加号标签。每个短语必须能改变可见结果：

1. 成像管线：按已确认类型填写摄影介质或渲染质感、镜头运动、镜头焦段语言、画幅、帧率。
2. 光线曝光：主光、方向/弥散、反射、体积雾、曝光、高光和暗部。
3. 色彩反差：环境主色、辅助色、冷暖、饱和度、黑位、中间调、肤色保护。
4. 成像纹理：颗粒、阴影噪点、光晕、锐度、镜头缺陷与印片质感。
5. 大气材质：按剧本和已确认类型填写云、雾、尘、发丝、布料、木材、金属、皮肤或玉石受光。
6. 禁用：与已确认类型冲突的游戏界面感、塑料表面、漂浮衣摆、过度锐化、HDR光晕或无来源轮廓光。

删除“高级感、电影感、具有重量的流动感、压迫而克制”等无法直接渲染或没有可见参数的空词。

## 6. 环境色彩策略

P1只确认环境冷暖关系、曝光、黑位、中间调、主要环境色、允许的局部强调色、肤色保护与禁用色。没有已确认环境图时不凭文字臆造HEX值，也不生成环境色卡图片。

角色确认稿继承全片已确认的材质和造型语言，但使用中性影棚光，不让戏剧环境色覆盖人物、服装和道具的固有色。

## 7. 声音与音乐圣经

声音与音乐分开建立：

- 每场戏都应有环境声与同步动作音效，但不是每场戏都需要BGM。
- 环境声提供空间；动作音效同步事件；喘息、痛哼、哭泣、笑声和低吼属于非语言人声。
- 为主要人物锁定音色、口音、语速、语调和压力下的说话方式，作为后续声音资产设计依据。
- BGM只承担推动、反转、连接、积蓄或释放情绪，不默认铺满全片。
- 锁定主要乐器、节奏材质、低中高频倾向、核心动机、动态范围、留白和禁用声音；后续只能在同一音乐语言中改变速度、密度、力度和配器数量。
- 精品惊悚或剧情片优先少乐器、少旋律、多空隙；避免高音金属“叮叮”、无依据人声和声、宏大预告片铜管和每场更换乐器。

P1只交付声音与音乐原则，不生成音频、干声、BGM文件或独立音乐提示词。

## 8. P1交付顺序

1. 主要影视参考与具体借鉴维度。
2. 已确认的摄影或渲染管线、镜头运动、镜头焦段语言、画幅和帧率。
3. 一段可执行的全片风格锁定。
4. 环境色彩策略。
5. 主要人物声音气质基准。
6. 全片环境声原则与音乐圣经。

只给1套完整推荐，创作者整体确认或指出冲突；不让用户填写空表，不同时倾倒多套互斥方案。
