# 已验证故障模式

## 发布资源混用

不要把多个候选目录的 `workspace-v206.js`、`workspace-v206.css`、SSR chunk 或 Logo 挂载到同一运行路径。最后写入者会覆盖先前修复，且 HTML 版本号不会说明真实文件来源。

## 缓存与最终镜像

必须验证浏览器下载的文件哈希等于运行中镜像的文件哈希。不要把新 `?v=` 参数、Docker image 标签或 readiness 当成静态资源已更新的证据。最终镜像必须带入当前构建的公共静态目录。

## 客户端所有权

一个页面区域只保留一个运行时所有者。确认 CSP nonce 允许预期脚本执行；不要用旧 SSR/旧监听器与兼容运行时共同接管模板分类、登录头或工作台步骤。

## 会话与私有状态

只在显式登出或确认 `401` 时清理私有状态。临时网络、5xx、存储失败或资源读取失败不能被当作退出登录。清理时同时移除个人模板、用户素材、项目、任务和本地恢复缓存。

## 媒体播放

数据库 `READY` 只说明记录状态。验证对象存在、授权 URL 可读取、Range/低码率 rendition 被使用、浏览器获得尺寸并能播放。地址刷新成功后必须清理该媒体的旧失败标记。
