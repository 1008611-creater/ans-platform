# Seedance 2.5 视频交付编译

本参考属于 `hell-grind` 的渠道交付工作段。它只编译已经通过表演、镜头、空间物理和连续性质控的事实，不生成角色、场景或道具资产，也不提交供应商。

## 输入门

- 必须具备已审计的镜头、角色身份锚点、场景和关键道具状态、连续性事实，以及目标时长或可测算的内容。
- 正式提示词只使用已确认资产；候选资产只能生成明确标注为“预演”的提示词，不能解锁分镜或连续性。
- 每个 `@图片/@视频/@音频/@音效` 写清“参考什么、不参考什么”。角色参考只锁脸、发型、服装和身份；场景参考只锁空间、地标、光线和色彩；道具参考只锁形状、材质和当前状态；上一段末帧只锁构图和动作起点。

## 模式选择

| 模式 | 使用条件 | 时长 |
|---|---|---|
| 单段 | 一个可读的连续动作或一个小型镜头组 | 4-30 秒 |
| 延长段 | 已有实际成片且要从末状态续接 | 每段不超过 30 秒，总长不超过 60 秒 |
| 超长模式 | 已确认的完整短片、预告或 MV | 不超过 180 秒 |
| 30 秒多人试镜 | 三人以上同场，需要检验关系构图与身份区分 | 单段 30 秒；候选资产时仅预演 |

## 精确时序

先测算，再写提示词。台词按正常中文每秒 3-4 字、情绪或古风台词每秒 2-3 字、耳语每秒 1.5-2 字计算；每次停顿或换气预留 0.5-1 秒。关键眼神保留 1-2 秒，起身或坐下保留 1.5-3 秒，三至五步走位保留 2-4 秒，关键道具交互保留 1-2 秒。

- 单段为 4-30 秒；30 秒内最多八个镜头，任一镜头不少于一秒、不超过十秒。
- 时间戳连续且不重叠；需要卡点时同时标注 24fps 帧号。
- 内容超时时，先延长至 30 秒，再选择延长段或超长模式；不得删改用户锁定的台词。
- 内容不足时保留动作余韵和真实停顿，不用无意义空镜填充。

## 编译规则

1. 每个区间只写摄影机可见的动作、表情、物体、光线和声音。
2. 每个主要动作按“起始状态 -> 触发 -> 准备 -> 执行 -> 结果 -> 细微反应”写全；补充衣料、发丝、道具、环境或光线的二次反应。
3. 跨区间重复角色脸部、发型、服装、配饰和空间轴线锚点；关键道具写清变化前状态、触发动作、变化后状态和反应。
4. 指定景别、焦段、景深、机位、前中后景、视线方向、镜头运动及其叙事目的；光影要写光源、方向、色温、作用对象和变化原因。
5. 对白逐字保留；同时写音色、语速、停顿、重音、换气和口型同步。需要纯净底片时明确“无字幕、无背景音乐”；只允许出现的画面文字单独列出。
6. 负向约束只禁止会破坏本镜的字幕、水印、品牌、随机文字、无关音乐或无关元素，不能替代正向调度。

## 30 秒多人试镜

每位角色必须有身份锚点、当前服装、站位、一个可见区分物和本段唯一关系。每个区间只允许一名主行动者与至多一名直接反应者；其他人只能保持可见站位、视线或低幅度物理反应。禁止四人同时说话、走位或完成独立大动作。

```text
0-4s：全员同框，建立空间、站位、服装与关键道具。
4-10s：角色 A 受触发完成主动作；角色 B 给出反应。
10-16s：角色 C 做行动或选择；A/B 维持位置关系。
16-23s：角色 D 触发关系变化；仅一名既有角色回应。
23-30s：回到四人可见构图，以可验收末状态收束。
```

时间测算必须列出每名角色在每段的可见职责、主行动者和末状态。不得用“全员激烈互动”“镜头自由切换”等空话替代调度。

## 输出格式

1. 质控结论：通过项、修复项、最早失败变量；候选资产时标明“预演”。
2. 时间测算：台词、表演、走位、道具、运镜、首帧承接和末帧停留的总时长与结论。
3. 多模态版：全局约束、`@` 参考职责、连续时间戳、聚焦负向约束。
4. 纯文字版：保留相同时间轴和身份锚点，用完整文字替代 `@` 参考。
