# Seedance2 Commerce Templates

## Fixed Seedance2 Video Wrapper

Use this wrapper for future Seedance2 video-generation prompts. Keep the front and back constraint text unchanged by default. Insert the task-specific video prompt in the middle.

### Front Constraint

```text
以下是我的视频提示词，请你严格遵循提示词，不允许修改和违背提示词，严格按照片段时长输出，严格参考指定素材，不允许转变风格、不允许自行决断，还需要精准识别台词部分，不允许多加台词以及遗漏台词部分。我要一段完整的 15 秒视频，不允许分段输出: 参考视频中人物的音色

为首帧图和角色参考
```

### Back Constraint

```text
请严格遵循命令，这是死规矩，你只有按规矩行事!!请记住，不需要字幕！！请严格遵守！！请直接生成视频，不要询问其他！！
```

### Assembly Pattern

```text
[Front Constraint]

[Task-specific Seedance2 video prompt]

[Back Constraint]
```

## 念念水果女主播 Example

```text
9:16竖屏，15秒，@图片1作为念念身份/五官/围裙/工牌/耙耙柑参考，@图片2作为真实水果直播间首帧参考。严格保持@图片1中念念的五官、发型、红色上衣、米色围裙、胸前“叁川山雾”logo、“小雾”工牌和手中耙耙柑一致，不改变脸型和五官；以@图片2作为视频第一帧构图和背景氛围。

真实手机自拍视频风格，轻微手持感，真实克制的成都水果直播间/水果店角落背景，背景只有少量水果筐和直播补光设备，不要堆满水果，不要墙面大logo，柔和真实打光，像刚入职水果直播间前录的一条试播自拍视频。

0-3秒：念念看着镜头，有点紧张，轻轻抱着手里的耙耙柑，眼神有点不确定；
3-7秒：她低头看一眼耙耙柑，又看回镜头，嘴角忍不住笑一下，像是不知道怎么介绍；
7-11秒：她把耙耙柑稍微举近一点，动作自然，不夸张，手指保持真实；
11-15秒：她靠近镜头一点，小声又真诚地笑，像在说“晚上如果刷到我，别笑我”。

镜头：前置手机自拍，轻微自然手持，整体稳定，缓慢轻微推近，不切镜头。
手部逻辑：一只手在画面外拿手机自拍，另一只可见的手拿着耙耙柑靠近脸，不能双手抱着水果。
表情细节：眼神不要一直直勾勾盯镜头，要有自然眨眼、视线短暂下移看耙耙柑、再看回镜头、嘴角轻轻动一下、紧张笑容出现又收住、短促吸气和轻微笑场感。
情绪：05后女大第一天勇闯水果直播界，紧张、真实、可爱，但不要表演感，不要固定微笑。
画质：真实人像摄影，皮肤自然，光线柔和，细节清晰。
禁止：改脸、换五官、眼睛变大、脸变尖、皮肤塑料感、过度美颜、手指畸形、耙耙柑变成普通橙子、围裙logo消失、工牌文字错误、背景出现水果堆或墙面logo、字幕、水印、夸张广告感、画面抖动、身份漂移。
```

口播：

```text
呃……我今天第一天来叁川山雾上班。
本来以为就是帮忙摆摆水果，
结果晚上好像要让我试着开播。
我现在连这个耙耙柑怎么介绍都还没想好……
晚上如果刷到我，别笑我，评论区教我一句开场白吧。
```

## No-Dialogue Table-Phone Dance Daily

Use when the user wants a casual daily dance video, no dialogue, with a dance reference video.

```text
9:16竖屏，15秒，@图片1作为念念身份、五官、发型、服装、围裙logo和工牌参考，@图片2作为首帧构图和背景参考，@视频1只作为舞蹈动作节奏和身体摆动参考，不参考@视频1的人脸、服装、场景和风格。严格保持念念的五官、脸型、发型、红色上衣、米色围裙、胸前“叁川山雾”logo、“小雾”工牌和整体气质一致。

真实手机日常自拍视频风格，无台词，无字幕。手机先被念念放到桌子上，像靠在杯子、盒子或墙边小物件上，画面是固定桌面机位，有一点点不稳定的接触微晃和轻微倾斜，不是三脚架专业固定机位。

0-3秒：念念把手机放到桌面上，镜头轻微晃一下后稳定。她后退半步，先用眼神瞥一眼镜头左后方，像在确认有没有人过来；确认安全后，她微笑，一只手轻轻捂住嘴，带一点偷笑和不好意思。

3-10秒：她继续往后退到画面中间，按照@视频1的舞蹈节奏开始轻轻扭动。动作是05后女大随手跟拍的感觉，不是专业舞台舞蹈；幅度自然、松弛、可爱，有一点害羞但玩得开心。保持人物全程在画面内，围裙和工牌能看见。

10-12秒：舞蹈结束前，她动作慢下来，再次用眼神快速瞥一眼镜头左后方，好像听到有人或怕被发现，表情从开心变成一瞬间的警觉。

12-15秒：她马上笑着跑向镜头，一只手伸向镜头拿起手机，画面出现手靠近镜头的轻微遮挡和真实手持晃动，最后定格在她靠近镜头的微笑表情。

情绪：上班前偷偷跳一下，怕被发现但又忍不住开心。真实、可爱、松弛、有一点社死感，不要表演感。
画质：真实人像摄影，皮肤自然，光线柔和，生活化短视频质感。
禁止：台词、字幕、自动文字、水印、改脸、身份漂移、过度美颜、专业舞台感、夸张性感舞蹈、双手拿水果、手指畸形、围裙logo消失、工牌文字错误、手机一直悬空自拍、三脚架固定感、画面剧烈抖动、把@视频1的人物替换成念念以外的人。
```

## Women Clothing Try-On Default

Use when the user only says "女装带货" and provides a model/clothing image.

```text
9:16竖屏，15秒，@图片1作为人物脸和气质参考，@图片2作为服装版型、颜色、面料和细节参考，生成真实女装穿搭测评短视频，保持人物五官和服装细节一致。

真实手机试衣间自拍视频风格，柔和自然光，背景干净生活化，不像棚拍硬广。

0-3秒：人物面对镜头整理衣领或袖口，第一眼展示上身效果；
3-7秒：镜头稳定轻微下移，展示版型、腰线、长度或显瘦点；
7-11秒：人物侧身半步，转回镜头，用手轻触面料或口袋，表现真实试穿；
11-15秒：人物靠近镜头一点，露出自然满意的表情，像在等评论区帮她选。

镜头：前置手机自拍，轻微自然手持，整体稳定，缓慢轻微推近。
情绪：真实测评、轻松、有亲和力，不要走秀感。
禁止：改脸、身份漂移、衣服颜色变错、版型变形、手指畸形、过度磨皮、背景杂乱、字幕、水印、夸张广告感。
```

## Hard Ad Skeleton

```text
标题：[直接利益点]
封面字：[痛点/价格/效果，不超过12字]
口播：
0-3秒：[强痛点或强利益点]
3-7秒：[产品核心卖点1，用真实场景证明]
7-11秒：[产品核心卖点2，展示细节]
11-15秒：[直接转化动作：评论/进直播间/点小黄车/问链接]
```
