# Aesthetic Review Rubric

Use before accepting a website, mini program, H5, dashboard, Figma screen, Framer site, or Image2 UI concept as visually strong.

## Scoring

Score each dimension 0-5. Total 40.

| Dimension | 0-1 | 2-3 | 4-5 |
|---|---|---|---|
| First-screen memory | forgettable template | clear but familiar | screenshot-worthy signature moment |
| Typography | default/system-looking | readable hierarchy | type has personality and structure |
| Layout | centered cards, no tension | organized but ordinary | strong rhythm, density, responsive intent |
| Color/atmosphere | generic palette | coherent | specific to product and audience |
| Component craft | default controls | decent states | polished states, spacing, icons, microcopy |
| Platform fit | wrong medium | mostly adapted | website/app/miniapp conventions respected |
| Conversion/UX clarity | unclear action | understandable | primary action obvious and persuasive |
| Anti-slop | AI-template feel | some generic traces | distinctive, intentional, non-generic |

## Pass Thresholds

- 34-40: strong, can proceed if functional gates also pass.
- 28-33: usable but needs focused polish.
- 20-27: not production visual quality.
- Below 20: restart direction, not a small polish task.

## Forced Failure Conditions

- A mini program uses desktop landing-page composition.
- A dashboard/internal tool uses oversized marketing hero language instead of task density.
- A public landing page has no clear primary action.
- A design relies on decorative blobs/orbs/gradients as the main idea.
- Text overlaps, truncates badly, or mobile layout breaks.
- Image2 concept is treated as a final design spec without component/token translation.
