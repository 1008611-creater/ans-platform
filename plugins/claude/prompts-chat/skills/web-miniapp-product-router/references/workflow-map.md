# Workflow Map

| Phase | Trigger | Route |
| --- | --- | --- |
| Skill stack unclear | User asks best workflow, top skill, GitHub skill, or system upgrade | Read `skill-discovery.md` |
| Idea unclear | User has rough idea only | Product brief + target user + offer |
| Pages unclear | User asks what pages/screens are needed | `site-architecture` |
| Website project | User asks for website, landing page, portfolio, SaaS site, dashboard, web app, redesign, SEO, launch, Framer, Next.js, or static site | `website-product-router` |
| Mini program project | User asks for WeChat mini program, 小程序, appId, tabBar, login, payment, upload, cloud database, admin, backend, release review | `miniapp-product-router` |
| Visual/tooling unclear | User asks Figma/Framer/Pixso/Motiff/Image2/code | `frontend-product-design-router` |
| Need premium look | User says high-end, design sense, not plain | `frontend-product-design-router` then `top-design` or `impeccable` |
| Reusable project | User will iterate, hand off, launch, or reuse | Scaffold `DESIGN.md` + `PROJECT_MANIFEST.json` |
| Need website live fast | Simple public marketing site | `website-product-router` chooses Framer, static, or Next.js |
| Need product/app logic | Auth, database, dashboard, upload, API | `website-product-router` usually chooses Next.js/direct code |
| Need existing website improved | Existing repo or live site redesign | `website-product-router` existing-project audit first |
| Need Figma-to-code | Editable Figma design must become site | `website-product-router` + `frontend-product-design-router` |
| Need mini program preview/release | WeChat DevTools, real device, experience version, upload, review | `miniapp-product-router` |
| Need top GitHub source proof | User asks whether collected GitHub skills/templates were used | `skill-discovery.md` plus source records in `PROJECT_MANIFEST.json` |
| Need visual acceptance | User asks if design is good or says plain/ugly | `aesthetic-review-rubric.md` |
| Need conversion | Traffic, leads, sales, signups, bookings | `cro` + `analytics`; website details in `website-product-router` |
| Need launch | Domain, deployment, SEO, tracking, mini program review | Website deployment checklist or mini program release checklist plus verification |
