# 小说提纲与故事骨架法则

> 来源：凯蒂·维兰德《小说的骨架：好提纲成就好故事》

## 适用场景

- 在正式写作前搭建故事骨架、人物动机、冲突逻辑
- 设计故事前提句和"如果"问题
- 检查场景是否有功能、是否为无效场景
- 优化故事节奏，防止中段拖沓
- 为短剧/AI视频脚本压缩提纲

## 核心规则

### 规则1：提纲不是限制灵感，而是提前整理灵感

好提纲是"指南"不是"命令"。写初稿时如出现更好想法，可调整提纲。

```text
坏提纲 = 把故事锁死
好提纲 = 给故事导航
```

提纲的价值在于：**把大规模返工变成前期推演。**

### 规则2：故事核心公式

```text
故事骨架 = 人物想要什么 → 为什么想要 → 谁阻止他 → 他付出什么 → 他如何改变
```

完整版：好故事 = 清晰前提 + 强人物欲望 + 明确目标 + 持续阻碍 + 有代价的选择 + 结构化推进 + 主题回响

### 规则3：前提句是故事的第一块骨头

前提句用一句话说清楚故事，包含：人物 + 背景 + 核心冲突 + 故事方向

**前提句模板**：当【某个人物】在【某个背景】中遭遇【核心事件】后，他/她必须【完成某个目标】，否则将会【付出某种代价】。

检查标准：谁？发生了什么？必须做什么？失败代价？

### 规则4："如果"问题打开故事可能性

用"如果"问题突破第一个平庸想法，挖出更有戏剧性的方向：

- 如果主角不是表面身份，会怎样？
- 如果反派其实是对的，会怎样？
- 如果主角最想得到的东西会毁掉他，会怎样？
- 如果最亲近的人背叛主角，会怎样？
- 如果主角必须牺牲一样重要的东西才能赢，会怎样？
- 如果主角赢了外部目标，却输掉内心需求，会怎样？

### 规则5：人物不是设定表，而是故事发动机

人物推动故事的不是"设定"，而是：欲望 + 目标 + 阻碍 + 选择

核心设计问题：
- 他想要什么？
- 他为什么非要得到？
- 谁在阻止他？
- 他害怕失去什么？
- 他愿意为目标付出什么？
- 他的错误信念是什么？
- 故事结束时他发生了什么变化？

### 规则6：冲突设计公式

```text
冲突 = 目标明确 + 阻碍强大 + 代价具体 + 时间压迫
```

弱冲突：女主想证明自己。
强冲突：女主必须在今晚的订婚宴上证明自己是集团继承人，否则公司股权会被继母转移，她母亲留下的产业将彻底落入仇人手中。

### 规则7：背景不是装饰，而是叙事压力场

背景影响：人物身份 / 人物选择 / 冲突方式 / 阶层关系 / 情绪氛围 / 视觉风格 / 主题表达

判断标准：**删掉这个背景后，故事是否明显变弱？**

### 规则8：场景不是事件，而是功能单元

每一场戏至少推动以下之一：推进情节 / 暴露人物 / 升级冲突 / 埋下伏笔 / 强化主题 / 改变关系 / 制造悬念

如果删除这场戏故事没有明显变化，说明是无效场景。

### 规则9：视角选择原则

- 谁最痛，就用谁的视角
- 谁知道得最少，就更容易制造悬念
- 谁变化最大，就更适合承担这场戏

### 规则10：节奏控制

常见节奏问题：开头太慢 / 中段拖沓 / 高潮太弱 / 反转太密 / 信息堆积 / 情绪没有递进

优化方法：强场景后放缓冲 / 信息说明放进冲突里 / 定期制造新问题 / 每个转折让局势更糟 / 每个场景有情绪变化

## 可调用内容

### 前提句模板

```markdown
当【主角】在【背景】中遭遇【激发事件】后，
他/她必须【完成目标】，
否则【失败代价】。
```

### 人物设计核心表

```markdown
姓名：
表面身份：
真实身份：
核心欲望：
具体目标：
最大恐惧：
错误信念：
外部阻碍：
内部阻碍：
人物变化：
```

### "如果"问题发散表

```markdown
如果主角不是表面身份，会怎样？
如果反派其实是对的，会怎样？
如果主角最想得到的东西会毁掉他，会怎样？
如果读者期待的结果被反转，会怎样？
如果最亲近的人背叛主角，会怎样？
如果主角必须牺牲一样重要的东西才能赢，会怎样？
如果主角赢了外部目标，却输掉内心需求，会怎样？
```

### 场景功能检查表

```markdown
这一场发生在哪里？
谁是视角人物？
主角这一场想要什么？
阻碍是什么？
这一场的结果是什么？
人物关系是否发生变化？
是否推进主线？
如果删除这一场，故事是否受影响？
```

### 故事提纲模板

```markdown
## 1. 一句话前提
当【主角】在【背景】中遭遇【激发事件】后，必须【完成目标】，否则【失败代价】。

## 2. 核心卖点
类型： | 核心情绪： | 爽点： | 反转点： | 目标读者：

## 3. 主角设计
姓名： | 表面身份： | 真实身份： | 核心欲望： | 错误信念： | 人物变化：

## 4. 反派/阻碍设计
反派是谁： | 反派想要什么： | 反派优势： | 主角暂时无法战胜的原因：

## 5. 冲突链
主角目标： | 外部阻碍： | 内部阻碍： | 失败代价： | 时间压力：

## 6. 关键结构
开头钩子： | 激发事件： | 第一次反击： | 中段升级：
最低谷： | 高潮反转： | 结尾余味：
```

### 60秒短剧提纲压缩版

```markdown
0-5秒：强钩子（谁被羞辱？极端事件？）
5-15秒：身份压迫（谁看不起主角？弱势在哪？）
15-30秒：冲突升级（反派做了什么更过分的事？）
30-45秒：身份反转（主角亮出什么证据/身份/资源？）
45-55秒：爽点反击（反派如何被打脸？）
55-60秒：结尾钩子（留下新悬念或更大身份）
```

## 输出示例

### 前提句示例（女频短剧版）

当被未婚夫当众羞辱的普通女孩，发现自己其实是集团继承人后，她必须在订婚宴与集团会议中完成身份反击，否则将永远失去母亲留下的继承权。

### 人物设计示例（都市逆袭女主）

| 项目 | 内容 |
|---|---|
| 姓名 | 林知晚 |
| 表面身份 | 被未婚夫嫌弃的普通女孩 |
| 真实身份 | 集团继承人 |
| 核心欲望 | 拿回属于母亲的产业与尊严 |
| 最大恐惧 | 再次被抛弃、被证明"不配" |
| 错误信念 | 只有隐藏锋芒才能保护自己 |
| 人物变化 | 从隐忍退让，到主动亮身份、掌控局面 |

### 扩展版提纲 vs 精简版提纲

```text
扩展版提纲 = 思考过程（发散、试错、记录废案）
精简版提纲 = 写作路线图（章节顺序、场景功能、转折点、伏笔、视角、节奏）
```

## 避免事项

- 不要把提纲当固定格式（可以是手写/导图/清单/便利贴/图片）
- 不要让提纲锁死故事（出现更好想法可以调整）
- 不要只写人物设定表而不写欲望和选择
- 不要让背景只做摆设而不参与叙事
- 不要写无效场景（删掉它故事没变化就删）
- 不要让视角随意漂移（一场戏主要跟一个人）
- 不要在短剧中慢热（提纲阶段就明确每10秒的情绪变化）
- 不要一开始就写章节正文（先跑通故事逻辑再进入初稿）
