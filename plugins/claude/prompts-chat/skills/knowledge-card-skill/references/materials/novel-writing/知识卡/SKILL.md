# 小说写作辅助 Skill (Novel Writing Assistant)

基于7张核心知识卡的小说写作全流程辅助系统，覆盖从提纲搭建到初稿修改的完整创作链路。

## 触发条件

| 维度 | 说明 |
|------|------|
| **何时调用** | 用户要求"写小说"/"写故事"/"设计人物"/"写提纲"/"写对白"/"写场景"；任何涉及小说创作、短剧脚本、AI视频故事脚本的场景 |
| **不适用场景** | 纯诗歌创作（用其他工具）；纯散文写作（不需要结构化故事设计） |
| **输入** | 故事类型/题材 + 创作阶段（提纲/初稿/修改）+ 具体需求（人物设计/冲突设计/对白写作等） |
| **输出** | 故事提纲、人物设计表、冲突链、对白段落、场景描写、修改建议等 |

## 创作SOP（10步）

根据用户所处的创作阶段，调用对应的知识卡：

### 阶段一：故事设计（调用知识卡1、6、7）

```
Step 1: 找到故事种子
  → 画面/人物/关系/冲突/秘密/选择
  → 用"如果"问题打开可能性

Step 2: 写前提句
  → 模板：当【主角】在【背景】中遭遇【激发事件】后，
         必须【完成目标】，否则【失败代价】
  → 检查：谁？发生了什么？必须做什么？失败代价？

Step 3: 设计人物
  → 核心特质 + 反差面（行为反差法）
  → 欲望 + 目标 + 阻碍 + 选择
  → 人物公式：欲望 + 阻碍 + 选择 + 代价 + 变化

Step 4: 设计冲突链
  → 冲突 = 目标明确 + 阻碍强大 + 代价具体 + 时间压迫
  → LOCK模型：Lead + Objective + Confrontation + Knockout
  → 赌注必须足够大（三种死亡：肉体/职场/心理）
```

### 阶段二：结构搭建（调用知识卡1、2）

```
Step 5: 搭建提纲
  → 故事提纲模板（前提→卖点→主角→反派→冲突链→关键结构）
  → 场景功能检查：每场戏至少推动一项（情节/人物/冲突/伏笔/主题/关系/悬念）

Step 6: 规划事件链
  → 小事件链推进法：一件小事接一件小事，每件事推动人物关系
  → 事件功能分类：江湖事件/官场事件/生活事件/感情事件/家庭事件
  → 每个事件至少完成"展示人物/推进关系/暴露矛盾"中的两项
```

### 阶段三：初稿写作（调用知识卡3、4、5）

```
Step 7: 写对白
  → 三差异法：身份差 + 信息差 + 性格差
  → 对白冲突公式：表层话题 + 隐藏目的 + 情绪压力 + 信息不对称
  → 潜台词：嘴上说的不是心里想的

Step 8: 写场景
  → 烟火气公式：具体物件 + 具体价格 + 具体动作 + 具体尴尬
  → 展现 vs 讲述：影响人物关系/冲突走向/读者情绪的→展现
  → 背景参与叙事：删掉后故事是否明显变弱？

Step 9: 控制叙事
  → 视角稳定：一场戏主要跟一个人
  → 情节因果推进：不是事件排列，是因果关系
  → 象征让主题可感：用具体物承载抽象意义
```

### 阶段四：修改打磨（调用知识卡5、7）

```
Step 10: 修改检查
  → 主角欲望是否明确？阻碍是否具体？冲突是否升级？
  → 视角是否稳定？细节是否服务人物/情节/主题？
  → 章节结尾是否有钩子？悬念链是否完整？
  → 删掉无效场景/不推情节的对话/不服务主题的漂亮句子
```

## 核心规则速查

### 故事核心公式
```
故事骨架 = 人物想要什么 → 为什么想要 → 谁阻止他 → 他付出什么 → 他如何改变
```

### 冲突公式
```
冲突 = 目标明确 + 阻碍强大 + 代价具体 + 时间压迫
人物想要 A → 对立力量阻止 → 人物必须行动 → 行动导致更大阻力 → 故事推进
```

### 悬念公式
```
冲突提出问题 → 悬念延迟答案 → 风险持续加重 → 读者继续追问
```

### 人物塑造公式
```
人物靠"遇事反应"立住，不靠作者介绍
核心特质 + 反差面 = 有厚度的人物
```

### 对白公式
```
身份差：不同身份说话方式不同
信息差：一个人知道，一个人不知道
性格差：一个嘴硬，一个拆台
三差叠加 = 有张力的对白
```

### 场景公式
```
烟火气 = 具体物件 + 具体价格 + 具体动作 + 具体尴尬
```

### 情节推进公式
```
小危机开场 → 人物靠本事解决 → 暴露身份差异 → 引出更大规则 → 下一事件继续碰撞
```

```markdown

[ ] 每个重要场景是否带来变化？
[ ] 人物选择是否暴露性格？
[ ] 背景是否参与叙事？
[ ] 视角是否稳定？
[ ] 细节是否服务人物/情节/主题？
[ ] 有没有对故事无用的漂亮段落？
[ ] 结尾是否回应开头的问题？
[ ] 主题是通过故事表现还是作者直接说出来？
```

### 60秒短剧提纲压缩版
```markdown
0-5秒：强钩子（谁被羞辱？极端事件？）
5-15秒：身份压迫（谁看不起主角？弱势在哪？）
15-30秒：冲突升级（反派做了什么更过分的事？）
30-45秒：身份反转（主角亮出什么证据/身份/资源？）
45-55秒：爽点反击（反派如何被打脸？）
55-60秒：结尾钩子（留下新悬念或更大身份）
```

## 输出规范

1. **提纲输出**：使用故事提纲模板，包含前提句、人物设计、冲突链、关键结构
2. **人物输出**：使用人物设计核心表，必须包含核心特质+反差面
3. **对白输出**：标注身份差/信息差/性格差，体现潜台词
4. **场景输出**：包含具体物件、价格、动作、尴尬，避免抽象描述
5. **修改建议**：使用修改检查清单，逐条对照

## 避免事项

### 提纲阶段
- 不要把提纲当固定格式（出现更好想法可以调整）
- 不要只写人物设定表而不写欲望和选择
- 不要让背景只做摆设而不参与叙事

### 人物阶段
- 不要靠作者旁白介绍人物性格
- 不要写完美无缺的角色
- 不要把人物身份当标签而不影响行为

### 对白阶段
- 不要所有角色说话方式一样
- 不要强行插现代段子破坏氛围
- 不要为了搞笑牺牲人物尊严
- 对白不要只聊天不推进剧情

### 场景阶段
- 不要只写"繁华""热闹"等抽象词
- 不要堆砌辞藻而缺少具体细节
- 场景不要只描写不推进剧情

### 叙事阶段
- 不要只讲述关键转折（关系变化/冲突升级必须场景化）
- 不要让情节只是事件排列（必须有因果关系）
- 不要视角漂移（一场戏里不要随意跳到他人内心）
- 不要边写边否定（先完成初稿再修改）

### 冲突阶段
- 不要让冲突只是"困难"而没有人物意志和对立力量
- 不要用纯神秘感替代悬念
- 不要让主角失败后没有不可逆的损失
- 不要让章节结尾"关门"（要开一扇更危险的门）

## 质量检查

- [ ] 前提句是否包含：谁？发生了什么？必须做什么？失败代价？
- [ ] 人物是否有核心特质+反差面？
- [ ] 冲突是否有明确目标+强大阻碍+具体代价？
- [ ] 每个场景是否至少推动一项（情节/人物/冲突/伏笔/主题/关系/悬念）？
- [ ] 对白是否有身份差/信息差/性格差？
- [ ] 场景是否有具体物件/价格/动作/尴尬？
- [ ] 视角是否稳定？
- [ ] 章节结尾是否有钩子？

## 示例输出

### 前提句示例（古装剧版）
当被退婚的将门之女在边关发现父亲战死的真相后，她必须孤身潜入敌营查明真相，否则全家将被扣上通敌罪名满门抄斩。

### 人物设计示例（野生型女主）
| 项目 | 内容 |
|------|------|
| 核心特质 | 胆子大 + 反应快 + 会随机应变 + 能吃苦 + 有江湖经验 |
| 反差面 | 嘴硬但心软 / 莽撞但真诚 / 容易露怯也容易逞强 |
| 魅力点 | 被现实摔打过，但依然有旺盛生命力 |
| 避免 | 只写粗鲁，忽略野生、真诚、有生命力 |

### 对白示例（三差异法）
```
A（市井女主，嘴硬）：谁要你救？我自己能行。
B（冷面男主，拆台）：能行就不会被水匪追到船上来了。
A（更狼狈但保持尊严）：我那是引蛇出洞，懂不懂？
B（看穿不说破）：嗯，引得很像。
```
→ 身份差：市井vs冷面；信息差：B知道A在逞强；性格差：嘴硬vs拆台

### 场景示例（烟火气法）
茶楼里先结账后喝茶，一两银子一壶茶，女主掏钱时手抖了一下——那是她最后的家当。隔壁桌的镖师盯着她看，她假装不在意，把鞋上溅的泥蹭到桌腿下面。
→ 具体物件（茶楼/银子）、具体价格（一两银子）、具体动作（手抖/蹭泥）、具体尴尬（假装不在意）
