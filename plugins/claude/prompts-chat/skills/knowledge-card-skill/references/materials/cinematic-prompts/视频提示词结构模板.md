# 视频提示词结构模板

## 适用场景
为 AI 视频生成工具编写结构化提示词时使用。每个板块 = 一次生成单元，独立成片。多板块时：角色/风格/画幅在**板块一定义**，后续板块只写变化。

## 核心规则
- 每个板块包含 6 个区块：基础设定、道具、场景、声音、氛围与画质、画面内容
- 画面内容根据内容二选一：动作/情绪转折多 → 多分镜；单一连续动作/沉浸氛围 → 长镜头
- 后续板块沿用板块一的设定，只写变化

## 可调用内容

### 板块一：[一句话场景摘要]

**【基础设定】（角色）**
```
角色1：[外貌、服装、标志性特征、性格/气质]
角色2：[外貌、服装、标志性特征、性格/气质]
```

**【道具】**
```
[关键道具：样子、状态、与角色/事件的关系。例：插在枪套里的左轮，枪身有磨损划痕]
```

**【场景】**
```
[环境描述、时间、天气、空间布局、氛围细节]
```

**【声音】**
```
不需要配乐，仅保留同期声。
```

**【氛围与画质】**
```
风格核心：[艺术风格关键词] + 电影级质感、超写实、真人实景拍摄、杜绝游戏CG感
视觉基调：[摄影机型号] + [镜头型号] +（[附加效果，如动态模糊]）
色彩与影调：[色彩方案] + [胶片质感] + [光线描述] + [明暗/饱和/对比] + [画幅比例，如 2.39:1 宽荧幕 / 16:9 / 9:16]
风格参考：[导演/影视参考，可选]
```

**【画面内容】— 形式 A：多分镜**
```
分镜一：
景别：[如：中景、特写、全景，并说明拍哪里]
构图：[如：居中、三分法、对称、前景遮挡]
运镜手法：[如：固定机位、跟随、缓慢前推、手持]
画面内容：[角色动作、表情变化、事件发生]

分镜二：
景别：
构图：
运镜手法：
画面内容：

分镜三：
景别：
构图：
运镜手法：
画面内容：
```

**【画面内容】— 形式 B：长镜头（一镜到底）**
```
长镜头：运镜带动景别变化，分阶段写。
起：[景别 / 构图 / 运镜] —— [画面内容]
承：[景别 / 构图 / 运镜] —— [画面内容]
转：[景别 / 构图 / 运镜] —— [画面内容]
```

### 板块二及后续：[一句话场景摘要]

> 角色与风格沿用板块一，此处只写变化（换装、换场景、道具状态变化等）。

```
【基础设定】[沿用板块一，仅说明变化]
【道具】[沿用 / 新增 / 状态变化]
【场景】[本板块的新场景]
【声音】不需要配乐，仅保留同期声。
【氛围与画质】[沿用板块一，仅说明变化]
【画面内容】[多分镜 或 长镜头]
```

## 输出示例
```
板块一：赛博朋克雨夜街头

【基础设定】
角色1：{{Portrait 1}} 30岁亚裔女性，黑色短发，穿银色反光风衣，眼神冷峻

【道具】
透明雨伞，伞面有霓虹灯反射的彩色光斑

【场景】
深夜的赛博朋克都市街道，霓虹灯牌闪烁，细雨绵绵，地面积水倒映灯光

【声音】
不需要配乐，仅保留同期声。

【氛围与画质】
风格核心：赛博朋克、黑色电影、电影级质感、超写实、真人实景拍摄、杜绝游戏CG感
视觉基调：Sony Venice + Vintage Anamorphic（动态模糊、变形宽荧幕光斑）
色彩与影调：霓虹紫+青绿，胶片颗粒质感，霓虹环境光，高对比，2.39:1 宽荧幕
风格参考：《银翼杀手》+ 王家卫

【画面内容】
分镜一：
景别：中景，女性腰部以上
构图：居中构图，前景雨伞部分遮挡
运镜手法：缓慢前推
画面内容：女性撑伞站在街角，霓虹灯光在伞面上流转，她微微抬头看向远方

分镜二：
景别：特写，面部
构图：三分法，眼睛位于右上交点
运镜手法：固定机位
画面内容：雨水顺着脸颊滑落，眼神从冷漠转为警觉，瞳孔微微收缩

分镜三：
景别：全景，全身
构图：引导线，街道灯光形成透视线
运镜手法：拉远
画面内容：女性转身走入雨夜，身影逐渐融入霓虹光影中

——————————

板块二：室内安全屋

【基础设定】
角色1：{{Portrait 1}} 同上，风衣已湿透，头发贴在脸上

【道具】
透明雨伞收起靠在墙边，伞尖滴水

【场景】
昏暗的安全屋，唯一光源是窗外透入的霓虹光，墙上贴满监控照片

【声音】
不需要配乐，仅保留同期声。

【氛围与画质】
[沿用板块一]

【画面内容】
长镜头：
起：远景 / 前景遮挡（门框）/ 缓慢前推 —— 镜头从门外推入，女性推门进入安全屋
承：中景 / 三分法 / 固定机位 —— 她靠在墙上喘息，雨水从风衣滴落
转：特写 / 居中 / 缓慢前推 —— 她看向墙上的监控照片，眼神变得坚定
```

## 避免事项
- 不要在后续板块重复描述角色基础设定
- 不要忘记每个板块都要有声音行
- 画幅比例只在板块一指定
- 不要在一个板块中混用多分镜和长镜头两种形式
- 道具不要只列名字，要写状态和与角色的关系
