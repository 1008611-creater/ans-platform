# AI短视频人物出场提示词方法论

## 适用场景

AI视频中需要人物像电影角色一样有"登场感"时使用。不是单纯写"一个人出现"，而是通过场景铺垫、镜头运动、视觉焦点、首尾帧控制、人物转身等方式，让人物出场更有电影张力。

## 核心规则

### 核心公式

```
场景铺垫 → 镜头运动 → 人物出现方式 → 焦点变化 → 情绪反应 → 戏剧冲突
```

> 不要直接写"人物出现"，而是写"镜头如何发现人物、剧情如何引出人物、观众如何被人物吸引"。

## 可调用内容

### 一、由虚到实：先铺垫环境，再引出人物

**逻辑**
先让观众看到世界发生了什么，再把镜头焦点转到主角身上。

**叙事链**
```
环境事件 → 群众反应 → 主角出现 → 镜头聚焦 → 情绪建立
```

**适用场景**
灾难片人物出场、末日英雄登场、怪兽片主角亮相、科幻短剧开场、战争/逃亡类剧情开头

**提示词示例（灾难片）**
```
1-4秒：POV视角，城市建筑远处有巨型怪兽，怪兽在城市楼宇间咆哮
4-9秒：平视角，近景，人们聚集在街头惊恐望向远方
     主角人物从人群中侧身走出
     镜头聚焦在主角人物
     人物抬头望向远方，神情紧张
```

---

### 二、从无到有：制造突然出现的人物

**逻辑**
先让画面看起来正常，再让一个人物突然闯入，制造剧情反转。

**叙事链**
```
近景日常动作 → 镜头拉远/横移 → 空间被打开 → 新人物出现
```

**适用场景**
悬疑片、杀手登场、惊悚短剧、黑帮剧情、反派人物亮相

**提示词示例（杀手登场）**
```
画面1：女人正在帮男人擦拭脸颊，准备做spa
镜头慢慢拉远，同时横移
画面2：一个杀手突然出现在门口
```

---

### 三、用首尾帧控制人物出现

**逻辑**
用两张参考图控制AI的生成过程，大幅提高人物出场的可控性。

**工作流**
```
首帧（参考图1）：正常场景，没有关键人物
尾帧（参考图2）：人物已经出现，形成冲突
        ↓
提示词连接两个画面，AI生成中间过程
```

**适用场景**
- 一个人从门口出现
- 一个人从黑暗中走出
- 一个怪物慢慢靠近
- 一个角色从人群中被镜头发现
- 一个反派突然出现在窗外

---

### 四、通过剧情动作制造人物登场

**逻辑**
用动作重复+情绪升级制造戏剧张力，在关键时刻揭示人物。

**叙事链**
```
动作重复 → 情绪升级 → 镜头特写 → 突然揭示 → 人物反应
```

**适用场景**
惊悚追杀、悬疑反转、反派亮相、剧情高潮

**提示词示例（车内惊悚）**
```
图1：女人十分紧张地想要启动汽车
     无论怎么扭动钥匙，汽车都无法启动
     女人越来越紧张
     镜头推进到手部特写
     女人颤抖的手不停转动钥匙
     随着车子启动的声音，镜头切回中景
此刻图2：反派杀手站在车窗外
     正俯身看着车内的女人
     女人猛地转头看到他，被吓到抱头尖叫
```

---

### 五、背影开场：镜头推进后露出真容

**逻辑**
先不露脸 → 通过背影制造神秘感 → 镜头推进/下降 → 人物转身 → 表情变化

**叙事链**
```
背影/侧面 → 神秘感建立 → 镜头推进 → 转身 → 表情变化
```

**适用场景**
大佬登场、反派Boss亮相、科幻指挥官出场、皇帝/将军/掌权者亮相、商业人物高级感开场

**提示词示例（科幻指挥官）**
```
镜头慢慢下降
坐在椅子上的人物转身面向镜头
表情由严肃变为微笑
```

## 避免事项

- ❌ 不要直接写"一个人出现/走进房间" — 缺乏镜头语言和叙事节奏
- ❌ 不要只堆砌"电影感、高清、真实感"标签 — 关键在镜头运动和剧情结构
- ❌ 不要跳过场景铺垫直接进入人物 — 没有环境就没有登场感
- ❌ 提示词示例中的具体画面描述可根据场景替换细节，但**叙事结构保留**
