# Douyin Caption And Cover Patterns

## Title Patterns

- Direct result: `我用X解决了Y，效果比想象中明显`
- Pain point: `很多人卡在Y，其实是少了X`
- Curiosity: `这个细节不改，视频再好也容易被划走`
- Scenario: `做X之前，先看这一步`
- Contrast: `不是X没用，是你少做了Y`

## Caption Pattern

```markdown
标题推荐：

正文：
第一句钩子。
补充1-2句背景或关键步骤。
给出轻量 CTA。

话题：
#话题1 #话题2 #话题3

封面：
1. 画面：
   文案：
   理由：
2. ...

风险提醒：
```

## Cover Rules

- 2-8 Chinese characters per main text block is easiest to scan.
- Put the product/result/person face/关键动作 in the cover if available.
- Avoid tiny explanatory copy; move detail into caption.
- Use high-contrast text and leave margins for platform UI.
