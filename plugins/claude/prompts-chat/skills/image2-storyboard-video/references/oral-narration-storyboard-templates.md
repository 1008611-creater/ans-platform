# 单人口播型故事板模板

用于这类项目：

- 单人长时间口播
- 多片段转场 / 插片
- 纪实解释型短片
- 知识型、评论型、产业观察型、纪录片口播型内容

## 1. 人物图模板

```text
16:9 横版，一张图内多个模块。

【基础设定】
角色类型：固定主讲人 / 固定口播人
项目类型：真实纪实口播短片
不可改变的身份锚点：年龄、脸型、发型、服装、手势习惯、眼神气质

【氛围与画质】
风格核心：真实试装照 / 选角参考照 / 口播角色圣经图
视觉基调：自然皮肤、真实布料、普通室内光或窗边光
摄影：50mm / 85mm 纪实人像

【画面内容】
1. 正面口播位半身
2. 45度侧脸半身
3. 正面近景静止表情
4. 常用手势半身
5. 服装细节
6. 全身站姿
7. 远中近景识别点说明
8. 备用口播状态
```

## 2. 关键信息图模板

```text
16:9

【基础设定】
主题：<这一张图要说明的唯一核心论点>
形式：纪实视觉关系板 / 信息锚点图

【氛围与画质】
风格核心：真实摄影元素组成的信息关系图，不是 PPT，不是海报
视觉基调：与项目主风格一致

【画面内容】
单张图内呈现 3-5 个真实视觉证据，必须一眼说明：
1. 这段在讲什么
2. 证据在哪里
3. 为什么要切到下一个段落
```

## 3. 主讲人口播位首帧模板

```text
用途：Image2 生成主讲人口播 true first frame

【基础设定】
地点：<超市 / 牛舍 / 道路边 / 检测区 / 早餐桌旁 / 牧场外围>
主要角色：固定主讲人
角色参考说明：使用已通过的人物图，只锁身份和服装
场景参考说明：使用真实场景参考，只锁环境和空间关系
声音限制：现场感为主

【氛围与画质】
风格核心：真实口播首帧，不是直播，不是海报
摄影机/镜头：50mm 中近景
色彩与光线：跟场景真实光一致

【画面内容】
主体位置：主讲人半身或中近景，看向镜头
空间关系：背景能说明当前段落场景
动作起点：正要开始说这一段的第一句
镜头运动余量：允许轻微推近或微调
必须可见的识别点：脸、发型、上衣、稳定眼神
```

## 5. 正式故事板模板

进入此模板前提：

- 主讲人人物图通过
- 关键信息图通过
- 口播位和 B-roll 首帧通过

```text
16:9

【基础设定】
上传主讲人人物图、关键信息图、首帧图
故事：<这一段的论点和证明逻辑>

【1-8 镜头脚本】
1) 主讲人口播主镜头
2) 主讲人口播补位或轻微变化
3) B-roll 证据 1
4) B-roll 证据 2
5) B-roll 证据 3
6) 主讲人或场景过桥
7) B-roll 结论性证据
8) 下段转场落点

【制作板结构】
顶部栏 / 角色与风格参考 / 道具锁定 / 环境和机位路线 / 8帧故事板 / 灯光情绪 / 音频 / 摄影笔记

【生成要求】
必须一眼看出是“主讲人主线 + B-roll 证明”的制作板，不是两条并行故事线。
```

## 6. 口播型项目常见错误

- 先写完整故事板，再临时补主讲人人设
- 人物图没锁住，就开始做口播首帧
- 关键信息图缺失，导致故事板只剩漂亮镜头拼接
- 口播和 B-roll 变成两条竞争叙事线
- 主讲人口播位像直播间、发布会或广告主持，而不是纪实解释者
