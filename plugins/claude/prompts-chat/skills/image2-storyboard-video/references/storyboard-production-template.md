# 单张电影制作板 / 视觉规划表模板

用于生成一张 16:9 Image2 故事板。它融合角色参考、制作板、故事帧和导演注释颜色系统。

```text
(上传角色图 / 参考图) 16:9

故事 = <当前项目自己的短片/广告故事，一句话说明题材、人物、冲突、情绪和结尾爆点。>

故事帧数量 = 6-9 帧。简单 10 秒展示面用 6 帧讲清起势、推进、峰值、收束；复杂动作、高价值展示、车辆/道具交互用 8-9 帧承载更多动作和镜头信息。

1) <镜头1：远景/建立镜头，交代地点、人物关系和情绪起点。>
2) <镜头2：人物特写或动作开始。>
3) <镜头3：另一个人物反应或关键对视。>
4) <镜头4：关键道具/动作近景。>
5) <镜头5：手部/道具/服装/物件特写，承载情绪或信息。>
6) <镜头6：空间全景或关系镜头，展示冲突升级。>
7) <镜头7：人物特写，情绪或爽点开始兑现。>
8) <镜头8：反应/抢词/转折/决定性动作。>
9) <镜头9：大远景或结尾画面，完成爆点、情绪或下一镜头连接。>

避免场景过于相似。创建一个电影制作板 / 视觉规划表，比例 16:9，展示短片或商业广告的完整概念。布局简洁、基于网格，并分为清晰标记的部分。

【共享创意指导（顶部栏）】
整体要求：镜头数量、统一调色板、环境背景、视觉优先级、时长、比例。

【角色与风格参考】
展示核心角色的正面、背面、侧面、特写、放松姿态；配有服装和配饰参考。强调身份一致性，同时允许在具体场景中轻微变化。

【道具锁定】
展示关键道具整体、细节、材质、用途和不可变形态。

【环境和场景设计】
展示主场景，并加入俯视示意图，说明角色在空间中的移动路径。包括摄像机位置和沿路线标注的拍摄类型。

【故事板区】
一系列编号帧，大约 8-9 个镜头，展示场景进展。每个帧包括：摄像机类型 / 镜头感觉、镜头大小（广角、中景、特写、微距）、运动方式（静态、跟踪、手持等）、动作和情绪进展的简短描述。
1-9 号故事帧内部保持纯电影画面，只呈现人物、道具、场景、导演箭头、构图框和情绪标记；台词集中放在底部【音频 / 音调】栏，以制作笔记小字记录。

【灯光 / 情绪 / 风格备注】
与灯光条件、氛围和纹理相关的视觉示例和简短描述。包括一天中不同时间的过渡和光线质量变化。

【情绪关键词块】
简洁情绪基调和主题词。

【音频 / 音调部分】
环境声音、音乐风格和整体声音氛围。
台词以制作笔记形式集中列在本栏，不进入任一故事帧画面。

【电影摄影笔记】
镜头特性、运动风格和后期处理感觉的总体视觉哲学。

【导演注释颜色系统】
红色箭头 = 身体运动。
蓝色箭头 = 摄像机运动。
绿色标记 = 构图 / 构图笔记。
橙色标记 = 光线方向。
紫色标记 = 歌声 / 情感强调。
黑色文字 = 短焦镜头笔记和面板标签。

整个版面应感觉连贯、电影化且专业设计，像导演的预制作指南，能一眼传达基调、节奏和视觉叙事。

生成要求：单张 16:9 专业电影制作板，浅灰制作板底色，清晰网格，真实电影帧，清晰中文栏目，规整编号，角色名、道具名、镜头说明、灯光、情绪、音频、摄影笔记都由 Image2 生成在图内。完整保留顶部栏、角色与风格参考、道具锁定、环境路线、8-9 个故事帧、导演注释颜色系统。画面帧清楚，版面干净，像导演预制作指南。
```
