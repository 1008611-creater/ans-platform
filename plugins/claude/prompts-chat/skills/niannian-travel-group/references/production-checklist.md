# 念念旅行团生产审计清单

## 剧情

- [ ] 本集只有一个主要小目标
- [ ] 内容由具体动作推动，不靠设定解释
- [ ] 没有跨越未授权的时间段
- [ ] 结尾是自然下一步，不是强行反转
- [ ] 没有打破第四面墙

## 首发第一天

- [ ] 上集为上午：法宝袋、偷跑、开机、偶然落地、海边停留
- [ ] 中集为中午：同一生活区、第一次吃饭、支付小麻烦、街巷
- [ ] 下集为下午至晚上：沿街走、同片海变化、天黑、夜市入口
- [ ] 不回天界、不跨日、不出现父亲发现、闻川和追捕

## 人物

- [ ] 念念首次下凡前不了解凡间
- [ ] 法宝袋物件来自她从爹爹那里顺来
- [ ] 她有法力但不靠法力跳过所有生活细节
- [ ] 服装、发型、包、设备和动作连续
- [ ] 口播年轻自然，不模仿具体创作者

## 视听

- [ ] 第三人称到第一人称有明确动作转场
- [ ] POV不是纯航拍，保留手、袖口、脚步、呼吸和轻微晃动
- [ ] 风景和环境声有完整停留
- [ ] 口播不盖住海浪、风、街巷、碗筷和人声

## 合规与素材

- [ ] 真实地点、人物、声音和商业场所具备可用权限
- [ ] 不虚构真实人物经历
- [ ] 品牌物件不做广告化特写，生产前核对使用边界
- [ ] AI合成角色与真实素材的标注方案已确认
