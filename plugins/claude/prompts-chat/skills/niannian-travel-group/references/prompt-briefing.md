## 提示词结构

每条提示词都包含三层，缺一不可：

1. **角色锚点**（人物相关才需要）：从提示词包第 1 节完整复制，禁止改动五官/发型/服装描述；
2. **任务描述**：本张图要做的事（视角、动作、表情、场景）；
3. **验收标准**：生成后必须逐条核对，不达标就返工，不带着问题进下一张。

MJ 用英文 prompt + `--ar` + `--v 6.1`；OpenLux 用英文 prompt + `--size` + `quality=high`。

## 角色一致性铁律

- 脸型/眼睛/眉形/鼻唇比例每张一致；
- 发型：长直黑发 + 云纹银簪 + 少量碎发；
- 服装：浅薄荷白双层仙裙、宽袖、银色细腰带、云纹暗绣；
- 比例：修长清俊、不网红脸、不过度美颜；
- 六表情：轻松/好奇/惊讶/被汽水呛到/认真观察/临时心虚。

## 现实场景铁律

- 贴近真实福建氛围，仙气只给天宫；
- 品牌物件无实读 Logo 和完整包装文字；无授权改原创相似物件；
- 路牌/招牌等文字由后期用可靠素材叠加，不靠模型生成；
- 真实人物不露脸（手部/背影原则），避免肖像与授权问题。

## 生成顺序

1. 第一批：念念正面半身 → 锁定锚点 → 侧面/背面/全身 → 六表情集；
2. 第二批：天宫偏殿 → 念念落座/殿门回头 → 法宝袋 → 道具特写；
3. 第三批：按首发微区域顺序做现实场景（海边落地 → 路牌 → 街巷 → 饭摊 → 下午海边 → 夜市入口）。

## 阻塞项（生成前先确认）

- 念念外观年龄定档（当前 20–23 岁外观）；
- 相机外观固定（当前黑色深灰无品牌）；
- 福建首发微区域地理范围；
- 品牌物件授权取舍；
- 现实地名叠字方式。
