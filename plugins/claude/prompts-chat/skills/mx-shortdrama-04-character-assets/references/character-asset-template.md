# 人物资产提示词模板

## 输入槽位

```text
生产身份：{target_name}；{source_name_status}
选角层级：{casting_tier}；{lead_or_supporting_presence}
人物硬事实：{age_class}；{body_scale}；{skin_tone}；{face_anchors}
服装状态：{silhouette}；{layers}；{colors}；{materials}；{fit_and_wear}
发型发饰：{hairline}；{hairstyle}；{hair_accessories}
妆面与皮肤：{makeup_or_grooming}；{skin_state}
配饰：{accessories_and_exact_positions}
身份气质：{occupation_class_context}；{temperament}
当前状态：{just_experienced_event}；{visible_state_changes}
目标地区：{target_region} / {target_language_locale}
证据：{evidence_basis}
```

空槽位不输出。不得用推测填空；必要的本土化设计写为 `creative_fill`。

## 真实摄影细节编译

按当前景别选择细节，不要把所有细节全部堆入每条提示词：

```text
近景：毛孔、细小绒毛、眼角湿润、鼻头微红、自然肤色变化、眼睛焦点。
半身：皮肤自然纹理、发丝边缘、衣料受力褶皱、配饰反射、浅景深。
全身：体型比例、服装垂坠、鞋材质、重心和与环境的尺度关系。
```

“真实/电影感/高级/漂亮”只有在后面跟随可见证据时才保留。每张人物图最多指定一个轻微自然不对称点；摄影必须写明镜头距离或景别、光线方向/软硬/色温，以及光线对皮肤、发丝或衣料产生的结果。`32K`、`最佳品质`、`杰作` 等质量口号不进入模板。

## A. 定妆身份母图

```text
资产类型：16:9 单人影视定妆身份母图。
最高置信度人物身份：{生产身份与姓名状态}。
选角层级：{男主/女主/关键儿童/主要配角/次要配角}；{用具体骨相、跨角度表现、眼神和辨识锚点表达主角感或配角功能}。
人物硬事实：{年龄、体型、肤色、可见面部辨识锚点}。
服装：{版型、层次、颜色、具体材质、合体程度、磨损/褶皱/状态}。
发型与发饰：{发际线、长度、分缝、扎法、碎发、发饰材质和位置}。
妆面与皮肤：{眉形、眼妆、唇色、胡须、妆容完整度、伤妆/泪痕/疲劳等可见状态}。
配饰：{品类、材质、颜色、佩戴位置和数量}。
身份与当前状态：{职业/阶层/场合}；{刚经历的事件如何具体改变妆造和神态}。
画面：单人半身或四分之三身定妆照，中性可辨识表情，身体自然面向镜头；脸、发型、上身服装结构和关键配饰无遮挡。背景低干扰且符合身份语境，不包含剧情动作、其他人物或可读文字。
摄影：真实影视选角定妆摄影，清楚的自然皮肤纹理、发丝、衣物受力褶皱和材质反射；光线服务于辨识脸、发型和服装，不做美容广告或网红精修。
```

定妆母图的摄影细节必须结合用途填写：身份锁定优先自然人像压缩和脸部辨识；需要检查服装/体型时补充全身尺度；极近脸部特写只在剧情或 QA 明确需要时使用。光线写“方向 + 软硬 + 色温 + 对材质的可见影响”，不写抽象质量词。

## B. 角色设定卡

```text
引用：@{已通过的定妆身份母图}，只负责同一张脸、同一年龄、同一发型、同一妆面、同一服装和配饰身份。
资产类型：16:9 单人多宫格影视角色设定卡。
人物身份：{生产身份}；严格保持身份母图的全部人物与妆造锚点。
版式：正面全身、左侧全身、右侧全身、背面全身、正面半身/头肩近景；另列四种表情：中性、{表情2}、{表情3}、{表情4}。仅在连续性需要时加入{服装层次/配饰/状态细节}近景。
一致性：所有宫格是同一个人，年龄、脸型、五官比例、发际线、发型、肤色、体型、服装版型/材质/颜色、鞋、首饰和配饰位置完全一致；站姿中性，四肢和手指完整，全身尺度一致。
标签：仅标{生产身份}、视角和表情，放在对应宫格边缘或空白区域，不遮挡脸、身体、服装或配饰。
摄影：干净低干扰背景，均匀中性光，真实皮肤、发丝、织物、金属和鞋材质；角色设定资料质感，不做剧情海报、时尚广告或拼贴剪报。
```

角色设定卡沿用身份母图的摄影和妆造锚点，只补足跨角度能验证的皮肤、发丝、衣料与配饰细节；不得借新光线或新妆面重新设计脸。

## 渠道负向字段

仅在渠道有独立 negative prompt 时使用：

```text
多人、重复人物、不同人脸、年龄漂移、族裔漂移、换发型、换装、配饰漂移、服装结构变化、浓重美颜、塑料皮肤、油腻高光、假发感、头套感、头大身小、比例失真、短肢、断肢、多肢、坏手、裁脚、遮脸、二次元、卡通、明星脸、网红脸、字幕、水印、品牌、随机文字、噪点、颗粒、伪影、过度锐化、混乱纹理
```

儿童额外排除：成年身体、成年妆容、职业装、成熟性感造型。来源事实要求的伤妆、污渍、颗粒或媒介质感不得被负向字段误删。
