# MiniMax H3 创作契约参考

基于用户授权访问的《MiniMax H3 模型 - 使用手册》提炼；仅保留通用能力约束和创作方法，不保留原文案例、素材或私人链接。

## 1. 官方 H3 能力边界

| 项目 | 官方能力说明 | 使用时的结论 |
| --- | --- | --- |
| 输出 | 4–15 秒、24 FPS、原生双声道声音 | 先按此规划视频；实际提交以 RunningHub 通道契约为准。 |
| 画幅 | 21:9、16:9、4:3、1:1、3:4、9:16 | 若 API 没有画幅字段，在提示词中写清画幅。 |
| 提示词 | 最多 7000 字符，支持多语言 | 用结构化描述替代堆砌形容词。 |
| 图片 | JPG/JPEG/PNG/WEBP/HEIC/HEIF，单张最多 30MB | 先核对当前 API 对图片数量和节点的真实限制。 |
| 视频 | H.264/AVC 或 H.265/HEVC，内含 AAC/MP3，单段最多 50MB | 只有当前 API 实际暴露视频节点时才可提交。 |
| 音频 | WAV/MP3，单段最多 15MB | 音频用于表演、台词或节奏；不能假定任意通道支持音频。 |
| 首尾帧原生模式 | 图片 0–2 张；宽高 256–5760；比例 5:2–2:5 | 不带图可理解为文生，但 RunningHub 首尾帧通道仍以实际节点为准。 |
| 原生全能参考 | 最多 9 图、3 段视频、3 段音频；总素材最多 12；视频/音频单段 2–15 秒，总长度各不超过 15 秒 | 这是“值得定制工作流/API”的能力上限，不表示当前三图、四图或图音通道已经支持。 |
| 分辨率意图 | 768p 适合常规短边 768；1440p 为官方推荐规格 | 可作为创作意图。只有 API 可选时才传分辨率字段。 |

**原则：官方能力上限不等于当前 RunningHub API 的可提交字段。** 先读取 `minimaxh3skill` 的通道注册表与 API 页面；超过已发布通道能力时，使用 `runninghub-workflow-api` 完成工作流定制、发布并获得实际契约。

## 2. 创作契约模板

```text
输出规格：生成 [时长] 秒、[画幅] 视频；[是否强调原生声音/文字清晰/交付目的]。

参考职责：
- 图 1：[场景、整体风格、光线或构图]
- 图 2：[人物外貌、服装和角色一致性]
- 图 3：[产品、道具或关键资产]
- 图 4：[Logo、片尾卡或文字视觉]
- 音频：[台词、情绪表演、节拍或环境声音]

场景与叙事：[人物/产品在何处做什么，情绪如何变化]。

镜头与剪辑：[镜头 1 -> 镜头 2 -> 镜头 3；镜头运动；转场；节奏]。

人物与产品动作：[角色动作，产品与动作的自然关系]。

文字与版式：[精确文本；字体气质；位置、字距、出现/停留/离场；仅出现一次、清晰可读、不得乱码或错拼]。

声音与节奏：[环境声、BGM、台词；在第 N 秒的镜头/文字同步点]。

风格与硬约束：[材质、调色、光线、质感；必须保留项；禁止新增项；禁止的转场或风格]。
```

## 3. 专项短模板

### 连续关键帧（多图）

```text
图 1 到图 2 使用 [硬切/扫视/光学拖影]；保留 [人物、产品、固定遮罩] 的位置和比例不变。
图 2 到图 3 用 [分屏重组/曝光闪烁] 推进至 [动作或构图结果]。
所有 [Logo/标题] 仅出现一次，清晰可读；不得新增人物、车辆、建筑、Logo 或任何文字。
```

### 高级品牌片（四图）

```text
图 1 定义 [场景和胶片氛围]，图 2 锁定 [人物]，图 3 锁定 [产品]，图 4 为 [片尾 Logo]。
让人物在 [具体动作] 中自然使用/展示产品；节奏 [克制/高级/冷感/灵动]。
不是普通剧情片，也不是普通电商广告；片尾 Logo 在 [位置] 清晰停留 [时长意图]。
```

### 影视预告

```text
[时长] 秒 [画幅] 预告：Shot 1 [氛围建立]；Shot 2 [冲突]；Hard cut 到 Shot 3 [高潮]；短黑场后标题 [文字与字距/材质] 出现。
声音：开场 [低频/环境]，第 [N] 秒 [冲击或转场]，标题出现时 [hit]，结尾 [定格和余韵]。
禁止 [错误类型、过度发光、拖沓转场、模仿既有旋律]。
```

### MG/片头/文字动效

```text
先出现 [黑底/线框/色块]，随后 [分屏边界/剪影/道具/文本] 按鼓点依次 [滑入/弹出/遮罩揭示]。
转场只用 [硬切、色块切、分屏重组、画格贴入]，不使用 [柔和溶解、流体转场]。
文字 “[精确文本]” 仅出现一次，拼写准确、清晰可读；指定 [位置、字距、停留和离场]。
```

### 图像加音频（人物表演）

```text
图像负责锁定 [人物、场景、产品]；音频负责 [台词、表演强度、节奏]。
人物在第 [N] 秒完成 [动作/表情]，与 [台词词句/鼓点] 对齐；保留 [人物特征、服装、产品]。
禁止 [口型不同步、无关人物、错误文字、无关音乐或风格]。
```
