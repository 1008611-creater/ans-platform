# Hook And Proof Script

Use this before making commerce visuals. The script decides what each image or shot must prove.

## Core Structure

1. **Hook:** stop the viewer with a concrete claim, contradiction, or sensory promise.
2. **Doubt:** name the viewer's likely skepticism.
3. **Proof chain:** show evidence, not adjectives.
4. **Burst point:** the most shareable/satisfying sensory or emotional moment.
5. **Close:** make the next action feel low-friction and justified.

## Hook Types

Use one primary hook:

- **Sensory shock:** "剥开这一秒，汁直接挂在手上。"
- **Origin contrast:** "这不是仓库货，是今天山里刚分出来的。"
- **Doubt reversal:** "看荔枝甜不甜，不先看颜色，先看这里。"
- **Gift/status:** "送人别只看盒子，里面这口才是面子。"
- **Scarcity/timing:** "这批果再晚两天，口感就不是这个状态了。"
- **Process trust:** "你收到前，它会经过这三道筛。"

Avoid empty hooks:
- "家人们太好吃了"
- "源头好物来了"
- "品质精选"
- "高端大气"
- "错过后悔"

## Proof Beats

Pick 3-5. Each proof beat needs a visual.

Food/fruit proof:
- peel/open/crack moment
- juice, steam, pull, crunch, fiber, grain, oil, aroma proxy
- cross-section or inside texture
- hand scale and natural size variation
- sorting rejects or grade comparison
- origin and handling process
- packing and cold/freshness workflow
- first bite reaction, but only after evidence

Trust proof:
- real worker hands
- simple process steps
- package going into shipping box
- visible batch/order workflow without readable private data
- seller/person accountable in the frame

Gift proof:
- open-box reveal
- package material close-up
- clean arrangement without hiding product quality
- handoff scene or table scene matching real use

## Burst Point

The burst point is the one moment viewers remember or replay.

Good burst points:
- fruit skin breaks and juice beads appear
- product sound/texture implied visually
- box opens to reveal abundance after a process montage
- side-by-side rejected vs selected goods
- seller says a specific line while showing a hard proof

Bad burst points:
- logo zoom
- generic smile
- beauty shot with no new proof
- price card
- exaggerated claim without evidence

## 20-40 Second Script Template

```text
0-3s Hook:
<specific claim or contradiction with visible proof>

3-8s Doubt:
<name the buyer's concern: stale, sour, fake origin, ugly gift, damaged shipping>

8-22s Proof chain:
1. <proof beat + visual>
2. <proof beat + visual>
3. <proof beat + visual>

22-30s Burst point:
<the strongest sensory/process/gift moment>

30-40s Close:
<simple purchase/gift/use reason; no empty shouting>
```

## Shot-To-Script Mapping

Every shot must answer one question:

- Why stop? Hook image.
- Why believe? Proof image.
- Why trust the seller? Process image.
- Why remember the product? Sensory burst image.
- Why buy now? Close image.

If a shot only says "it looks premium", replace it with proof or make it a short transition.

## Line Quality Rules

For Chinese commerce scripts, read `chinese-commerce-script.md` before finalizing. The core rule is: write what a seller can say while doing the action on camera.

Prefer:
- "我先剥一颗给你看。"
- "这颗不是最大，但水分最稳。"
- "坏果和压伤的先挑掉。"
- "装盒前再过一遍手。"

Avoid:
- "甄选优质产地，匠心打造"
- "高端品质，尊享生活"
- "新鲜美味，老少皆宜"
- "源头直发，品质保证" without showing process proof
- "这盒才成立"
- "这口要的是..."
- "核心不是..."
- "降低怀疑"
- any analysis sentence disguised as口播
