# 自动化适配器接口约定

## 适配器最小接口

```python
class Adapter:
    name: str
    target_url: str

    def inspect(self, page):
        """只读侦察页面，返回可见控件和映射状态。"""

    def fill_task(self, page, task):
        """填写任务，但不点击付费/提交按钮。"""

    def review(self, page, task):
        """返回提交前截图、费用提示和人工确认信息。"""

    def submit_once(self, page, task):
        """仅在确认后提交一次并返回页面证据。"""

    def read_receipt(self, page, task):
        """读取任务状态或页面回执。"""
```

## 设计原则

- 适配器负责页面动作，任务状态机负责状态和断点；
- 不把站点选择器写进通用任务校验脚本；
- 页面侦察返回“已验证/未知/阻塞”，不猜测；
- 提交动作必须是单次显式调用；
- 所有截图、错误和回执落本地批次目录；
- 页面发生变化时，先重新运行 inspect，再修改适配器。

## MXAI 当前未知项

以下内容必须以当前登录后页面真实侦察为准，不从截图猜测：

- 输入框稳定定位器；
- 参考图上传控件类型；
- v8.2 是否为页面真实版本选项；
- 9:16 是否原生存在或需要映射到1:2；
- `--sref`、`--oref`、`--iw` 的页面输入方式；
- 生成按钮是否显示积分/费用确认；
- 任务ID和结果状态的回读位置。
