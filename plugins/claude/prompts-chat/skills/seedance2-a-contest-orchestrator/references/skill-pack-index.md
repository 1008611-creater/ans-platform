# Skill Pack Index

Use this pack in the following order:

## 1. Learn the proven method

Invoke:

- `mx-shell-zombie-scavenger-research`

Use when:

- you want to absorb Mx-Shell's public workflow;
- you want proven rules before generating anything;
- you need to distinguish confirmed facts from public summaries.

## 2. Build reusable images

Invoke:

- `image2-narrative-firstframe`

Use when:

- the project needs character sheets;
- multi-character shots drift;
- a prop, room, or world detail must stay stable;
- a video shot needs a true first frame.

## 3. Convert frames into shots

Invoke:

- `seedance2-narrative-shot-workflow`

Use when:

- the first frame is approved;
- a 5-second or short dramatic shot must be generated;
- you need timed beats, audio rules, and strong negative constraints.

## 4. Stay in routing mode

Invoke:

- `seedance2-a-contest-orchestrator`

Use when:

- you need the next stage decision;
- you are prioritizing scenes;
- you want the next 3 executable tasks instead of broad theory.
