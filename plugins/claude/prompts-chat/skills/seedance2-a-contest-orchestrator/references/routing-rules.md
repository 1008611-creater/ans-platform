# Routing Rules

Invoke `ai-film-champion-method` when:

- the user wants a direction above average taste;
- the goal is first place rather than "good enough";
- you need to decide whether a project should be rebuilt before execution.

Invoke `mx-shell-zombie-scavenger-research` when:

- the user says `先学习`;
- the user wants to borrow `丧尸清道夫` methods;
- the user wants external best practices turned into reusable workflow rules.

Invoke `relic-collector-ip-system` when:

- the chosen IP line is 遗物回收员 / relic collector;
- the user wants the world, protagonist, or case package;
- the next step depends on that IP's rules or asset plan.

Invoke `image2-narrative-firstframe` when:

- a scene needs a true first frame;
- characters drift between shots;
- the project needs repeatable reference assets;
- prop text or scene layout must be stabilized before video.

Invoke `seedance2-narrative-shot-workflow` when:

- the first frame is approved;
- the user needs copy-ready Seedance2 prompts;
- a shot needs audio, timing, and negative constraints;
- reroll decisions need to be structured.

Stay in orchestrator mode when:

- the user is choosing between stages;
- the work needs prioritization;
- the contest path is being adjusted.
