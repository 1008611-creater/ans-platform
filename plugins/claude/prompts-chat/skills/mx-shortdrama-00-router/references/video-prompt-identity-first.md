# 身份前置毫秒分镜视频提示词

## S-002 默认编译覆盖

本文件的默认执行版本为“参考协同 + 首段基准 + 后续差分”。正文只写原片中文角色名；目标地区英文名留在资产映射和内部合同。资产参考名只写中文显示名，去掉英文名、资产 ID 和文件名后缀；同一完整提示词内第一次引用写中文名，后续再次引用同一资产时在中文名前加 `@`。每张参考图必须以“职责 + 本段画面事实”进入正文，不能只列引用清单。第一个小分镜建立完整基准，后续小分镜只写“保持上一状态；变化；结果”，不重复未变化的服装、空间、光线、道具或角色身份。删除无画面作用的模板套话和抽象审美词；每个小分镜仍保留构图/人物、动作因果、镜头运动、光线/道具/环境、声音/对白及毫秒时间码。

## 默认结构

每个完整 `VG` 生产组仍只生成一段模型正文，但正文内部必须按原片小分镜时间顺序展开。默认模板如下：

```text
场景身份：这是一个{场景类型}。
环境身份：发生在{时代、地点、空间、阶层、行业、故事背景}。
人物身份：{最高置信度人物是谁}；位于画面{开场位置/遮挡/前后景关系}；开场状态为{有证据的心理、身体或任务状态}。

按小分镜时间轴执行（必须按顺序、按毫秒时码表现，不得省略构图、动作或镜头运动）：
S001 | 00:00:00.000-00:00:00.867（本组 0.000-0.867 秒）
构图/人物：{Gemini/Step02 构图、人物站位、遮挡、前后景关系}
动作：{人物动作细节、手部任务、眼神/表情、重心变化、道具或环境反馈}
镜头运动：{初始机位与轴线、运动路径与速度、跟随对象或重构图、焦点/景别变化、结束稳定构图}
光线/道具/环境：{光源、光质、色温、可见道具、桌面/墙面/窗帘/文件等环境事实}
声音/对白：{本镜头对应说话人、画内/画外关系、目标语言台词或无对白反馈}

S002 | ...

整体光线连续性：{跨镜头保持或变化的光线事实}。
声音/氛围总控：{跨镜头声音空间、环境声、对白连续关系}。
连续细节：{服装、发型、皮肤、道具、场景磨损、反射等可见连续性}。
负向约束：避免{当前组最可能出现的 5-10 个失败}。
```

三类身份必须先于动作出现。`场景身份` 是事件类型，不是地址；`环境身份` 是故事世界和空间语境；`人物身份` 是稳定角色身份加当前状态。不要用 `视频目标`、`空间与人物连续性`、`节拍与镜头`、`声音与表演` 或 `硬约束` 包装模型正文。

## 电影因果层（v5 默认）

电影感不是额外的风格形容词，而是每个小分镜内可执行的变化链。编译时必须保留：

```text
上一稳定状态 -> 视觉/光线/台词/环境触发 -> 人物反应 -> 镜头/环境反馈 -> 结束状态
```

执行分支：

- 镜头、构图或光线改变：只写变化后的字段和变化方向；写清人物如何承接变化，最后写姿势、视线、表情、重心或道具的结束状态。不能重复前一镜头完整机位文本。
- 镜头、构图和光线不变但有台词：只声明稳定字段保持，把台词绑定到有证据的口型、停顿、视线、眉眼、嘴唇、头部、重心或手部任务变化；没有证据时不得臆造皱眉、微笑、呼吸加重等表演。
- 镜头、构图和光线不变且无台词：只写证据中的连续微动作或保持状态，不新增事件、镜头运动或情绪转折。
- 视觉变化与人物变化同时发生：先写触发关系，再写人物反应，最后写镜头落点；“人物自然变化”“镜头服务动作”等套话不能代替事实。

每条小分镜必须同时检查四层空间：前景/遮挡、主体及动作、背景道具/环境痕迹、焦点/景别与环境反馈。字段缺失时写“保持上一状态”或“证据未给出”，不能用模板补齐。

## 分镜故事版区域

Step04 Word 必须在生视频提示词之前，为每个 `VG` 输出“分镜故事版”：场景目标、观众必须理解、可读性风险、故事板作图提示词，以及按毫秒源镜头展开的故事板计划。计划每条至少写叙事任务、观众焦点、调度/表情、光线/镜头与作图状态。正式图执行固定为：`storyboard-director 计划 -> validate -> score -> render -> 单张跟随原片画幅的正式故事板`；竖屏原片使用 9:16，横屏原片使用 16:9。实际故事板图未生成时只写待生成；生成后回填真实路径、SHA-256、渠道任务 ID 与 QA，不得把提示词或源片帧当作故事板成图。

## 证据展开

`shot_evidence` 不只是 sidecar，它是生视频正文的默认信息源。对一个 `VG`：

1. 先用共同剧情目的确定一个场景身份。
2. 用地点、时代、阶层、行业和故事类型确定环境身份。
3. 用最高置信度角色绑定、开场位置和可见表情/身体事实确定人物身份与开场状态。
4. 随后按每个源 `shot_id` 的原始起止时码逐条展开，不合并、不改序、不丢毫秒。
5. 每个小分镜必须至少写清：构图/人物、动作、镜头运动、光线/道具/环境、声音/对白。
6. Gemini v4 的 `剧情发展`、`人物动作细节`、`镜头运动细节`、构图、站位、空间关系和光线，在与映射清晰帧一致时是最高权重视觉语义证据；必须进入对应小分镜，而不是只留在证据表。
7. Mimo ASR、Qwen3 ForcedAligner、字幕/OCR 与声纹/主动说话脸仍负责台词文本和说话人绑定；Gemini 不覆盖台词真值。
8. 小分镜不是流水账：每条只写会改变画面的可见事实，但不能省略镜头运动、构图变化、人物动作因果或道具/环境反馈。

如果一个 `VG` 内的小分镜已经表达两个无法共享场景身份或连续动作链的事件，优先返回上游重分组；不要用模板硬塞。

## 视觉语言

抽象质量词不能直接进入正文，必须翻译成可见证据：

| 抽象词 | 可见证据 |
| --- | --- |
| 真实 | 不完美皮肤、环境磨损、自然阴影、非对称细节 |
| 高级 | 克制色彩、少量材质对比、留白、稳定构图 |
| 电影感 | 明确光源、景深、镜头运动、空间层次、情绪节奏 |
| 活人感 | 微表情、重心偏移、手部自然占用、明确眼神方向 |
| 产品质感 | 材质反光、边缘高光、使用痕迹、尺度参照 |

不要写“真实、高级、电影感、质感好”。例如把“真实有电影感的女孩”改成“女孩肩膀微微前倾，眼神看向画外，皮肤保留自然纹理，发丝边缘受侧光勾勒，背景玻璃有轻微反射和街道虚化”。

## 检查

- 每个完整 `VG` 只有一组场景、环境和人物身份前置，但必须包含全部小分镜时间轴。
- 每个小分镜都要有毫秒级起止时码、构图/人物、动作、镜头运动、光线/道具/环境、声音/对白。
- 删除任一形容词后画面没有变化时，删除该词或改成可见证据。
- 动作必须有动机；手部被任务占用；重心自然变化；镜头运动服务动作或关系变化；场景给动作提供阻力、声音或反馈。
- 编译前必须清除占位值（如 `[object Object]`、`undefined`、`null`）。若上游字段是对象数组，必须转成自然语言或回退到构图事实，禁止原样进入正文。
- 负向约束集中一次，限制在 5-10 个已知失败，不用否定句淹没正向画面。
- 提示词结构通过不代表视频已生成、已验收或已获渠道提交授权。
