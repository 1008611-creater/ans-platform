# Step04 Word 版式与验收合同

## 适用范围

生成、更新或验收短剧转绘 Step04 Word 时执行本合同。内容事实、资产提示词和生视频提示词仍由对应编号 Skill 决定；本合同只负责用户可见 Word 的几何、分页、文件写入和验收。

## 已观察问题

实际任务曾把横向 Letter 页面的资产总表设为 `17100 DXA`，而页面真实可用宽度只有 `14256 DXA`。OOXML 仍保存完整文字，但最右列伸出页面，用户看到右侧文字缺失。其他表曾使用 `14400 DXA`，同样超过真实可用宽度。修复后 25 张表的最大宽度为 `14256 DXA`，越界数为 0，Microsoft Word 导出的 28 页可完整显示。

这条防线只保护 Word 表格版式。触发条件是表格网格宽度超过当前 section 可用宽度；保护动作是保存和交付 Step04 Word；owner 是 Step04 Word 生成器；当全部表格结构回读和 Microsoft Word 全页视觉检查通过后解除阻塞。

## 页面几何

1. 从最终 DOCX 当前 section 读取 `page_width`、`left_margin` 和 `right_margin`，计算 `usable_width = page_width - left_margin - right_margin`。不要根据横向、Letter 或历史模板猜固定宽度。
2. 当前项目横向 Letter、左右各 `0.55 in` 的结果为 `14256 DXA`，只能作为已验证示例，不作为其他页面设置的通用常量。
3. 每张表的 `tblW`、`tblGrid/gridCol`、每行各单元格 `tcW` 必须使用 DXA，并且总宽度一致且不大于该 section 的 `usable_width`。关闭 autofit，不使用百分比宽度或 Word 默认自适应。
4. 生成器收到非正列宽、列数不匹配或总宽度超限时立即抛错，不得生成一个看似成功但右侧不可见的 Word。

## 列宽与内容

1. 先为标识、证据等级、镜头范围等短字段分配最小可读宽度，再把最大剩余宽度给完整提示词列。
2. `资产名＆ID` 必须完整可辨识；提示词允许自然换行和跨页，不得删字、截断、改成省略号或靠极小字号塞入页面。
3. 横向生产包正文默认不低于 8 pt；高密度索引最低 7 pt。空间不足时优先重分配列宽、允许增页或拆成“集中索引 + 逐资产详表”，不得继续缩字。
4. 集中资产总表保留资产名与 ID、最高置信度身份、证据等级、使用镜头和完整可复制提示词。逐资产详表继续保留职责、提示词、参考图和成图状态；不能用版式修复改变内容合同。

## 跨页规则

1. 给跨页表的首行设置 `w:tblHeader`，保证每一页重复表头，避免续页失去列语义。
2. 普通高度的记录行设置 `w:cantSplit`；单行内容本身高于一页时允许该行跨页，否则 Word 会制造大块空白或无法排版。
3. 不设置固定行高。长提示词单元格使用自动高度、顶部对齐和正常段落换行。
4. 验收时区分“合法跨页续行”和“右侧裁切”：前者文字在后页继续且列仍在页内，后者的网格或文字越过右页边界，必须失败。

## 文件占用与不中断交付

1. 先写临时文件并完成结构校验，再替换目标文件。目标 DOCX 被 Word、资源管理器预览或桌面预览控件独占时，不终止用户应用、不停转。
2. 文件被占用时，写入同目录、确定性命名的修复副本，例如在原 stem 后追加 `_防裁切修复`；将该实际路径、SHA-256 和审计结果写入 `harness_state.json` 与当前 Word 审计记录。
3. 不得声称已覆盖仍被占用的旧文件。后续目标解除占用时，可由同一生成器在下一次明确更新中恢复权威文件名；不要创建多个随机后缀副本。

## 验收

1. 用 `python-docx` 或直接 OOXML 回读每张表：记录 section 可用宽度、表数量、每张 `tblGrid` 总宽度、最大宽度和越界数量；越界数量必须为 0。
2. 回读关键表头和最右列文本，确认 `资产名＆ID`、`可复制生图提示词` 等字段仍存在，提示词字数和内容没有因修版丢失。
3. 使用 Microsoft Word 自动化导出 PDF 或逐页图像，检查全部页面的右边界、换行、跨页表头、行拆分、重叠、缺字和异常空白。不得使用 LibreOffice 生成、转换或验收转绘 Word。
4. 只有结构回读和 Microsoft Word 全页视觉检查都通过，才把 DOCX 记录为 Step04 可交付文件。若 Microsoft Word 自动化真实不可用，明确记录未完成视觉验收，不得把结构检查冒充视觉通过。

## 后续复利检查

下一次同类 Step04 Word 至少验证一次：超宽输入会在保存前失败、长提示词完整保留、跨页表头重复、目标文件被占用时仍产生唯一可用副本并更新任务状态。若任一项失败，只修复 Word 生成边界，不改人物、场景、故事板或生视频方法。

## 版本归档

当用户确认新的 Step04 Word 明显优于旧版本时，把新文件设为唯一活跃默认版本；不要继续让生成器重建已经被替代的基础版、准确版、预览版或历史详情版。归档前列出精确候选，只处理被新版本替代的用户可见 Word，不移动 Markdown、编译合同、证据 sidecar 或渠道产物。

用户同意归档后，先生成一个带日期的 ZIP，核对条目数量、文件名、大小和 ZIP SHA-256，再把已入包的旧 Word 移入同目录 `archive/versions`，最后将 `harness_state.json` 中所有活跃 Step04 Word 别名和 SHA-256 统一指向新默认文件。文件被独占时不强关用户应用；归档其他可读版本，把该文件记录为唯一待归档项，解除占用后再移动并重建 ZIP。不得把部分归档报告成全部完成。
