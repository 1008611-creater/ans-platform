# Skill Evaluation Rubric

Use this rubric after a skill materially affects a task, especially when deciding whether it should remain a champion.

## Score Fields

Score each field from 0 to 2.

| Field | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Trigger accuracy | Wrong or unnecessary | Useful but broad/narrow | Clearly necessary |
| Rework reduction | Added work | Some help | Prevented real rework |
| Context efficiency | Bloated context | Acceptable | High signal, low context |
| Evidence quality | No verifiable output | Partial evidence | Clear commands, artifacts, or citations |
| Noise control | Confusing or duplicate | Minor noise | No meaningful noise |

Total:

- 9-10: Champion candidate or keep as champion.
- 7-8: Useful; keep but monitor.
- 5-6: Patch trigger/body or restrict use.
- 0-4: Demote unless there is a rare high-value niche.

## Required Notes

Each durable score should include:

- Task name or project.
- Skill name.
- One sentence on what improved.
- One sentence on what failed or cost extra.
- Whether to keep, patch, demote, or promote.

## Monthly Review

During review, group scores by skill and inspect:

- Average total score.
- Trigger false positives.
- Repeated context bloat.
- Missing verification.
- Overlap with other skills.

Keep the champion list short. If two skills solve the same problem, keep the one that produces clearer action with less context.
