# shadcn/ui Boundaries

Use shadcn/ui for app-like interfaces, not as a default website personality.

## Good Fits

- SaaS dashboards.
- Admin panels.
- Settings, forms, tables, filters, command menus.
- Internal tools.
- Product apps with dense interactions.

## Poor Fits

- Brand-led landing pages needing distinctive art direction.
- Editorial, luxury, cultural, cinematic, or portfolio sites.
- Any case where default cards, badges, and purple gradients become the visual idea.

## Requirements

- Map components to actual workflows.
- Customize typography, spacing, color, and states.
- Avoid nested cards and generic SaaS hero composition.
