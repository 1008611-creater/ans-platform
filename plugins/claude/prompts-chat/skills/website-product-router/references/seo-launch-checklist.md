# SEO Launch Checklist

For public websites, verify or explicitly mark not done:

- Unique title and meta description.
- Canonical URL for production pages.
- Open Graph and Twitter/social preview image.
- Explicit favicon or application icon reference, with a successful browser request.
- `robots.txt` and `sitemap.xml` where applicable.
- Semantic headings with one clear H1 per page.
- Descriptive links and image alt text.
- 404/not-found page for routed sites.
- Schema only when it is accurate and useful.
- Core Web Vitals/performance budget is recorded when SEO launch matters.
- Public accessibility basics are checked: alt text, labels, focus, contrast.

Do not mark SEO complete from a plan alone. Record checked public URLs and artifacts. A localhost or private candidate can prove that tags are present or absent, but cannot prove the final canonical URL, crawlability, share-card fetch, or production schema output.
